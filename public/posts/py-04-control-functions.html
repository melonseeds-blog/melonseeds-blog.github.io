들여쓰기 = 블록

대부분의 언어가 중괄호 { }로 블록을 표시하지만, Python은 들여쓰기 그 자체가 블록 구조다. 같은 들여쓰기 깊이를 가진 줄이 하나의 블록이 된다.

if x > 0:
    print("양수")
    print("계속 같은 블록")
print("바깥")  # 들여쓰기가 풀렸으므로 if 바깥

콜론(:)은 "아래에 블록이 따라온다"는 신호다. if, for, while, def, class 등 모든 블록 도입부에 붙는다.

탭과 스페이스를 섞지 말자 Python 3에서는 탭과 스페이스를 섞으면 TabError가 발생한다. PEP 8 권장은 스페이스 4칸이다. 에디터의 "Show whitespace" 기능을 켜두면 안전하다.

조건문

if / elif / else

score = 85

if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
else:
    grade = "F"

print(grade)  # B

다른 언어의 else if를 Python에서는 elif로 줄여 쓴다. switch가 없던 시절(3.10 이전)에는 긴 elif 사다리로 분기를 처리했다.

truthy / falsy

Python은 거의 모든 값을 bool로 평가할 수 있다. 다음은 모두 falsy다.

# falsy 값들
bool(False)   # False
bool(None)    # False
bool(0)       # False
bool(0.0)     # False
bool("")      # False  (빈 문자열)
bool([])      # False  (빈 리스트)
bool({})      # False  (빈 딕셔너리)
bool(set())   # False  (빈 셋)

# 그 외는 모두 truthy
bool("0")     # True  (문자열 "0"은 비어있지 않음, 주의!)
bool([0])     # True  (요소가 있음)
bool(-1)      # True

이 덕분에 빈 컨테이너 체크가 매우 간결하다.

items = []

# 비추천 - 명시적이지만 길다
if len(items) == 0:
    print("비어있음")

# 권장 - Pythonic
if not items:
    print("비어있음")

조건 표현식(삼항)

Python의 삼항 연산자는 다른 언어와 어순이 다르다. 값1 if 조건 else 값2 형태다.

age = 20
status = "성인" if age >= 18 else "미성년"

# C/Java: status = age >= 18 ? "성인" : "미성년"
# Python: status = "성인"  if age >= 18 else "미성년"

# 리스트 컴프리헨션과 결합
nums = [1, -2, 3, -4]
absolutes = [n if n >= 0 else -n for n in nums]  # [1, 2, 3, 4]

match-case (3.10+)

Python 3.10에서 도입된 구조적 패턴 매칭이다. 단순한 값 비교를 넘어 패턴 구조를 매칭할 수 있다.

def http_status(code):
    match code:
        case 200 | 201:
            return "성공"
        case 404:
            return "찾을 수 없음"
        case 500 | 502 | 503:
            return "서버 에러"
        case _:                # 와일드카드 (default)
            return "알 수 없음"

# 구조 분해
def describe(point):
    match point:
        case (0, 0):
            return "원점"
        case (x, 0):
            return f"X축 위 x={x}"
        case (0, y):
            return f"Y축 위 y={y}"
        case (x, y):
            return f"점 ({x}, {y})"

print(describe((3, 0)))  # X축 위 x=3

반복문

for - 이터러블 순회

Python의 for는 C 스타일의 카운터 루프가 아닌 이터러블 순회 루프다.

fruits = ["사과", "바나나", "체리"]

for fruit in fruits:
    print(fruit)

# 문자열도 이터러블
for ch in "Hi":
    print(ch)        # H, i

# 딕셔너리 순회
scores = {"국어": 90, "수학": 85}
for key in scores:           # 키만
    print(key)
for key, val in scores.items():   # 키-값
    print(key, val)

range, enumerate

# range(stop)
for i in range(5):           # 0, 1, 2, 3, 4
    print(i)

# range(start, stop)
for i in range(2, 6):        # 2, 3, 4, 5
    print(i)

# range(start, stop, step)
for i in range(10, 0, -2):   # 10, 8, 6, 4, 2
    print(i)

# enumerate - 인덱스가 필요할 때
for i, fruit in enumerate(["사과", "바나나", "체리"]):
    print(f"{i}: {fruit}")

# 시작 인덱스 지정
for i, fruit in enumerate(["사과", "바나나"], start=1):
    print(f"{i}번째: {fruit}")
실행 결과 (enumerate)
0: 사과 1: 바나나 2: 체리

while

n = 10
while n > 0:
    print(n)
    n -= 1

# 무한 루프 + break
while True:
    user_input = input("종료하려면 q: ")
    if user_input == "q":
        break

break / continue / for-else

for i in range(10):
    if i == 3:
        continue   # 이번 반복 건너뛰기
    if i == 7:
        break      # 루프 종료
    print(i)
# 출력: 0 1 2 4 5 6

# for-else - 다른 언어에 거의 없는 문법
for item in [1, 2, 3, 4, 5]:
    if item == 99:
        print("찾음")
        break
else:
    print("못 찾음")   # break 없이 끝까지 돌면 실행
for-else의 else는 "정상 종료"일 때 실행된다 조건이 거짓일 때 else가 실행되는 것이 아니라, break 없이 루프를 끝까지 돌았을 때 else가 실행된다. 이름이 헷갈리므로 nobreak로 외우면 편하다.

함수 정의

def greet(name):
    """이름을 받아 인사 문자열을 반환한다."""   # docstring
    return f"Hello, {name}!"

msg = greet("Alice")
print(msg)            # Hello, Alice!
print(greet.__doc__)  # 이름을 받아 인사 문자열을 반환한다.
  • def로 시작, 콜론으로 블록 도입
  • 첫 줄에 들어가는 문자열은 docstring이 되어 help()나 __doc__로 접근 가능
  • return이 없으면 자동으로 None 반환
def no_return():
    print("hi")

result = no_return()
print(result)  # None

# 여러 값 반환 - 사실은 tuple
def min_max(nums):
    return min(nums), max(nums)

lo, hi = min_max([3, 1, 4, 1, 5])
print(lo, hi)  # 1 5

인자 종류

Python은 인자 전달 방식이 매우 유연하다. 6가지 형태를 한 함수에 다 쓸 수도 있다.

종류문법호출 예설명
위치 인자def f(a, b)f(1, 2)순서대로 전달
키워드 인자def f(a, b)f(a=1, b=2)이름으로 전달, 순서 무관
기본값def f(a, b=10)f(1)생략 시 기본값 사용
가변 위치 인자def f(*args)f(1, 2, 3)tuple로 받음
가변 키워드 인자def f(**kwargs)f(x=1, y=2)dict로 받음
def info(name, age=20, *hobbies, **extra):
    print(f"이름: {name}")
    print(f"나이: {age}")
    print(f"취미: {hobbies}")
    print(f"기타: {extra}")

info("Alice", 25, "독서", "등산", city="서울", job="개발자")
실행 결과
이름: Alice 나이: 25 취미: ('독서', '등산') 기타: {'city': '서울', 'job': '개발자'}

인자는 반드시 다음 순서로 정의해야 한다.

def f(필수, 기본값=값, *args, **kwargs):
    pass

인자 종류 강제 (/ , *)

특정 인자를 위치로만 또는 키워드로만 받도록 강제할 수 있다.

함수 인자 종류 — /와 *로 영역을 나눈다
def func(a, b, /, c, d, *, e, f):
    print(a, b, c, d, e, f)

# OK
func(1, 2, 3, d=4, e=5, f=6)
func(1, 2, c=3, d=4, e=5, f=6)

# Error - a는 키워드로 전달 불가
func(a=1, b=2, c=3, d=4, e=5, f=6)
# TypeError: func() got some positional-only arguments passed as keyword arguments

# Error - e는 위치로 전달 불가
func(1, 2, 3, 4, 5, 6)
# TypeError: func() takes 4 positional arguments but 6 were given
언제 쓸까? /는 인자 이름을 노출하고 싶지 않을 때(API 안정성), *는 의미를 분명히 하기 위해 호출 측에서 이름을 적게 강제하고 싶을 때 쓴다. 예: sorted(iterable, *, key=None, reverse=False).

스코프와 LEGB

이름을 찾을 때 Python은 4단계 스코프를 순서대로 뒤진다. 이를 LEGB 규칙이라 한다.

LEGB — Local → Enclosing → Global → Built-in 순서로 이름 검색
x = "global"   # G

def outer():
    x = "enclosing"   # E

    def inner():
        x = "local"   # L
        print(x)      # local

    inner()
    print(x)          # enclosing

outer()
print(x)              # global
print(len)            # B - built-in 함수

global / nonlocal

안쪽 스코프에서 바깥 변수에 대입하려면 명시해야 한다. 단순 읽기는 LEGB로 자동 해결된다.

counter = 0

def increment():
    global counter   # 모듈 전역 변수에 대입하겠다
    counter += 1

increment()
increment()
print(counter)  # 2

def make_counter():
    count = 0
    def inc():
        nonlocal count   # 바로 바깥 함수 변수에 대입하겠다
        count += 1
        return count
    return inc

c = make_counter()
print(c(), c(), c())  # 1 2 3
대입이 있으면 그 변수는 그 스코프의 지역 변수 함수 안에서 counter = counter + 1처럼 쓰면, 오른쪽의 counter도 지역 변수로 간주되어 UnboundLocalError가 난다. 바깥 변수를 수정하려면 global 또는 nonlocal이 필요하다.

람다(lambda)

이름 없는 한 줄짜리 함수다. 표현식 하나만 담을 수 있고, 결과가 자동으로 반환된다.

# def 버전
def square(x):
    return x * x

# lambda 버전 - 동일
square = lambda x: x * x

print(square(5))  # 25

# 인자 여러 개
add = lambda a, b: a + b
print(add(3, 4))  # 7

# 정렬 키로 자주 사용
people = [("Alice", 30), ("Bob", 25), ("Charlie", 35)]
people.sort(key=lambda p: p[1])   # 나이 기준
print(people)
# [('Bob', 25), ('Alice', 30), ('Charlie', 35)]

# map / filter 와 함께
nums = [1, 2, 3, 4, 5]
squared = list(map(lambda n: n**2, nums))      # [1, 4, 9, 16, 25]
evens   = list(filter(lambda n: n%2 == 0, nums))  # [2, 4]
람다는 짧을 때만 쓰자 조금이라도 복잡하면 def로 풀어쓰는 것이 가독성에 좋다. PEP 8도 람다를 변수에 할당하는 것보다 def 사용을 권장한다.

함수가 일급 객체

Python에서 함수는 객체다. 변수에 담고, 인자로 넘기고, 반환값으로 받을 수 있다.

def shout(text):
    return text.upper()

def whisper(text):
    return text.lower()

# 변수에 담기
fn = shout
print(fn("Hello"))   # HELLO

# 인자로 넘기기
def apply(func, value):
    return func(value)

print(apply(shout, "hi"))     # HI
print(apply(whisper, "BYE"))  # bye

# 반환값으로 돌려주기 - 클로저
def make_multiplier(factor):
    def mul(x):
        return x * factor    # factor를 캡처
    return mul

double = make_multiplier(2)
triple = make_multiplier(3)
print(double(10))  # 20
print(triple(10))  # 30

인자 unpacking

리스트/튜플 앞에 *, 딕셔너리 앞에 **를 붙이면 함수 호출 시 자동으로 풀어준다. 함수 정의의 *args, **kwargs의 반대 방향이다.

def add(a, b, c):
    return a + b + c

# 리스트 unpacking
nums = [1, 2, 3]
print(add(*nums))   # 6  --- add(1, 2, 3)과 동일

# 딕셔너리 unpacking
params = {"a": 10, "b": 20, "c": 30}
print(add(**params))  # 60  --- add(a=10, b=20, c=30)과 동일

# 함께 사용
def greet(name, greeting="Hi", punct="!"):
    print(f"{greeting}, {name}{punct}")

args = ["Alice"]
kwargs = {"greeting": "Hello", "punct": "?"}
greet(*args, **kwargs)   # Hello, Alice?

흔한 함정

가변 객체를 기본 인자로

리스트/딕셔너리 기본값 함정 기본 인자는 함수가 정의될 때 한 번만 평가된다. 가변 객체를 기본값으로 쓰면 호출마다 누적되는 버그가 생긴다. 
# 잘못된 예
def append_item(item, target=[]):    # 함정!
    target.append(item)
    return target

print(append_item(1))   # [1]
print(append_item(2))   # [1, 2]  ← 새 리스트가 아니다!
print(append_item(3))   # [1, 2, 3]

# 올바른 패턴
def append_item(item, target=None):
    if target is None:
        target = []
    target.append(item)
    return target

print(append_item(1))   # [1]
print(append_item(2))   # [2]  ← 매번 새 리스트

global 남용

global은 함수 간 결합도를 높이고 테스트를 어렵게 만든다. 가능하면 값을 인자로 받고 결과를 return으로 돌려주자.

# 나쁜 예
total = 0
def add(x):
    global total
    total += x

# 좋은 예
def add(total, x):
    return total + x

total = add(total, 5)

탭/스페이스 혼용

def f():
    print("a")    # 스페이스 4칸
	print("b")    # 탭 - TabError 발생

한 파일 안에서 들여쓰기 문자를 섞으면 안 된다. 에디터의 "Convert indentation to spaces" 기능을 한 번 실행해두자.

for-else 오해

# 잘못된 이해: "for가 안 돌면 else"
for x in []:    # 빈 이터러블 - 루프 본문 한 번도 실행 안 됨
    print(x)
else:
    print("else 실행됨")   # 그래도 else는 실행된다 (break가 없었으니까)

다시 한 번 — for-else의 else는 break 없이 끝났을 때 실행된다. 빈 이터러블이라도 break가 없었으므로 else가 돈다.
