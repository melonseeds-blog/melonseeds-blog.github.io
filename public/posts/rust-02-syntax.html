변수와 가변성 — let·mut·섀도잉

Rust에서 변수는 let으로 묶고, 기본이 불변이다. 한 번 값을 바인딩하면 다시 대입할 수 없다. 바꾸려면 mut를 명시적으로 붙여야 한다. 컴파일러가 "이건 안 바뀐다"를 기본 가정으로 잡아 주기 때문에, 실수로 값을 덮어쓰는 부류의 버그가 줄어든다.

fn main() {
    let x = 5;
    // x = 6;            // 컴파일 에러: 불변 변수에 재대입 불가

    let mut y = 10;     // mut를 붙이면 재대입 가능
    y = 20;

    println!("x = {x}, y = {y}");
}

섀도잉은 재대입이 아니다

같은 이름으로 let을 다시 쓰면 이전 변수를 가린다(shadowing). 이는 새 변수를 만드는 것이라, 타입을 바꿔도 된다. mut로 같은 변수의 값을 바꾸는 것과는 의미가 다르다 — mut는 같은 변수의 타입을 바꿀 수 없지만, 섀도잉은 새 변수이므로 가능하다.

fn main() {
    let spaces = "   ";          // &str 타입
    let spaces = spaces.len();   // 섀도잉: 이제 usize 타입
    println!("길이 = {spaces}");

    let n = 5;
    let n = n + 1;               // 새 변수로 6을 다시 바인딩
    {
        let n = n * 2;           // 안쪽 블록 한정 섀도잉 → 12
        println!("안쪽 n = {n}");
    }
    println!("바깥 n = {n}");    // 다시 6
}
C++과 이렇게 다르다 — 기본값이 뒤집혀 있다 C++에서는 int x = 5;가 기본이고 불변으로 만들려면 const를 붙인다. Rust는 정반대다 — let x = 5;가 이미 불변이고, 바꾸려면 mut를 붙인다. 즉 Rust의 let은 C++의 const가 기본값인 셈이다. 또 C++의 변수 재선언과 달리, Rust 섀도잉은 같은 스코프에서도 합법이며 타입까지 바꿀 수 있다.

자료형 — 스칼라와 복합 타입

Rust는 정적 타입 언어지만, 대부분의 경우 컴파일러가 타입을 추론한다. 추론이 모호할 때만 let guess: u32 = ...처럼 타입 주석을 단다. 타입은 크게 스칼라(단일 값)와 복합(여러 값 묶음)으로 나뉜다.

스칼라 타입

스칼라는 네 부류다 — 정수, 실수, 불리언, 문자. 정수는 비트 폭과 부호 유무를 이름에 담는다(i32, u8, i64, usize 등). 부동소수점은 f32·f64이고, 기본은 f64다. 문자 char는 1바이트가 아니라 유니코드 스칼라 값이라 4바이트다.

fn main() {
    let count: i32 = -42;       // 부호 있는 32비트 정수
    let size: usize = 1024;     // 포인터 크기 부호 없는 정수
    let ratio = 3.14_f64;       // f64 (실수 기본 타입)
    let is_ready = true;        // bool
    let letter = 'R';           // char — 유니코드 스칼라 값

    println!("{count} {size} {ratio} {is_ready} {letter}");
}

복합 타입 — 튜플과 배열

튜플은 서로 다른 타입을 고정 길이로 묶는다. 구조 분해로 한 번에 꺼내거나 .0, .1 인덱스로 접근한다. 배열은 같은 타입을 고정 길이로 묶으며, 길이가 컴파일 타임에 정해진다. 배열 인덱스가 범위를 벗어나면 컴파일이 잡아내거나 실행 중 패닉으로 멈춘다 — C++처럼 조용히 잘못된 메모리를 읽지 않는다.

fn main() {
    // 튜플: 타입이 섞여도 된다
    let person: (&str, u32) = ("Ada", 36);
    let (name, age) = person;          // 구조 분해
    println!("{name}는 {age}살", );
    println!("이름만: {}", person.0);  // 인덱스 접근

    // 배열: 같은 타입, 고정 길이 5
    let days = [1, 2, 3, 4, 5];
    println!("첫째 날 = {}", days[0]);
    println!("배열 길이 = {}", days.len());

    // [값; 개수]로 같은 값 반복 초기화
    let zeros = [0; 3];                // [0, 0, 0]
    println!("{:?}", zeros);
}

함수와 표현식

함수는 fn으로 정의하고, 매개변수에는 반드시 타입을 적는다. 반환 타입은 -> 뒤에 쓴다. Rust의 핵심 특징은 표현식 지향이라는 점이다 — 함수 본문의 마지막 표현식이 곧 반환값이 된다. 이때 세미콜론을 붙이지 않는다. 세미콜론을 붙이면 표현식이 문(statement)으로 바뀌어 값이 사라진다.

// 마지막 표현식이 반환값 — return도 세미콜론도 없다
fn add(a: i32, b: i32) -> i32 {
    a + b
}

// 조기 반환이 필요하면 return을 명시적으로 쓴다
fn abs_diff(a: i32, b: i32) -> i32 {
    if a >= b {
        return a - b;
    }
    b - a          // 마지막 표현식 반환
}

fn main() {
    let sum = add(2, 3);
    println!("합 = {sum}");
    println!("차 = {}", abs_diff(4, 9));
}
C++과 이렇게 다르다 — 표현식이 값을 낸다 C++에서 if는 문이라 값을 만들지 못해 삼항 연산자 ?:가 따로 있다. Rust에서는 if 자체가 표현식이라 let n = if cond { 1 } else { 2 };처럼 값으로 쓸 수 있다(삼항 연산자가 없는 이유다). 마찬가지로 블록 { ... }도 마지막 표현식을 값으로 내보낸다. 그래서 함수 끝에서 return 없이 표현식만 두는 스타일이 관용적이다.

제어 흐름 — if·loop·while·for

if 조건은 반드시 bool이어야 한다 — C++처럼 정수 0을 거짓으로 자동 변환하지 않는다. 그리고 if는 표현식이므로 값으로 쓸 수 있다.

fn main() {
    let number = 7;

    // if를 값으로 사용 (양쪽 분기 타입이 같아야 한다)
    let parity = if number % 2 == 0 { "짝수" } else { "홀수" };
    println!("{number}는 {parity}");
}

loop·while·for

반복은 세 가지다. loop는 무한 반복이며 break로 값을 내보낼 수도 있다. while은 조건이 참인 동안 돈다. for는 이터레이터(범위·컬렉션)를 순회하며, Rust에서 가장 흔히 쓰는 반복문이다. 범위는 0..5(끝 미포함)나 0..=5(끝 포함)로 표현한다.

fn main() {
    // loop + break로 값 반환
    let mut counter = 0;
    let result = loop {
        counter += 1;
        if counter == 10 {
            break counter * 2;   // loop가 20을 반환
        }
    };
    println!("result = {result}");

    // while
    let mut n = 3;
    while n > 0 {
        println!("{n}!");
        n -= 1;
    }

    // for로 범위 순회 (0..3 → 0,1,2)
    for i in 0..3 {
        println!("i = {i}");
    }

    // for로 배열 순회
    let items = [10, 20, 30];
    for item in items {
        println!("item = {item}");
    }
}
인덱스 대신 for-in을 쓴다 C++에서 for (int i = 0; i < n; i++)로 배열을 도는 습관이 있다면, Rust에서는 for item in items처럼 값 자체를 순회하는 쪽이 관용적이고 안전하다. 인덱스 계산 실수로 범위를 벗어날 여지가 없다. 인덱스가 정말 필요하면 for (i, item) in items.iter().enumerate()를 쓴다.

match 기초

match는 값을 여러 패턴과 차례로 견주어 처음 맞는 가지를 실행하는 표현식이다. C++의 switch와 비슷해 보이지만 더 강하다 — 모든 경우를 빠짐없이 다뤘는지 컴파일러가 망라성(exhaustiveness)을 검사한다. 빠진 경우가 있으면 컴파일이 거부한다. 나머지를 받는 _ 또는 변수 패턴으로 마무리한다.

fn describe(n: i32) -> &'static str {
    match n {
        0 => "영",
        1 | 2 => "하나 또는 둘",   // | 로 여러 값 묶기
        3..=9 => "한 자리 수",     // 범위 패턴
        _ => "그 외",              // 나머지 전부 — 망라성 보장
    }
}

fn main() {
    // match는 표현식이라 값으로 바인딩된다
    for n in [0, 2, 7, 100] {
        println!("{n} → {}", describe(n));
    }
}

각 가지의 결과 타입은 서로 같아야 하며, match 전체가 그 타입의 값을 만든다. 위 예시에서는 모든 가지가 &'static str를 내므로 함수 반환값으로 그대로 쓸 수 있다. 패턴은 여기서 다룬 리터럴·범위·| 외에도 구조 분해, 가드 조건 등으로 확장되는데, 그 부분은 열거형과 함께 다음 편에서 이어 간다.

이 편의 요점 한 줄 Rust 문법의 바탕에는 두 가지 원칙이 깔려 있다 — 안전을 기본값으로(불변이 기본, 망라성 검사) 그리고 표현식 지향(if·블록·match·loop가 값을 낸다). 이 둘만 잡으면 나머지 문법은 그 위에 얹히는 응용이다.
