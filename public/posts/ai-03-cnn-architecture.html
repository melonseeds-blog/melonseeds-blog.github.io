왜 MLP로는 안 되는가

2편에서 다룬 다층 퍼셉트론(MLP)은 입력을 1차원 벡터로 받아 완전연결 계층을 쌓는 구조다. 표 형태의 데이터에는 잘 맞지만, 이미지에는 두 가지 결정적인 문제가 있다. 이 문제 때문에 CNN(Convolutional Neural Network, 합성곱 신경망)이 등장한다.

MLP가 이미지에서 무너지는 두 가지 지점

1. 공간 정보 손실 — MLP에 이미지를 넣으려면 2차원 픽셀 격자를 한 줄로 펴야 한다. 이 순간 "어떤 픽셀이 어떤 픽셀 옆에 있었는가"라는 위치 관계가 사라진다. 사람의 얼굴에서 눈과 코의 상대적 배치, 결함의 가장자리가 이어지는 모양 같은 국소적 패턴이 모두 흩어진다.

2. 파라미터 폭발 — 1000×1000 컬러 이미지는 입력 노드가 300만 개다. 첫 은닉층 노드가 1000개라면 그 사이 가중치만 30억 개다. 학습이 불가능할 정도로 무겁고, 그만큼의 데이터도 없으면 곧바로 과적합된다.

핵심 통찰은 이렇다. 이미지에서 의미 있는 패턴은 대부분 국소적이고, 같은 패턴이 이미지 어디에 나타나든 같은 의미를 가진다. 왼쪽 위의 엣지든 오른쪽 아래의 엣지든 "엣지"라는 사실은 변하지 않는다. MLP는 이 두 성질을 전혀 활용하지 못한다. CNN은 바로 이 두 성질 — 지역성과 위치 불변성 — 을 구조 자체에 새겨 넣은 신경망이다.

전통적 비전과의 연결 OpenCV에서 Sobel, Gaussian 같은 필터를 이미지에 적용해 본 적이 있다면 CNN의 절반은 이미 아는 셈이다. CNN의 합성곱 계층은 그 "필터를 이미지 위로 슬라이딩하는" 연산과 동일하다. 단 하나, 필터의 숫자를 사람이 정하지 않고 학습으로 찾는다는 점만 다르다.

합성곱 계층 — 학습되는 필터

합성곱 계층(Convolution Layer)은 작은 필터, 즉 커널(kernel)을 이미지 위에서 한 칸씩 미끄러뜨리며 각 위치마다 곱셈-덧셈을 수행한다. 커널이 덮은 입력 영역과 커널의 숫자를 원소별로 곱해 모두 더하면, 그 위치의 출력값 하나가 나온다. 이 과정을 이미지 전체에 반복하면 특징 맵(feature map)이라는 2차원 출력이 만들어진다.

그림 1. 합성곱 연산 — 학습되는 3×3 커널이 입력 위를 슬라이딩하며 특징 맵 한 칸씩을 채운다

OpenCV의 고정 커널과 무엇이 다른가

OpenCV의 filter2D나 Sobel 필터도 커널을 슬라이딩한다. 연산 자체는 같다. 차이는 커널의 숫자를 누가 정하는가에 있다.

OpenCV 고정 커널

  • 커널 값을 사람이 수식으로 설계
  • Sobel은 엣지, Gaussian은 블러 — 용도가 고정
  • 새 문제에는 새 커널을 사람이 다시 고안
  • 해석은 쉽지만 표현력이 제한적

CNN 학습 커널

  • 커널 값을 데이터로부터 역전파로 학습
  • 무엇을 검출할지 데이터가 알려준다
  • 한 계층에 커널 수십~수백 개를 동시에
  • 문제에 맞는 특징을 스스로 찾아냄

합성곱 계층에는 보통 커널이 하나가 아니라 여러 개 있다. 커널 하나는 특정 패턴(예: 수직 엣지) 하나에 반응하므로, 다양한 패턴을 잡으려면 커널이 여러 개 필요하다. 커널이 32개면 특징 맵도 32장 나온다. 이 32라는 숫자를 그 계층의 필터 개수 또는 출력 채널 수라고 부른다.

합성곱 파라미터와 출력 크기

합성곱 계층의 동작은 몇 개의 하이퍼파라미터로 결정된다. 이들이 특징 맵의 크기와 연산량을 좌우한다.

파라미터 의미 크기를 키우면
커널 크기 (Kernel size) 커널의 가로×세로. 3×3, 5×5가 흔하다. 한 번에 보는 영역이 넓어지지만 파라미터가 늘어난다
스트라이드 (Stride) 커널을 몇 칸씩 건너뛰며 슬라이딩할지 출력이 작아지고 다운샘플링 효과가 생긴다
패딩 (Padding) 입력 가장자리에 0을 덧대는 두께 출력 크기가 커지고 가장자리 정보 손실이 줄어든다
입력 채널 (In channels) 입력의 깊이. 컬러는 3, 중간 계층은 이전 필터 수 커널도 같은 깊이를 갖게 되어 커진다
필터 개수 (Out channels) 이 계층의 커널 수 = 출력 특징 맵 장수 더 다양한 패턴을 잡지만 연산·메모리가 늘어난다
출력 크기 계산 공식

입력 한 변의 크기를 W, 커널 크기 K, 패딩 P, 스트라이드 S라 하면 출력 한 변의 크기는 다음과 같다.

// 출력 크기 = 내림( (W - K + 2P) / S ) + 1
출력 = floor( (W - K + 2P) / S ) + 1

// 예 1) 입력 32, 커널 3, 패딩 0, 스트라이드 1
(32 - 3 + 0) / 1 + 1 = 30      // 32 -> 30, 가장자리 한 줄씩 줄어듦

// 예 2) 입력 32, 커널 3, 패딩 1, 스트라이드 1  (same 패딩)
(32 - 3 + 2) / 1 + 1 = 32      // 크기 유지, 가장 흔한 설정

// 예 3) 입력 32, 커널 3, 패딩 1, 스트라이드 2
(32 - 3 + 2) / 2 + 1 = 16      // 절반으로 다운샘플링

채널은 이 공식에 들어가지 않는다. 채널 방향은 항상 커널이 통째로 덮어 곱-합하므로, 출력의 가로세로에는 영향을 주지 않고 출력의 장수만 필터 개수로 결정된다.

"same 패딩"이 흔한 이유 커널 3×3에 패딩 1을 주면 출력 크기가 입력과 같아진다. 이렇게 하면 합성곱을 여러 번 쌓아도 크기가 의도치 않게 줄지 않아 구조 설계가 단순해진다. 크기를 줄이는 일은 풀링이나 스트라이드에 명시적으로 맡긴다.

풀링 계층 — 공간을 줄이다

풀링 계층(Pooling Layer)은 특징 맵의 작은 영역을 하나의 값으로 압축해 가로세로 크기를 줄인다. 보통 2×2 영역을 스트라이드 2로 훑어 특징 맵을 절반으로 만든다. 풀링의 목적은 세 가지다.

풀링이 하는 세 가지 일

1. 공간 축소(다운샘플링) — 특징 맵이 작아지면 이후 계층의 연산량과 메모리가 크게 줄어든다.
2. 위치 불변성 확보 — 객체가 몇 픽셀 움직여도 풀링 영역 안에서는 같은 값이 나온다. 작은 이동·변형에 둔감해진다.
3. 수용 영역 확장 — 크기를 줄이면 다음 계층의 커널이 상대적으로 더 넓은 원본 영역을 보게 된다.

풀링 종류 동작 특징과 쓰임
Max Pooling 영역 안에서 가장 큰 값 하나만 남긴다 가장 강한 특징 반응을 보존한다. "패턴이 있었는가"를 묻는 분류에 가장 널리 쓰인다.
Average Pooling 영역 안 값들의 평균을 낸다 전반적인 분포를 부드럽게 요약한다. 강한 반응이 평균에 희석될 수 있다.
Global Average Pooling 특징 맵 한 장 전체를 평균내 값 하나로 분류 헤드에서 FC 계층을 대체한다. 뒤에서 다시 다룬다.
풀링에는 학습할 파라미터가 없다 합성곱 커널은 가중치를 학습하지만, 풀링은 "최댓값을 고른다" 또는 "평균을 낸다"는 고정된 규칙일 뿐이다. 학습되는 숫자가 하나도 없다. 그래서 풀링은 빠르고 가볍다. 최근 일부 구조는 풀링 대신 스트라이드 2 합성곱으로 다운샘플링을 대신하기도 한다.

특징 맵의 계층적 학습

CNN의 진짜 힘은 합성곱과 풀링을 여러 번 쌓았을 때 나온다. 계층이 깊어질수록 특징 맵이 표현하는 내용의 추상화 수준이 올라간다. 얕은 층은 단순한 무늬를, 깊은 층은 그 무늬들이 조합된 의미 있는 형태를 학습한다.

그림 2. CNN의 계층적 특징 학습 — 단순한 시각 요소에서 의미 있는 객체로 추상화가 깊어진다
계층 위치 학습하는 특징 산업 비전 예시
얕은 층 엣지, 코너, 밝기·색 경계 스크래치의 가장자리, 부품 외곽선
중간 층 질감, 곡선, 반복 무늬 표면 거칠기, 용접 비드 패턴
깊은 층 객체의 부분, 부품 형태 커넥터 핀 배열, 라벨 영역
최종 층 객체 전체, 클래스를 가르는 표현 "정상 / 크랙 / 오염" 같은 결함 유형

수용 영역 — 얼마나 넓게 보는가

수용 영역(Receptive Field)은 "출력 특징 맵의 한 픽셀이 원본 입력의 어느 범위를 보고 만들어졌는가"를 뜻한다. 이 개념이 중요한 이유는, 한 픽셀이 보는 범위가 좁으면 작은 패턴만, 넓으면 큰 구조까지 인식할 수 있기 때문이다.

층이 깊어지면 수용 영역이 넓어진다

3×3 합성곱 한 번을 거친 출력 픽셀은 입력의 3×3 영역을 본다. 그 위에 3×3 합성곱을 한 번 더 쌓으면, 두 번째 계층의 한 픽셀은 첫 계층의 3×3을 보고, 그 3×3 각각이 다시 입력의 3×3을 보므로 결국 입력의 5×5를 본다. 세 번 쌓으면 7×7이다. 여기에 풀링으로 크기를 절반씩 줄이면 수용 영역은 훨씬 더 빠르게 커진다.

// 3x3 합성곱을 스트라이드 1로 쌓을 때 수용 영역
1개 층  ->  3 x 3
2개 층  ->  5 x 5
3개 층  ->  7 x 7
// 중간에 2x2 풀링이 끼면 이후 층의 수용 영역은 2배씩 더 빠르게 확장

이것이 CNN을 깊게 쌓는 핵심 이유 중 하나다. 작은 커널을 여러 번 쌓으면, 큰 커널 하나를 쓰는 것과 비슷한 넓은 수용 영역을 얻으면서도 파라미터는 더 적고 비선형성은 더 많이 들어간다. 얕은 층의 픽셀은 좁게 봐서 디테일을, 깊은 층의 픽셀은 넓게 봐서 전체 맥락을 담당한다.

수용 영역이 객체보다 작으면 못 본다 검출하려는 결함이나 객체가 모델의 수용 영역보다 크면, 어떤 출력 픽셀도 그 전체를 한 번에 보지 못한다. 큰 결함을 다뤄야 하는데 얕은 네트워크를 쓰거나 입력 해상도만 키우면 이 함정에 빠진다. 모델 깊이와 입력 크기는 "무엇을 봐야 하는가"에 맞춰 같이 설계해야 한다.

완전연결 계층과 분류 헤드

합성곱과 풀링을 거치면 입력 이미지는 작고 깊은 특징 맵 더미가 된다. 예를 들어 7×7×512 같은 형태다. 이것을 최종 클래스 확률로 바꾸는 부분을 분류 헤드(classification head)라 부른다.

전통적 방식 — Flatten 후 FC

고전적인 CNN(LeNet, AlexNet, VGG)은 마지막 특징 맵을 한 줄로 펴서(Flatten) 완전연결 계층(Fully Connected, FC)에 통과시킨다. FC 계층이 모든 특징을 종합해 클래스별 점수를 내고, 마지막에 Softmax가 그 점수를 합이 1인 확률 분포로 바꾼다. 문제는 이 Flatten + FC 부분이 전체 파라미터의 대부분을 차지할 만큼 무겁고, 입력 크기가 고정된다는 점이다.

최근 방식 — Global Average Pooling

최근 구조는 무거운 FC 대신 Global Average Pooling(GAP)을 쓴다. 특징 맵 한 장을 통째로 평균내 값 하나로 만들면, 512장의 특징 맵이 512개의 숫자가 된다. 여기에 작은 FC 하나만 붙여 클래스 수만큼 출력한다. 파라미터가 극적으로 줄고, 과적합에 강하며, 입력 크기에 덜 민감하다는 장점이 있다.

특징 추출부와 분류 헤드의 분리 합성곱·풀링이 쌓인 앞부분을 백본(backbone, 특징 추출부), 뒤의 FC 또는 GAP 부분을 헤드라 부른다. 이 분리는 전이학습의 토대가 된다. 큰 데이터로 학습된 백본은 그대로 두고 헤드만 내 문제에 맞게 바꿔 다시 학습할 수 있다. 자세한 내용은 5편에서 다룬다.

CNN 전체 구조

지금까지의 조각을 하나로 잇는다. 전형적인 분류 CNN은 [합성곱 → ReLU → 풀링] 블록을 여러 번 반복해 특징을 추출하고, 그 결과를 분류 헤드에 통과시켜 클래스 확률을 낸다.

그림 3. CNN 전체 구조 — 백본이 [Conv-ReLU-Pool] 반복으로 특징을 추출하고, 헤드가 클래스 확률을 낸다

여기서 ReLU는 2편에서 다룬 활성화 함수다. 합성곱은 곱셈과 덧셈만 하는 선형 연산이므로, 합성곱만 쌓으면 아무리 깊어도 하나의 선형 변환과 다를 게 없다. 각 합성곱 뒤에 ReLU 같은 비선형 활성화를 끼워야 비로소 네트워크가 복잡한 패턴을 표현할 수 있다.

CNN이 잘 동작하는 이유

CNN이 이미지에서 MLP를 압도하는 이유는 세 가지 구조적 성질로 정리된다. 이 셋은 앞에서 본 "왜 MLP로는 안 되는가"에 대한 직접적인 해답이다.

지역 연결성 출력 픽셀 하나는 입력 전체가 아니라 커널 크기만큼의 작은 이웃만 본다. 이미지의 의미 있는 패턴이 국소적이라는 사실과 정확히 맞아떨어진다. 불필요한 먼 거리 연결이 없어 파라미터가 적다.
가중치 공유 같은 커널 하나가 이미지 전체를 슬라이딩한다. 위치마다 다른 가중치를 쓰지 않으므로 파라미터가 극적으로 줄고, "엣지를 찾는 능력"을 이미지 한 군데에서 배우면 모든 위치에 곧바로 적용된다.
평행이동 불변성 가중치 공유 덕분에 같은 패턴은 이미지 어디에 있든 같은 반응을 만든다. 풀링이 작은 위치 변화를 추가로 흡수한다. 결함이 화면 어디에 찍히든 같은 결함으로 인식할 수 있다.
한 문장 요약 CNN은 "이미지의 패턴은 국소적이고, 위치가 바뀌어도 의미는 같다"는 두 가지 사전 지식을 신경망 구조 자체에 박아 넣은 것이다. 그래서 같은 데이터로도 MLP보다 훨씬 적은 파라미터로 더 잘 학습한다.

산업 비전 관점에서

산업 결함 검사에서 가장 어려운 점은 "결함의 모습이 너무 다양하다"는 것이다. 같은 스크래치라도 길이, 방향, 깊이, 조명에 따른 음영이 매번 다르다. 전통적 비전에서는 이런 변동을 사람이 규칙으로 일일이 잡아줘야 했다.

CNN이 결함 검사에 강한 이유

1. 외관 변동을 특징으로 흡수 — 다양한 모습의 결함 샘플을 보여주면, CNN은 "결함을 결함이게 하는 공통 특징"을 스스로 추출한다. 규칙을 사람이 나열할 필요가 없다.
2. 위치·크기에 둔감 — 평행이동 불변성과 풀링 덕분에 결함이 부품의 어디에 생기든 검출한다.
3. 미묘한 텍스처 결함에 강함 — 얕은 층의 질감 특징이 사람 눈에도 애매한 표면 오염, 얼룩 같은 결함을 잡아낸다.

공짜는 아니다 — 데이터와 연산이 필요하다 CNN의 강점은 모두 "충분한 학습 데이터"를 전제로 한다. 결함 샘플이 수십 장뿐이면 CNN은 과적합되어 현장에서 무너진다. 또 학습과 추론에 GPU 연산이 필요해, 고속 라인에서는 추론 속도가 제약이 된다. 그래서 실무에서는 전통적 비전으로 충분한 부분은 그대로 두고, CNN은 정말 필요한 곳에만 쓰는 하이브리드 전략이 흔하다. 이 주제는 13편에서 다룬다.

흔한 오해

CNN을 처음 접할 때 자주 빠지는 오해 세 가지를 짚는다. 이 셋을 바로잡으면 CNN의 본질이 더 또렷해진다.

"커널은 사람이 설계한다" 아니다. CNN의 합성곱 커널 값은 사람이 정하지 않는다. 학습 데이터와 정답으로부터 역전파를 통해 자동으로 결정된다. 사람이 정하는 것은 커널의 "크기"와 "개수" 같은 구조적 설정뿐이다. OpenCV의 Sobel처럼 값을 손으로 채우는 것과는 완전히 다르다.
"풀링도 학습된다" 아니다. 풀링은 "최댓값을 고른다" 또는 "평균을 낸다"는 고정 규칙으로, 학습되는 파라미터가 하나도 없다. 학습되는 것은 합성곱 계층의 커널 가중치와 FC 계층의 가중치다.
"깊을수록 무조건 좋다" 아니다. 계층을 무작정 깊게 쌓으면 기울기가 사라지거나 폭발해 오히려 학습이 안 되고, 더 깊은 네트워크가 더 얕은 것보다 성능이 나빠지는 퇴화(degradation) 현상까지 나타난다. 이 문제를 구조적으로 푼 것이 바로 ResNet의 잔차 연결이며, 다음 4편에서 LeNet부터 ResNet까지 주요 아키텍처의 발전을 따라간다.
다음 편 예고 이번 글에서는 CNN을 이루는 부품 — 합성곱, 풀링, 수용 영역, 분류 헤드 — 을 하나씩 뜯어봤다. 4편에서는 이 부품들을 실제로 어떻게 조립했는지, LeNet · AlexNet · VGG · GoogLeNet · ResNet으로 이어지는 주요 CNN 아키텍처의 계보를 살펴본다. "더 깊게"라는 욕망과 그것을 가능하게 한 아이디어들의 역사다.
