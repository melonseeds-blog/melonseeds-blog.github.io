왜 ML에 별도 성능 지표가 필요한가

전통적 소프트웨어는 "기대 출력 = 실제 출력"이면 합격이다. 하지만 ML 모델은 확률적이며 "정답에 가까운 출력"을 낼 뿐이다. Ch2 품질 특성에서 언급한 테스트 오라클 문제가 바로 이 지점에서 등장한다.

그래서 ML에서는 합격/불합격 대신 정량적 지표로 모델의 품질을 측정한다. 실러버스가 사용하는 정식 명칭은 "기계학습 기능적 성능 측정지표(ML Functional Performance Metrics)"다. "기능적"이라는 단어가 붙은 이유는 수행 효율성(처리 속도·메모리 등 비기능적 특성)과 구분하기 위함이다.

지표의 종류는 ML 문제 유형에 따라 달라진다 분류(Classification)·회귀(Regression)·군집화(Clustering)는 각각 다른 지표를 쓴다. 시험에서는 "이 시나리오에 어울리는 지표는?"을 자주 묻는다.

혼동 행렬 (Confusion Matrix)

분류 문제에서 모델의 예측 결과를 정리하는 2×2 표가 혼동 행렬이다. 시험에 직접 출제되는 핵심 개념이므로 표 모양·기호 위치·계산 공식을 완전히 외워야 한다.

PositiveNegative
예측값
(Predicted)		PositiveTP
True Positive		FP
False Positive
NegativeFN
False Negative		TN
True Negative

네 가지 영역의 의미

  • True Positive (TP) — 실제 양성을 양성이라고 맞게 예측. 진짜 양성.
  • True Negative (TN) — 실제 음성을 음성이라고 맞게 예측. 진짜 음성.
  • False Positive (FP) — 실제 음성을 양성이라고 잘못 예측. 1종 오류(Type I Error). "있다고 헛소리".
  • False Negative (FN) — 실제 양성을 음성이라고 잘못 예측. 2종 오류(Type II Error). "놓침".
True/False는 "예측이 맞았나", Positive/Negative는 "예측이 무엇이었나" T/F는 정답 여부, P/N은 예측 결과. 이 구조를 잡고 있으면 헷갈리지 않는다. 예) FP = "예측은 P인데 그게 F(틀림)".

분류 지표 — Accuracy/Precision/Recall/F1

정확도 (Accuracy)

Accuracy = (TP + TN) / (TP + TN + FP + FN) × 100%

모든 예측 중 맞춘 비율이다. 직관적이지만 불균형 데이터(Imbalanced Data)에서는 함정이 있다.

예) 암 진단에서 환자 1%, 정상 99%인 경우 모두 "정상"이라고 예측하는 모델도 정확도는 99%다. 이런 경우 정확도는 무의미하다.

정밀도 (Precision)

Precision = TP / (TP + FP) × 100%

"양성이라고 예측한 것 중 진짜 양성의 비율"이다. 양성 예측에 대한 신뢰도를 나타낸다.

FP를 줄이는 것이 중요할 때 본다. 예) 스팸 필터에서 일반 메일을 스팸으로 분류하면(FP) 사용자가 중요 메일을 놓치므로 정밀도가 중요하다.

재현율 (Recall, 민감도 Sensitivity)

Recall = TP / (TP + FN) × 100%

"실제 양성 중 모델이 잡아낸 비율"이다. 양성을 놓치지 않는 능력이다.

FN을 줄이는 것이 중요할 때 본다. 예) 암 검진에서 실제 암 환자를 정상이라고 판단하면(FN) 치명적이므로 재현율이 중요하다.

F1-Score

F1 = 2 × (Precision × Recall) / (Precision + Recall)

정밀도와 재현율의 조화 평균(Harmonic Mean)이다. 값은 0~1이며 1에 가까울수록 좋다. 산술 평균이 아닌 조화 평균을 쓰는 이유는 둘 중 하나가 매우 낮으면 F1도 낮아져 균형을 강조하기 때문이다.

불균형 데이터에서 정확도 대신 사용하는 대표 지표다.

계산 예제 — 암 진단 모델

1000명을 검사한 결과가 다음과 같다고 가정한다.

실제값
암 (P)정상 (N)
예측암 (P)TP = 80FP = 20
정상 (N)FN = 30TN = 870
  • Accuracy = (80+870) / 1000 = 95.0%
  • Precision = 80 / (80+20) = 80.0% — 암이라고 진단한 100명 중 80명이 진짜 암
  • Recall = 80 / (80+30) = 72.7% — 실제 암 환자 110명 중 80명을 잡음
  • F1-Score = 2 × (0.80 × 0.727) / (0.80 + 0.727) ≈ 0.762 (76.2%)
정확도 95%만 보면 안 되는 이유 위 예에서 정확도는 95%로 훌륭해 보이지만 실제 암 환자 30명을 놓쳤다(FN=30, 재현율 72.7%). 의료 시나리오에서는 재현율을 우선해야 한다.

ROC 곡선과 AUC

ROC 곡선 (Receiver Operating Characteristic)

이진 분류기의 식별 임계값(threshold)을 바꿔가며 성능을 그린 그래프다. 원래 군용 레이더용으로 개발돼서 "수신자 조작 특성"이라는 이름이 붙었다.

  • x축: FPR (False Positive Rate) = FP / (TN + FP)
  • y축: TPR (True Positive Rate) = Recall = TP / (TP + FN)

곡선이 좌상단에 가까울수록 좋은 모델이다. 대각선(y=x)은 무작위 분류기와 같다.

AUC (Area Under Curve)

ROC 곡선 아래의 면적이다. 0~1 값을 가지며 클수록 좋다. 분류기가 양성·음성 클래스를 얼마나 잘 구분하는지를 단일 숫자로 요약한다.

  • AUC = 1.0 → 완벽한 분류기
  • AUC = 0.5 → 무작위 분류기 (쓸모 없음)
  • AUC < 0.5 → 거꾸로 예측하면 더 잘 맞는 모델 (반전 필요)

회귀 지표 — MSE, R-제곱

회귀 모델은 연속값을 예측하므로 "맞고 틀림"이 아닌 "얼마나 가깝게 맞췄나"를 측정한다.

평균 제곱근 오차 (MSE, Mean Square Error)

MSE = (1/n) × Σ (y_actual - y_predicted)²

실제값과 예측값 차이의 제곱 평균이다. 항상 양수이며 0에 가까울수록 좋다. 차이를 제곱하는 이유는 양/음 오차가 서로 상쇄되지 않도록 하기 위함이다.

MSE의 제곱근을 취한 RMSE(Root MSE)도 자주 사용되며, 단위가 원래 데이터와 같아져 해석이 쉽다.

R-제곱 (R-squared, 결정계수)

회귀 모델이 종속 변수의 변동을 얼마나 잘 설명하는지를 0~1로 나타낸다. 1에 가까울수록 모델이 데이터를 잘 설명한다.

  • R² = 1.0 → 모델이 데이터를 완벽히 설명
  • R² = 0.0 → 모델이 평균값보다 나을 게 없음
  • R² < 0 → 모델이 평균값보다 못함

군집화 지표 — 실루엣 계수

군집화는 비지도학습이라 정답 라벨이 없다. 그래서 "같은 군집끼리 가깝고, 다른 군집끼리 멀수록 좋다"는 원칙으로 측정한다.

  • 군집 내 측정지표 (Intra-cluster metrics) — 같은 군집 안 데이터 포인트들의 유사성. 높을수록 좋다.
  • 군집 간 측정지표 (Inter-cluster metrics) — 서로 다른 군집 사이 데이터 포인트들의 유사성. 낮을수록 좋다.
  • 실루엣 계수 (Silhouette Coefficient) — 위 둘을 결합한 단일 점수. -1 ~ +1 범위.
    • +1 → 군집이 잘 분리됨
    • 0 → 군집 경계가 모호함(무작위 군집화)
    • -1 → 군집이 잘못 할당됨

측정지표의 한계

실러버스는 ML 기능적 성능 측정지표가 다음 한계를 가진다고 명시한다.

  • 기능적 측면만 측정한다. ISO 25010의 비기능 특성(수행 효율성)이나 Ch2의 AI 품질 특성(설명 가능성·유연성·자율성)은 측정하지 않는다.
  • 지도학습은 라벨에 의존한다. 라벨이 잘못되면 지표값 자체가 의미를 잃는다(Ch4 라벨링 참조).
  • 데이터 대표성에 의존한다. 편향된 데이터로 측정하면 편향된 결론을 얻는다.
  • 모델만 평가한다. 데이터 파이프라인이나 시스템 전체는 고려하지 않는다.
  • 도구 의존적이다. 대부분 라이브러리나 프레임워크를 통해서 계산한다.

시나리오별 지표 선택 가이드

모든 지표를 동시에 최고로 만드는 모델은 존재하지 않는다. 모델의 사용 목적과 비용 구조에 따라 우선 지표를 정해야 한다.

지표적합한 시나리오대표 사례
Accuracy데이터가 대칭(균형)이고 FP·FN 비용이 비슷할 때일반 손글씨 숫자 분류 (각 숫자 비율 균등)
PrecisionFP 비용이 클 때, 양성 예측의 신뢰도가 중요할 때스팸 필터 (정상 메일이 스팸으로 가면 안 됨)
RecallFN 비용이 클 때, 양성을 절대 놓치면 안 될 때암 검진, 결함 검출, 보안 침해 탐지
F1-Score클래스가 불균형하고 Precision·Recall이 비슷하게 중요할 때드문 사기 거래 탐지, 희귀 질환 분류
ROC AUC이진 분류기의 전반적 식별 능력 비교여러 모델 후보 평가
MSE / R²회귀 문제주택 가격 예측, 수요 예측
실루엣 계수비지도 군집화의 분리 품질고객 세분화, 이상 그룹 탐지
Precision과 Recall은 보통 트레이드오프 관계 임계값을 낮추면 더 많은 양성을 잡지만(Recall↑) 잘못된 양성도 늘어난다(Precision↓). 두 지표는 함께 봐야 의미가 있고, 그 균형을 한 숫자로 본 것이 F1이다.

ML 벤치마크 스위트

새로운 데이터 세트·알고리즘·하드웨어·프레임워크가 끊임없이 등장하기 때문에 각 기술의 상대적 효능을 객관적으로 비교하려면 공통 벤치마크가 필요하다. ML 벤치마크 스위트는 다음 두 종류의 지표를 함께 제공한다.

  • 훈련 시간 — 특정 목표 품질(예: 정확도 75%)에 도달하기까지 걸리는 시간
  • 예측 시간 — 훈련된 모델이 예측을 수행하는 시간

공부 노트 — Ch5 한눈에 보기

1. 혼동 행렬 = 분류 문제의 기본. TP/FP/FN/TN 위치 외우기.
2. Accuracy = (TP+TN)/전체 → 불균형 데이터에서 함정.
3. Precision = TP/(TP+FP) → FP 비용이 클 때 (스팸 필터).
4. Recall = TP/(TP+FN) → FN 비용이 클 때 (암 검진).
5. F1 = Precision과 Recall의 조화 평균.
6. ROC = TPR vs FPR 그래프, AUC = 그 곡선 아래 면적.
7. 회귀 → MSE, R-제곱. 군집화 → 실루엣 계수(-1 ~ +1).
8. 모든 지표를 동시에 최고로 만들 수는 없다 — 시나리오 기반 선택.

연습 문제

Q1. 다음 혼동 행렬에서 정밀도(Precision)를 계산하시오. TP=40, FP=10, FN=20, TN=130.
  • 66.7%
  • 80.0%
  • 85.0%
  • 91.4%
정답: b — Precision = TP / (TP+FP) = 40 / (40+10) = 0.80 = 80%. 참고로 Recall = 40/60 = 66.7%, Accuracy = 170/200 = 85%다.
Q2. 다음 시나리오에 가장 적합한 측정지표는? "공장의 결함 부품 검출 시스템. 결함 부품을 놓쳐 출하되면 막대한 리콜 비용이 발생한다."
  • Accuracy
  • Precision
  • Recall
  • 실루엣 계수
정답: c — 결함을 놓치는 것(FN)이 가장 큰 비용이므로 재현율(Recall)을 우선해야 한다. 정밀도는 정상 부품을 결함으로 오판하는 FP 비용을 줄이는 데 쓴다.
Q3. 다음 중 ML 기능적 성능 측정지표의 한계로 적절하지 않은 것은?
  • 설명 가능성(Explainability) 같은 비기능 특성은 측정하지 못한다.
  • 지도학습의 경우 라벨 품질에 의존한다.
  • 데이터 파이프라인 전체의 품질을 평가한다.
  • 대부분 도구·라이브러리를 통해서만 계산된다.
정답: c — 실러버스 5.3절은 측정지표가 "모델에만 적용되며 데이터 파이프라인은 고려하지 않는다"고 명시한다. 나머지는 모두 정확한 한계 설명이다.
Q4. AUC = 0.5 의 의미로 가장 적절한 것은?
  • 완벽한 분류기다.
  • 무작위 추측과 같은 수준의 분류기다.
  • 거꾸로 예측하면 더 잘 맞는 분류기다.
  • 훈련이 부족하지만 추가 학습 시 개선 여지가 크다.
정답: b — AUC=0.5는 ROC 곡선이 대각선과 일치하는 경우로 무작위 추측과 동등하다. AUC<0.5는 거꾸로 예측해야 더 나은 경우다.
