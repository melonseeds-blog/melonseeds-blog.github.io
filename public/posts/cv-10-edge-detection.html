엣지란 무엇인가

엣지(edge)는 이미지에서 밝기가 급격하게 변하는 경계다. 물체의 윤곽, 그림자의 경계, 무늬의 가장자리가 모두 엣지로 나타난다. 사람은 윤곽선만 봐도 물체를 알아본다 — 그래서 엣지는 거의 모든 비전 알고리즘의 출발점이 된다.

밝기가 "급격하게 변한다"는 것을 수학으로 옮기면 미분이 된다. 어떤 위치에서 밝기 함수의 변화율이 크다면 그 지점이 엣지다. 이미지는 픽셀로 이루어진 이산 데이터이므로, 실제로는 미분 대신 이웃 픽셀의 차이로 근사한다. 이 근사 연산을 작은 행렬, 즉 커널(kernel)로 표현해 이미지에 합성곱(convolution)한다.

밝기가 급변하는 지점에서 1차 미분은 peak를, 2차 미분은 zero-crossing(부호 전환)을 만든다.

엣지 검출 방법은 크게 두 갈래다. 1차 미분을 쓰는 방법(Sobel, Scharr)은 변화율이 가장 큰 지점, 즉 미분값의 peak를 엣지로 본다. 2차 미분을 쓰는 방법(Laplacian)은 미분의 부호가 바뀌는 지점, 즉 zero-crossing을 엣지로 본다. Canny는 1차 미분을 기반으로 여러 단계를 거쳐 깔끔한 엣지 선을 뽑아내는 종합 알고리즘이다.

이 글의 모든 코드는 wrapper 없이 OpenCV를 직접 호출한다 실무 라이브러리에서는 OpenCV 함수를 직접 노출하지 않고 wrapper로 감싸지만, 이 글은 학습이 목적이므로 cv::Sobel 같은 원본 API를 그대로 보여준다. 각 함수가 무엇을 하는지 이해한 뒤 wrapper로 옮기는 편이 낫다.

1차 미분 — Sobel

Sobel 연산자는 가장 널리 쓰이는 1차 미분 엣지 검출기다. x 방향 미분과 y 방향 미분을 각각 구하는 두 개의 커널로 이루어진다. 미분만 하면 노이즈에 약하므로, Sobel 커널은 미분 방향과 수직으로 가벼운 평활화(smoothing)를 함께 한다 — 이것이 단순 차분보다 Sobel이 안정적인 이유다.

Sobel 커널

3×3 Sobel 커널은 다음과 같다. 가운데 줄(또는 열)에 가중치 2를 줘서 미분 방향의 중심을 강조하고, 나머지 줄로 평활화한다.

Sobel의 Gx는 좌우 밝기 차이를, Gy는 상하 밝기 차이를 측정한다. 두 커널은 서로 전치(transpose) 관계다.

cv::Sobel 기본 사용

cv::Sobel은 미분 차수를 인자로 받는다. dx=1, dy=0이면 x 방향 1차 미분, dx=0, dy=1이면 y 방향 1차 미분이다. 핵심은 출력 깊이를 CV_16S 또는 CV_32F로 받는 점이다 — 미분 결과는 음수가 나올 수 있기 때문이다.

#include <opencv2/opencv.hpp>

int main()
{
    cv::Mat src = cv::imread("part.jpg", cv::IMREAD_GRAYSCALE);
    if (src.empty())
    {
        std::cerr << "이미지를 열 수 없습니다." << std::endl;
        return -1;
    }

    // 노이즈 억제를 위해 먼저 가벼운 블러를 적용한다
    cv::Mat blurred;
    cv::GaussianBlur(src, blurred, cv::Size(3, 3), 0);

    // x 방향, y 방향 1차 미분 — 출력 깊이는 CV_16S (음수 보존)
    cv::Mat gradX, gradY;
    cv::Sobel(blurred, gradX, CV_16S, 1, 0, 3);  // dx=1, dy=0, ksize=3
    cv::Sobel(blurred, gradY, CV_16S, 0, 1, 3);  // dx=0, dy=1, ksize=3

    // 화면 표시·저장을 위해 절대값을 취하고 8비트로 변환한다
    cv::Mat absX, absY;
    cv::convertScaleAbs(gradX, absX);
    cv::convertScaleAbs(gradY, absY);

    // 두 방향을 합쳐 근사 엣지 강도를 만든다 (가중 합)
    cv::Mat grad;
    cv::addWeighted(absX, 0.5, absY, 0.5, 0, grad);

    cv::imshow("Sobel X", absX);
    cv::imshow("Sobel Y", absY);
    cv::imshow("Sobel combined", grad);
    cv::waitKey(0);
    return 0;
}

cv::Sobel의 인자 순서는 (src, dst, ddepth, dx, dy, ksize, scale, delta, borderType)다. ddepth는 출력 깊이, ksize는 커널 크기(1, 3, 5, 7 중 홀수)다. convertScaleAbs는 절대값을 취한 뒤 8비트로 포화 변환하므로, 음수 미분값을 화면에서 보이게 만든다.

Gradient magnitude와 direction

x 방향 미분 Gx와 y 방향 미분 Gy를 알면 그 지점의 gradient 크기와 방향을 정확히 계산할 수 있다. 크기는 엣지가 얼마나 강한지, 방향은 엣지가 어느 쪽을 향하는지를 나타낸다.

// float로 미분을 받으면 정확한 magnitude·direction 계산이 가능하다
cv::Mat gx, gy;
cv::Sobel(blurred, gx, CV_32F, 1, 0, 3);
cv::Sobel(blurred, gy, CV_32F, 0, 1, 3);

// gradient 크기: sqrt(gx^2 + gy^2)
cv::Mat magnitude;
cv::magnitude(gx, gy, magnitude);

// gradient 방향: atan2(gy, gx), 라디안 또는 도(degree)
cv::Mat direction;
cv::phase(gx, gy, direction, true);  // true = 결과를 도(0~360) 단위로

// magnitude를 0~255로 정규화해 화면에 표시한다
cv::Mat magDisplay;
cv::normalize(magnitude, magDisplay, 0, 255, cv::NORM_MINMAX, CV_8U);
cv::imshow("Gradient magnitude", magDisplay);
cv::waitKey(0);
addWeighted는 근사, magnitude는 정확 addWeighted(absX, 0.5, absY, 0.5, ...)는 빠른 근사일 뿐이다. 정확한 엣지 강도가 필요하면 cv::magnitude로 sqrt(gx² + gy²)를 계산한다. Canny 내부도 magnitude를 쓴다.

ksize와 scale 파라미터

ksize를 키우면 더 넓은 영역을 평균하므로 노이즈에 강해지지만 엣지가 두꺼워지고 위치 정밀도가 떨어진다. scale은 미분 결과에 곱하는 배율로, 미분값이 작아 화면에서 잘 안 보일 때 키운다. delta는 결과에 더하는 오프셋이다.

// ksize = -1 은 3x3 Scharr 커널을 의미한다 (다음 절 참고)
cv::Sobel(blurred, gradX, CV_16S, 1, 0, 3);   // 표준 3x3
cv::Sobel(blurred, gradX, CV_16S, 1, 0, 5);   // 5x5 — 더 부드럽고 두꺼운 엣지

// scale로 미분 결과를 증폭, delta로 밝기 오프셋 추가
cv::Sobel(blurred, gradX, CV_16S, 1, 0, 3, 2.0, 0.0);  // 결과 x2

Scharr — 더 정확한 작은 커널

3×3처럼 작은 커널에서는 Sobel의 미분 근사가 회전 대칭성이 떨어진다 — 대각선 방향 엣지에서 오차가 생긴다. Scharr 커널은 같은 3×3 크기에서 가중치를 다르게 잡아 미분 정확도를 높인 연산자다. 작은 커널로 정밀한 미분이 필요할 때 Sobel 대신 쓴다.

Scharr는 중심 가중치를 10, 모서리를 3으로 잡아 3×3에서 Sobel보다 회전 대칭성이 좋다.

OpenCV에서는 cv::Scharr 함수를 따로 제공한다. 사용법은 Sobel과 거의 같지만 커널이 3×3으로 고정이므로 ksize 인자가 없다.

cv::Mat src = cv::imread("part.jpg", cv::IMREAD_GRAYSCALE);
cv::Mat blurred;
cv::GaussianBlur(src, blurred, cv::Size(3, 3), 0);

// Scharr — ksize 인자가 없다 (항상 3x3)
cv::Mat scharrX, scharrY;
cv::Scharr(blurred, scharrX, CV_16S, 1, 0);  // x 방향
cv::Scharr(blurred, scharrY, CV_16S, 0, 1);  // y 방향

cv::Mat absX, absY, grad;
cv::convertScaleAbs(scharrX, absX);
cv::convertScaleAbs(scharrY, absY);
cv::addWeighted(absX, 0.5, absY, 0.5, 0, grad);

cv::imshow("Scharr combined", grad);
cv::waitKey(0);

// cv::Sobel에 ksize = cv::FILTER_SCHARR(-1)을 줘도 같은 결과다
cv::Sobel(blurred, scharrX, CV_16S, 1, 0, cv::FILTER_SCHARR);
Sobel과 Scharr는 언제 갈리는가 커널을 3×3보다 키울 수 있다면 Sobel로 충분하다. 하지만 3×3 크기를 유지하면서 미분 정밀도가 중요한 경우 — 예를 들어 정밀한 gradient 방향이 필요한 특징 추출 — 에는 Scharr가 유리하다. 산업 검사의 서브픽셀 엣지 추출에서도 Scharr 기반 gradient가 자주 쓰인다.

2차 미분 — Laplacian

Laplacian은 2차 미분 기반 엣지 검출기다. 1차 미분이 엣지에서 peak를 만든다면, 2차 미분은 엣지에서 부호가 바뀌는 zero-crossing을 만든다. Laplacian은 x·y 두 방향의 2차 미분을 더한 값으로, 방향에 무관한 단일 결과를 낸다 — Sobel처럼 x/y를 따로 구하지 않아도 된다.

Laplacian 커널은 중심과 이웃의 밝기 차이를 한 번에 측정한다. 4-이웃 합에서 중심값의 4배를 뺀다.

가장 중요한 특징은 노이즈에 매우 민감하다는 점이다. 2차 미분은 작은 밝기 흔들림도 크게 증폭하기 때문이다. 그래서 Laplacian은 거의 항상 가우시안 블러를 먼저 적용한 뒤 쓴다 — 이 조합을 LoG(Laplacian of Gaussian)라고 부른다.

cv::Mat src = cv::imread("part.jpg", cv::IMREAD_GRAYSCALE);

// Laplacian은 노이즈에 민감하므로 블러가 사실상 필수다
cv::Mat blurred;
cv::GaussianBlur(src, blurred, cv::Size(3, 3), 0);

// 2차 미분 — 출력 깊이는 반드시 CV_16S 또는 CV_32F
cv::Mat lap;
cv::Laplacian(blurred, lap, CV_16S, 3);  // ksize = 3

// 음수를 포함하므로 절대값 후 8비트 변환
cv::Mat absLap;
cv::convertScaleAbs(lap, absLap);

cv::imshow("Laplacian", absLap);
cv::waitKey(0);

cv::Laplacian의 인자는 (src, dst, ddepth, ksize, scale, delta, borderType)다. ksize=1이면 위 그림의 기본 3×3 커널을, ksize=3 이상이면 Sobel 기반의 더 큰 2차 미분 커널을 쓴다.

convertScaleAbs는 zero-crossing 정보를 버린다 convertScaleAbs는 절대값을 취하므로 부호 정보가 사라진다 — 즉 진짜 엣지 위치인 zero-crossing을 찾을 수 없게 된다. 정밀한 엣지 위치가 필요하면 CV_32F 결과에서 직접 부호가 +에서 -로(또는 그 반대) 바뀌는 픽셀을 찾아야 한다. 화면 표시용으로만 convertScaleAbs를 쓴다.

Laplacian 응용 — 샤프닝

Laplacian은 엣지 검출 외에 이미지 샤프닝에도 쓰인다. 원본에서 Laplacian 결과를 빼면 엣지가 강조되어 또렷한 이미지가 된다.

cv::Mat lap32;
cv::Laplacian(src, lap32, CV_32F, 1);

// 원본(float) - Laplacian = 엣지가 강조된 샤프 이미지
cv::Mat src32, sharp32;
src.convertTo(src32, CV_32F);
sharp32 = src32 - lap32;

cv::Mat sharp;
sharp32.convertTo(sharp, CV_8U);  // 0~255로 포화 변환
cv::imshow("Sharpened", sharp);
cv::waitKey(0);

Canny 엣지 검출

Canny는 1986년 John Canny가 제안한 엣지 검출 알고리즘으로, 지금도 가장 널리 쓰이는 표준이다. Sobel·Laplacian이 미분 결과를 그대로 내놓는 것과 달리, Canny는 얇고 연결된 깔끔한 엣지 선을 결과로 준다. 이를 위해 4단계를 거친다.

Canny 엣지 검출의 4단계 파이프라인. 각 단계가 순서대로 엣지를 정제한다.

4단계 상세

① 가우시안 블러 — 미분은 노이즈를 증폭하므로 먼저 가우시안 블러로 잡티를 제거한다. cv::Canny는 내부에서 Sobel을 쓰지만 블러는 자동으로 하지 않으므로, 호출 전에 직접 블러하는 것이 권장된다.

② Gradient 계산 — Sobel로 x·y 미분을 구하고 gradient의 크기와 방향을 계산한다. 방향은 보통 0°, 45°, 90°, 135° 네 방향으로 양자화한다.

③ 비최대 억제(Non-Maximum Suppression) — gradient 방향을 따라 이웃 픽셀과 비교해, 자신이 그 방향에서 가장 크지 않으면 0으로 만든다. 이 단계로 두꺼운 엣지가 1픽셀 폭의 얇은 선으로 정리된다.

④ 이중 임계값 + hysteresis — 높은 임계값(threshold2)보다 큰 픽셀은 확실한 엣지, 낮은 임계값(threshold1)보다 작은 픽셀은 버린다. 그 사이의 약한 픽셀은 확실한 엣지와 연결되어 있을 때만 엣지로 살린다. 이 연결 추적이 hysteresis다 — 끊긴 엣지를 이어주고 고립된 잡음 점을 제거한다.

cv::Canny 사용

#include <opencv2/opencv.hpp>

int main()
{
    cv::Mat src = cv::imread("part.jpg", cv::IMREAD_GRAYSCALE);
    if (src.empty())
    {
        std::cerr << "이미지를 열 수 없습니다." << std::endl;
        return -1;
    }

    // ① 전처리 — 가우시안 블러로 노이즈를 줄인다
    cv::Mat blurred;
    cv::GaussianBlur(src, blurred, cv::Size(5, 5), 1.4);

    // ②~④ Canny가 gradient 계산·NMS·hysteresis를 한 번에 수행한다
    cv::Mat edges;
    double threshold1 = 50.0;   // 낮은 임계값
    double threshold2 = 150.0;  // 높은 임계값 (보통 threshold1의 2~3배)
    cv::Canny(blurred, edges, threshold1, threshold2);

    // 결과는 CV_8UC1 — 엣지는 255(흰색), 나머지는 0(검정)
    std::cout << "엣지 픽셀 수: " << cv::countNonZero(edges) << std::endl;

    cv::imshow("Canny edges", edges);
    cv::waitKey(0);
    return 0;
}
실행 결과 (콘솔)
엣지 픽셀 수: 48213

cv::Canny의 출력은 항상 CV_8UC1 바이너리 이미지다 — 엣지는 255, 배경은 0. Sobel·Laplacian처럼 convertScaleAbs로 후처리할 필요가 없다. 입력은 8비트 단일 채널 이미지를 받는다.

Canny 파라미터 튜닝

Canny 결과의 품질은 파라미터에 크게 좌우된다. 핵심은 두 임계값과 apertureSize, L2gradient다.

파라미터역할권장값 / 효과
threshold1낮은 임계값 — 약한 엣지 후보의 하한낮추면 엣지가 늘어남(노이즈 포함)
threshold2높은 임계값 — 확실한 엣지의 기준높이면 강한 엣지만 남음
apertureSize내부 Sobel 커널 크기3, 5, 7 (기본 3)
L2gradientgradient 크기 계산 방식true면 정확한 L2, false면 빠른 L1 근사

threshold1 : threshold2 비율

Canny 논문과 OpenCV 공식 문서는 두 임계값의 비를 1:2 ~ 1:3으로 잡기를 권한다. 비율이 너무 가까우면 hysteresis가 제 역할을 못 하고, 너무 멀면 약한 엣지가 과하게 살아난다.

// 1:2 비율 — 일반적인 출발점
cv::Canny(blurred, edges, 50, 100);

// 1:3 비율 — 강한 엣지 위주로 깔끔하게
cv::Canny(blurred, edges, 50, 150);

// 너무 낮은 임계값 — 노이즈가 엣지로 잡힘 (피할 것)
cv::Canny(blurred, edges, 10, 30);

이미지 통계 기반 자동 임계값

임계값을 손으로 맞추기 어려우면 이미지의 밝기 중앙값(median)을 기준으로 자동 계산하는 방법이 자주 쓰인다.

// 밝기 중앙값을 구한다
std::vector<uchar> pixels;
blurred.reshape(1, 1).copyTo(pixels);
std::nth_element(pixels.begin(), pixels.begin() + pixels.size() / 2, pixels.end());
double median = pixels[pixels.size() / 2];

// 중앙값 기준 ±33% 범위로 임계값을 잡는다
const double kSigma = 0.33;
double lower = std::max(0.0,   (1.0 - kSigma) * median);
double upper = std::min(255.0, (1.0 + kSigma) * median);

cv::Mat edges;
cv::Canny(blurred, edges, lower, upper);

apertureSize와 L2gradient

apertureSize는 Canny 내부 Sobel의 커널 크기다. 키우면 더 부드러운 gradient를 쓰지만 엣지 위치 정밀도가 떨어진다. L2gradient=true는 gradient 크기를 sqrt(Gx² + Gy²)로 정확히 계산하고, false는 |Gx| + |Gy|로 빠르게 근사한다. 정밀도가 중요한 산업 검사에서는 true를 쓴다.

// apertureSize = 3 (기본), L2gradient = true (정확한 크기 계산)
cv::Canny(blurred, edges, 50, 150, 3, true);

// apertureSize = 5 — 더 부드럽지만 엣지 위치는 덜 정밀
cv::Canny(blurred, edges, 50, 150, 5, true);

// gx, gy를 미리 계산해 Canny에 직접 넘기는 오버로드도 있다
cv::Mat gx, gy;
cv::Sobel(blurred, gx, CV_16S, 1, 0, 3);
cv::Sobel(blurred, gy, CV_16S, 0, 1, 3);
cv::Canny(gx, gy, edges, 50, 150, true);
트랙바로 임계값을 실시간 조정하면 빠르다 cv::createTrackbar로 threshold1·threshold2 슬라이더를 만들고 콜백에서 cv::Canny를 다시 호출하면, 이미지를 보면서 최적 임계값을 즉시 찾을 수 있다. 검사 대상이 정해진 산업 라인에서는 이렇게 찾은 값을 고정해 쓴다.

엣지 검출 전 전처리

모든 엣지 검출기는 미분에 기반한다. 그리고 미분은 본질적으로 고주파 성분을 증폭한다 — 진짜 엣지뿐 아니라 노이즈도 함께 키운다. 그래서 엣지 검출 전 노이즈 제거는 선택이 아니라 거의 필수다.

블러 없이 미분하면 노이즈가 무수한 가짜 엣지를 만든다. 블러는 진짜 엣지만 남긴다.

전처리에는 보통 가우시안 블러를 쓴다. 노이즈의 종류에 따라 선택이 달라진다.

cv::Mat src = cv::imread("part.jpg", cv::IMREAD_GRAYSCALE);
cv::Mat blurred;

// 일반적인 가우시안 노이즈 — 가우시안 블러
cv::GaussianBlur(src, blurred, cv::Size(5, 5), 1.4);

// 소금-후추 노이즈 — 미디언 블러가 더 효과적
cv::medianBlur(src, blurred, 5);

// 엣지를 살리면서 노이즈만 줄이고 싶을 때 — 양방향 필터
cv::bilateralFilter(src, blurred, 9, 75, 75);

// 전처리한 이미지로 엣지 검출
cv::Mat edges;
cv::Canny(blurred, edges, 50, 150);
블러가 과하면 엣지 자체가 뭉개진다 노이즈를 없애려고 커널을 너무 키우면 진짜 엣지의 위치가 흐려지고 약한 엣지가 사라진다. 노이즈를 잡을 만큼만 최소로 블러하는 것이 원칙이다. 엣지를 보존하면서 노이즈만 줄여야 한다면 bilateralFilter가 답이지만 연산 비용이 크다.

검출 방법 비교

세 가지 대표 방법은 출력 형태와 강건성, 용도가 다르다. 상황에 맞게 고른다.

실무 선택 기준 깔끔한 윤곽선 한 줄이 필요하면 Canny. gradient의 크기·방향 자체를 다음 단계에서 쓰려면 Sobel/Scharr. 작은 점·얼룩을 찾거나 이미지를 또렷하게 만들려면 Laplacian. Canny도 내부적으로는 Sobel을 쓰므로, Canny는 Sobel의 상위 호환에 가깝다.

산업 검사 관점

산업 비전에서 엣지 검출은 그 자체가 목적인 경우는 드물다. 대부분 치수 측정이나 윤곽 추출의 출발점으로 쓰인다.

예를 들어 부품의 폭을 재려면, 먼저 엣지로 부품의 양쪽 경계를 찾고 그 사이 거리를 픽셀 단위로 측정한 뒤 캘리브레이션 값을 곱해 실제 치수로 환산한다. Canny로 윤곽을 뽑아 cv::findContours로 닫힌 외곽선을 만든 다음 면적·둘레·바운딩 박스를 계산하는 흐름도 흔하다.

// 엣지 → 윤곽선 → 형상 측정의 기본 흐름
cv::Mat src = cv::imread("part.jpg", cv::IMREAD_GRAYSCALE);
cv::Mat blurred, edges;
cv::GaussianBlur(src, blurred, cv::Size(5, 5), 1.4);
cv::Canny(blurred, edges, 50, 150);

// 엣지 이미지에서 닫힌 윤곽선을 추출한다
std::vector<std::vector<cv::Point>> contours;
cv::findContours(edges, contours, cv::RETR_EXTERNAL, cv::CHAIN_APPROX_SIMPLE);

for (const auto& contour : contours)
{
    double area = cv::contourArea(contour);
    if (area < 100.0)  // 너무 작은 윤곽은 노이즈로 보고 건너뛴다
        continue;

    cv::Rect box = cv::boundingRect(contour);
    std::cout << "부품 폭=" << box.width
              << "px, 높이=" << box.height << "px"
              << ", 면적=" << area << std::endl;
}
서브픽셀 엣지는 후속 글에서 다룬다 이 글의 Canny는 픽셀 단위 엣지다. 정밀 측정에서는 1픽셀보다 작은 단위로 엣지 위치를 추정하는 서브픽셀 엣지가 필요하다 — gradient 프로파일을 곡선으로 피팅해 peak의 정확한 위치를 찾는 방식이다. 별도 글에서 자세히 다룬다.
산업 라인에서는 ROI를 먼저 좁힌다 검사 대상의 위치가 대체로 고정되어 있다면, 전체 이미지에 엣지 검출을 돌리지 말고 관심 영역(ROI)만 잘라 처리한다. 연산량이 줄고 배경 노이즈가 엣지로 잡히는 일도 막을 수 있다.

흔한 함정

엣지 검출에서 거의 모두가 한 번씩 밟는 함정들이다.

8비트로 미분을 받으면 음수가 잘린다

미분 결과는 음수가 나올 수 있다 — CV_8U로 받으면 안 된다 밝은 곳에서 어두운 곳으로 가는 엣지는 미분값이 음수다. 출력 깊이를 CV_8U로 주면 음수가 모두 0으로 잘려 한쪽 방향 엣지가 통째로 사라진다. 반드시 CV_16S나 CV_32F로 받은 뒤 convertScaleAbs로 변환한다. 
// 나쁨 — CV_8U로 받으면 음수 미분값이 0으로 잘린다
cv::Mat badGrad;
cv::Sobel(blurred, badGrad, CV_8U, 1, 0, 3);  // 한쪽 방향 엣지 손실!

// 좋음 — CV_16S로 받아 음수를 보존한 뒤 절대값 변환
cv::Mat grad16, gradDisplay;
cv::Sobel(blurred, grad16, CV_16S, 1, 0, 3);
cv::convertScaleAbs(grad16, gradDisplay);     // 음수까지 살아남음

노이즈 전처리 생략

블러 없이 곧장 미분하면 노이즈가 가짜 엣지를 무수히 만든다. 특히 Laplacian과 Canny는 전처리 없이는 거의 쓸 수 없다.

// 나쁨 — 원본을 바로 Canny에 넣으면 노이즈가 엣지로 잡힌다
cv::Mat edges;
cv::Canny(src, edges, 50, 150);

// 좋음 — 가우시안 블러로 전처리한 뒤 검출
cv::Mat blurred;
cv::GaussianBlur(src, blurred, cv::Size(5, 5), 1.4);
cv::Canny(blurred, edges, 50, 150);

Canny 임계값 부적절

임계값이 맞지 않으면 엣지가 끊기거나 노이즈가 넘친다 threshold2가 너무 높으면 약한 진짜 엣지가 끊어진 점선처럼 나오고, threshold1이 너무 낮으면 노이즈가 엣지로 살아난다. 두 값의 비를 1:2~1:3으로 유지하고, 이미지 통계나 트랙바로 적절한 절대값을 찾는다. 
// 나쁨 — 임계값이 너무 높아 엣지가 끊어진다
cv::Canny(blurred, edges, 150, 400);

// 나쁨 — 임계값이 너무 낮아 노이즈가 엣지로 잡힌다
cv::Canny(blurred, edges, 5, 15);

// 좋음 — 1:3 비율의 적절한 범위
cv::Canny(blurred, edges, 50, 150);

미분 결과를 변환 없이 imshow

CV_16S나 CV_32F 미분 결과를 그대로 imshow에 넘기면 화면이 거의 검정이거나 깨져 보인다. imshow는 float를 0~1로, 정수는 타입 범위로 해석하기 때문이다. 표시 전에 반드시 8비트로 변환한다.

cv::Mat grad16;
cv::Sobel(blurred, grad16, CV_16S, 1, 0, 3);

// 나쁨 — CV_16S를 그대로 표시하면 제대로 안 보인다
// cv::imshow("grad", grad16);

// 좋음 1 — 절대값 + 8비트 포화 변환
cv::Mat disp1;
cv::convertScaleAbs(grad16, disp1);
cv::imshow("grad abs", disp1);

// 좋음 2 — 음수까지 보고 싶으면 정규화로 0~255 매핑
cv::Mat disp2;
cv::normalize(grad16, disp2, 0, 255, cv::NORM_MINMAX, CV_8U);
cv::imshow("grad normalized", disp2);
cv::waitKey(0);
정리하면 미분 결과는 음수를 포함하므로 CV_16S/CV_32F로 받고, 검출 전에 블러로 노이즈를 잡고, Canny 임계값은 1:2~1:3 비율로 맞추고, 화면 표시 전에는 8비트로 변환한다. 이 네 가지가 엣지 검출 입문의 핵심 습관이다.
