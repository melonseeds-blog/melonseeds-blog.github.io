Ch4. ML 데이터 (Q15 ~ Q16)

Q15Ch4 ML 데이터AI-4.4.1 (K2)
'DataSure'는 기계학습(ML) 모델 품질 개선을 위한 제품을 개발하는 스타트업 회사다. DataSure는 데이터가 올바로 라벨링됐는지 확인함으로써 이런 개선이 이뤄진다고 주장한다. 다음 중 이 제품을 사용해 예방할 수 가장 적절한 결함은?
  • A모델에 보안 취약성이 있을 것이다.
  • B모델의 정확도가 떨어질 것이다.
  • C모델이 의도한 기능을 만족하지 못할 것이다.
  • D모델이 편향된 결과를 도출할 것이다.
정답: B

라벨이 잘못된 데이터로 학습한 ML 모델은 정확도가 떨어진다. 라벨 정확성을 보장하는 도구의 일차적 가치는 정확도 향상이다.
a) 보안 취약성은 데이터 프라이버시·보안 영역이지 라벨링 품질과 직접 관련이 없다.
c) 목적 부합성은 데이터의 정확성·공정성에서 비롯되는데, 이는 라벨링과는 다른 결함이다.
d) 편향은 라벨 오류보다는 불균형·미완성·중복 데이터에서 주로 발생한다.

a) 크라우드소싱은 다수의 사람을 활용한다.
c) AI 도구를 사용한 라벨링이 아니다.
d) 외부 위탁이 아니다.

Ch5. ML 기능적 성능 측정지표 (Q17 ~ Q19)

Q17Ch5 ML 성능 지표AI-5.1.1 (K3)
어느 이미지 분류에 대한 혼동 매트릭스(confusion matrix)가 다음과 같을 때, 이 분류기의 정밀도를 표현한 식은?
Positive (실제값)Negative (실제값)
Positive (예측값)78 (TP)22 (FP)
Negative (예측값)6 (FN)14 (TN)
  • A20 / 120 × 100
  • B78 / 120 × 100
  • C78 / 100 × 100
  • D22 / 100 × 100
정답: C

정밀도(Precision) = TP / (TP + FP) = 78 / (78 + 22) = 78 / 100 이다. 백분율로 표현하면 78%다.
정밀도는 "모델이 Positive라고 예측한 것 중 실제로 Positive인 비율"이다. 재현율(Recall) = TP/(TP+FN) = 78/84와 헷갈리지 않는다.

참조: 실러버스 5.1 / LO AI-5.1.1 (K3)

  • AR-제곱 (R-squared)

  • D거짓 양성 (False Positives)

'필요한 전기량'은 연속값이므로 회귀(regression) 문제다. 회귀 모델의 품질은 R-제곱, MSE, RMSE 같은 지표로 측정한다.
b)·c)·d) 모두 분류 문제용 지표라서 회귀 모델 평가에는 부적합하다.

Q19Ch5 ML 성능 지표AI-5.4.1 (K4)
'KnowYourPet'은 반려 동물이 배고픈지 여부를 판단하기 위해 기계학습(ML)을 활용하는 앱이다. 훈련 데이터에 반영된 바와 같이 대부분의 시간에 강아지는 배가 고프지 않을 가능성이 높다고 판단한다. 강아지가 배가 고프다고 잘못 판단하는 경우 개는 과식을 하게 되고 심각한 건강 문제로 이어질 수 있다. 다음 중 테스트 중인 모델의 적합성 판단을 위해 사용해야 할 지표는?
  • A정확도 (Accuracy)
  • B정밀도 (Precision)
  • C재현율 (Recall)
  • DF1-점수 (F1-score)

'배고프다'를 Positive라 보면, 거짓 양성(실제로는 배고프지 않은데 배고프다고 판단)이 강아지 건강에 치명적이다. 거짓 양성 비용이 클 때는 정밀도(Precision) = TP/(TP+FP)를 사용해야 한다.
a) 클래스 불균형('배고프지 않음' 우세) 상황에서 정확도는 신뢰할 수 없다.
c) 재현율은 Positive를 놓치면 안 될 때 유용하지만, 이 경우는 거짓 Positive가 더 위험하다.
d) F1은 정밀도·재현율이 비슷한 비중일 때 적합한데, 여기서는 정밀도가 훨씬 중요하다.

Ch6. 신경망과 테스팅 (Q20 ~ Q21)

Q20Ch6 신경망AI-6.1.1 (K2)
다음 중 심층 신경망(Deep Neural Net)을 가장 잘 설명한 것은?
  • A가장 낮은(가장 깊은) 뉴런이 대부분의 결정을 내리는 뉴런의 계층적 구조로 이루어진다.
  • B각 뉴런은 관련 편향성을 가지고 각 연결은 관련 가중치를 가지는 연결된 뉴런들로 이루어진다.
  • C입력과 출력층을 제외한 각 층이 서로 연결된 다수의 층으로 이루어지며, 오류는 네트워크를 통해 역방향으로 전파된다.
  • D뉴런의 층으로 구성되며, 각 층은 같은 층의 다른 뉴런을 기반으로 활성화 값을 생성한다.
정답: B

신경망은 연결된 뉴런으로 구성되고, 각 뉴런에는 편향값이, 각 연결에는 가중치가 할당된다. 이 값들로 활성화 값을 계산한다.
a) 신경망은 '깊은 뉴런이 결정한다'는 계층 구조가 아니다.
c) 신경망 층들은 '서로'가 아니라 다음 층에만 연결된다.
d) 활성화 값은 같은 층이 아니라 이전 층의 뉴런을 기반으로 계산된다.

참조: 실러버스 6.1 / LO AI-6.1.1 (K2)
Q21Ch6 신경망AI-6.2.1 (K2)
다음 중 신경망(neural network)의 테스트 커버리지 측정에 대해 가장 정확하게 설명한 것은?
  • A값 변경 커버리지는 신경망의 전체 출력에 영향을 미치는 개별 뉴런을 기초로 한다.
  • B임계값 커버리지는 0과 1 사이의 사전 설정값보다 큰 활성화값을 출력하는 뉴런을 기초로 한다.
  • C뉴런 커버리지는 테스트 중에 언제든 활성화되는 뉴런의 비율을 측정한 것이다.
  • D부호 변경 커버리지는 양수, 음수 및 0 활성화값 모두를 출력하는 뉴런의 커버리지를 측정한다.

임계값 커버리지(threshold coverage)는 테스트 도중 미리 설정한 임계값(예: 0.7)보다 큰 활성화값을 출력하는 뉴런의 비율을 측정한다.
a) 값 변경 커버리지는 활성화값의 변화량 기반이다.
c) 뉴런 커버리지는 0보다 큰 활성화값으로 정의된다.
d) 부호 변경 커버리지는 0이 아닌 양수·음수 활성화로 활성된 뉴런의 비율이다.

b) 윤리 문제이지 정확성 문제가 아니다.
c) 명백히 틀린 진술이다.

Q25Ch7 AI 테스팅 개요AI-7.7.1 (K4) · 복수 정답
기계학습(ML) 기반 통행료 부과 솔루션은 카메라로 촬영한 이미지로 들어오는 자동차 유형을 판단한다. 여러 유형의 카메라가 있고 솔루션 제공업체는 다양한 해상도의 카메라를 사용할 수 있다고 한다. 모델을 훈련하고 결과를 예측하기 위해 320×480 픽셀 크기의 jpeg 형식의 이미지가 필요하다. 모델은 원하는 높은 수준의 정확도로 차량 유형을 분류할 수 있어야 하며 취약성 테스트도 진행해야 한다. 각 통행요금소는 다른 시스템과 연결되지 않은 자신들만의 완성된 시스템을 가질 것이다. 다음 중 위의 시스템 테스팅을 위해 선택할 테스팅 유형으로 가장 적절한 것은? (두 개를 고르시오)
  • A컨셉 드리프트 테스팅
  • B적대적 테스팅 (Adversarial testing)
  • C확장성 테스팅 (Scalability testing)
  • D공정성 테스팅 (Fairness testing)
  • E데이터 파이프라인 테스팅 (Data pipeline testing)
정답: B, E

b) 정답 — "취약성 테스트"가 요구사항에 명시돼 있으므로 적대적 테스팅이 필요하다.
e) 정답 — 다양한 해상도·형식의 이미지를 320×480 jpeg로 변환해 모델에 넣어야 하므로 데이터 파이프라인이 제대로 동작하는지 검증해야 한다.
a) 컨셉 드리프트는 배포 후 테스트 영역이다.
c) 통행요금소는 서로 독립적이라 확장성과 무관하다.
d) 차량 유형 판별에는 공정성 이슈가 없다.

Ch8. AI 특유 품질 테스팅 (Q26 ~ Q28)
