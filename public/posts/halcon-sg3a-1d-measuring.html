1D 측정이란 무엇인가

HALCON의 1D Measuring은 직선 또는 원호 형태의 작은 ROI를 따라 1차원 gray value profile을 만든 뒤, 그 profile 위에서 엣지 위치를 subpixel 정밀도로 찾는 방식이다. 2D 엣지 검출처럼 contour 전체를 찾는 대신, profile line과 엣지의 교차점만 빠르게 추출한다.

핵심 아이디어

측정하려는 엣지가 ROI의 진행 방향에 거의 수직이라는 가정하에, ROI 폭 방향으로 픽셀을 평균해서 1D profile을 만든다. 평균을 취하기 때문에 노이즈는 줄고 엣지 신호는 살아난다.

언제 1D 측정을 쓰는가 폭, 간격, 위치 같은 1차원 수치만 필요하고 엣지가 비교적 직선·수직 조건을 만족할 때, 1D 측정은 2D 엣지 추출보다 빠르고 안정적이다.

1D 엣지 추출 과정

HALCON이 1D profile에서 엣지를 찾는 절차는 다음과 같다.

  1. ROI 안에 profile line을 따라 등간격으로 lines of projection을 수직 방향으로 구성한다.
  2. 각 line of projection에서 픽셀 gray value의 평균을 계산해 profile을 만든다.
  3. profile을 Gaussian 필터로 smoothing한다 (Sigma 파라미터).
  4. smoothed profile의 1차 미분을 계산한다.
  5. 1차 미분의 local extrema가 엣지 후보가 되고, 그중 절댓값이 Threshold 이상인 것만 엣지로 채택된다.
  6. 각 엣지의 profile line과의 교차점을 subpixel 위치로 반환한다.
ROI에서 profile을 만들고, 1차 미분의 extrema로 엣지를 찾는 흐름

Interpolation 모드

profile line이 수평·수직이 아니면 픽셀 사이 값을 보간해야 한다. measure object를 만들 때 Interpolation 파라미터로 지정한다.

모드속도정확도비고
nearest_neighbor가장 빠름낮음가까운 픽셀 값을 그대로 사용
bilinear중간중간실무 기본값으로 무난
bicubic느림가장 높음정밀 측정에 사용. ROI 주변 2픽셀 margin 필요

측정 ROI 설계

measure object는 두 가지 형태로 만든다.

직선 ROI — gen_measure_rectangle2

gen_measure_rectangle2 (Row, Column, Phi, Length1, Length2,
                        Width, Height, Interpolation, MeasureHandle)
  • Row, Column — ROI 중심
  • Phi — 회전 각도 (라디안)
  • Length1 — profile line 방향의 반 길이
  • Length2 — ROI 폭 방향의 반 길이
  • Width, Height — 적용 대상 이미지의 크기

원호 ROI — gen_measure_arc

gen_measure_arc (CenterRow, CenterCol, Radius, AngleStart,
                 AngleExtent, AnnulusRadius, Width, Height,
                 Interpolation, MeasureHandle)

원형 부품의 cog 폭이나 hole 가장자리를 따라 측정할 때 쓴다. 결과 거리는 기본적으로 arc length로 반환된다. 필요하면 두 엣지 좌표로 linear distance를 별도로 계산하거나, arc / radius로 angular distance를 얻는다.

ROI 폭 선택 가이드

ROI 폭은 노이즈 감소와 엣지 방향 가정 사이의 trade-off다.

  • 엣지가 profile line과 거의 수직이라면 ROI 폭을 크게 잡아 평균 효과로 노이즈를 줄인다.
  • 엣지가 기울어 있거나 휘어 있다면 ROI 폭을 좁혀야 한다. 그렇지 않으면 평균 과정에서 엣지가 blur 처리되어 위치 정확도가 떨어진다.
경사 엣지 주의 profile line의 수직 방향에서 엣지가 30도 이상 기울면, ROI 폭을 크게 줄이지 않는 한 profile 자체가 부드러워져 엣지가 사라지거나 위치 오차가 커진다.

네 가지 측정 함수

같은 measure object handle을 가지고 목적에 따라 네 가지 측정 함수를 선택해 호출한다.

함수반환용도
measure_pos개별 엣지 위치, amplitude, 간 거리한쪽 면 위치, 다중 엣지 사이 간격
measure_pairs엣지 쌍의 두 위치, IntraDistance, InterDistance두 엣지로 둘러싸인 객체 폭과 간격
measure_thresh특정 gray value를 갖는 subpixel 위치조명이 안정된 환경에서 임계값 기반 위치 추출
measure_projectionraw gray value profile (tuple)사용자 정의 1D 분석. pitch 라인 등 특수 패턴
measure_thresh의 한계 measure_thresh는 절대 gray value를 기준으로 위치를 잡기 때문에, 조명이 살짝 변해도 결과가 같이 흔들린다. 조명 안정성이 보장될 때만 의미가 있다.

핵심 파라미터

Sigma — Gaussian smoothing 강도

profile을 부드럽게 만드는 정도를 결정한다.

  • 작은 sigma — 엣지 위치는 민감하지만 노이즈에 흔들린다.
  • 큰 sigma — 노이즈가 줄지만 엣지 위치가 blur되고 인접 엣지가 합쳐질 수 있다.
  • 실무에서는 1.0 전후를 시작점으로 잡고 profile 모양을 보며 조정한다.

Threshold — 미분 진폭 기준

smoothed profile 1차 미분의 절댓값이 이 값 이상인 extrema만 엣지로 채택한다. 너무 낮으면 노이즈가 엣지로 잡히고, 너무 높으면 약한 엣지가 누락된다.

Transition — 엣지 방향성

값의미
positivedark → bright 전이만 채택
negativebright → dark 전이만 채택
all양방향 모두 채택. measure_pairs에서는 첫 엣지 방향으로 페어가 결정됨
*_strongest동일 방향이 연속될 때 가장 강한 엣지 하나만 유지. shadow 등 부엣지를 제거
Transition 오설정의 대표 증상 ROI 방향을 반대로 설정하면 negative와 positive가 통째로 뒤바뀐다. 측정값이 일관되게 한 쪽으로 어긋난다면 ROI 방향과 transition 조합부터 의심한다.

Select — 결과 개수 제한

first, last, all로 반환할 엣지 또는 페어를 제한한다. 검사 대상이 첫 번째 엣지뿐임이 확실하면 first로 설정해 안정성을 높인다.

엣지 페어 측정

두 엣지 사이의 폭을 측정하는 가장 흔한 경우다. pin width, hole diameter, lead gap, line width 같은 검사 항목이 모두 여기에 해당한다.

IntraDistance vs InterDistance

IntraDistance는 페어 내 두 엣지 거리, InterDistance는 인접 페어 사이의 거리

페어에서의 Transition

  • negative — 첫 엣지 negative + 둘째 엣지 positive. 즉 어두운 영역을 둘러싼 페어
  • positive — 밝은 영역을 둘러싼 페어
  • all — 첫 엣지 방향에 따라 자동 결정. 밝기가 들쭉날쭉한 객체에 유용

_strongest 모드의 가치

그림자나 반사로 같은 방향 엣지가 연달아 나타날 때, 기본 페어링은 첫 엣지(=그림자)를 선택해 페어를 잘못 만든다. negative_strongest처럼 접미사를 붙이면 같은 방향 연속 엣지 중 가장 강한 것만 남겨 페어가 정확해진다.

World 좌표 변환

1D 측정은 기본적으로 픽셀 단위 거리를 반환한다. 실제 mm나 µm 단위 치수가 필요하면 calibration이 필수다.

일반적인 흐름은 다음과 같다.

camera calibration으로 CamParam, WorldPose 획득
→ measure_pos / measure_pairs로 픽셀 좌표 추출
→ image_points_to_world_plane으로 world 좌표 변환
→ distance_pp로 물리 단위 거리 계산

예를 들어 caliper의 눈금 사이 거리를 mm로 얻는 코드의 핵심은 다음 한 줄이다.

image_points_to_world_plane (CamParam, WorldPose, RowLine, ColLine,
                              'mm', X, Y)
calibration plane 일치 WorldPose가 정의한 평면과 실제 측정 대상 평면이 일치해야 한다. 측정 대상의 Z 높이가 calibration plate와 다르면 scale 오차가 그대로 결과에 실린다. telecentric lens가 아니라면 특히 민감하다.

렌즈 왜곡이 큰 경우에는 좌표 보정이나 이미지 자체의 rectification이 추가로 필요하다. 자세한 절차는 Solution Guide III-C에서 다룬다.

ROI 정렬과 재사용

실제 라인에서는 부품 위치가 이미지마다 미세하게 바뀐다. measure ROI를 매번 같은 절대 좌표로 박아 두면 엉뚱한 위치를 측정한다. 그래서 shape matching 같은 정렬 단계가 거의 항상 앞단에 붙는다.

정렬 흐름

shape matching으로 part pose 획득
→ pose에 따라 measure ROI 파라미터 transform
→ 새 measure object 생성 또는 translate_measure 사용
→ 측정 수행
  • 위치만 변하는 경우 translate_measure로 가볍게 옮기면 된다.
  • 각도까지 바뀌면 ROI 파라미터를 변환한 뒤 measure object를 새로 만든다.

measure object 재사용

measure object 생성에는 비용이 든다. 같은 ROI를 반복 측정할 때는 매 프레임 생성하지 말고 handle을 보관해 재사용한다. 이는 SG III-A가 강조하는 실무 팁이다.

해제 잊지 말기 재사용이 끝나면 close_measure로 리소스를 해제한다. handle을 누적해 두면 장시간 검사에서 메모리 누수가 생긴다.

Fuzzy Measure Object

표준 measure object는 contrast와 transition만으로 엣지를 선택한다. ROI 안에 비슷한 강도의 엣지가 여러 개 있거나, 반사·그림자가 끼면 잘못된 엣지가 선택되기 쉽다. fuzzy measure object는 추가 feature에 대해 fuzzy membership function을 정의해 엣지 선택을 정교하게 제어한다.

사용 가능한 feature

SetType의미
contrast엣지 진폭
positionprofile 시작점으로부터 엣지 위치
position_pair페어의 위치 (중심·시작·끝 등 subtype)
size페어 폭
size_diff / size_abs_diff기대 폭과의 편차
gray페어 사이 영역의 gray value

적용 흐름

create_funct_1d_pairs (XValues, YValues, MembershipFunction)
set_fuzzy_measure (MeasureHandle, SetType, MembershipFunction)
fuzzy_measure_pairs (Image, MeasureHandle, Sigma, AmpThresh,
                     FuzzyThresh, Transition, ... )

예를 들어 switch의 pin이 약 9 픽셀 폭임을 알고 있다면 size 기반 membership function을 정의해, 반사로 생긴 가짜 엣지를 자연스럽게 배제할 수 있다. 모든 가능한 페어를 만들어 두고 membership 값으로 weighting하기 때문에, 단순 first/last 선택보다 훨씬 견고하다.

Normalized membership function

set_fuzzy_measure_norm_pair는 PairSize에 대해 정규화된 membership function을 받는다. 같은 정의로 부품 크기만 바뀐 경우 PairSize 값만 갈아끼우면 되므로, 멀티 모델 검사 시 유지보수가 쉬워진다.

부분 지식만 주면 위험 position만 지정하고 size를 지정하지 않으면, 작은 페어 둘이 합쳐진 큰 가짜 페어가 더 높은 membership을 받아 채택될 수 있다. 알고 있는 제약은 가능한 한 모두 fuzzy 함수로 넣는 편이 안전하다.

부분 ROI와 multi-channel

ROI 일부가 이미지 밖으로 나가도 이미지 안의 엣지와 그 사이 거리는 정상적으로 측정된다. 이미지 밖 영역의 profile 값은 0으로 채워진다. 또한 multi-channel 이미지를 넘기면 첫 번째 채널만 사용된다는 점도 기억해 둔다.

핵심 정리

  • 1D 측정은 ROI를 따라 만든 profile에서 엣지를 subpixel로 찾는다.
  • 엣지가 profile line에 거의 수직일 때만 가정이 성립한다.
  • 측정 함수는 measure_pos · measure_pairs · measure_thresh · measure_projection 네 가지로 구분된다.
  • Sigma · Threshold · Transition · Select가 결과 안정성을 좌우한다.
  • 엣지 페어 측정에서는 ROI 방향과 transition 조합, _strongest 활용이 핵심이다.
  • 물리 단위 치수가 필요하면 calibration과 image_points_to_world_plane이 필수다.
  • shape matching으로 ROI를 정렬하고 measure object는 재사용한다.
  • 반사·그림자·다중 엣지가 있는 환경에서는 fuzzy measure object로 선택을 정교화한다.
