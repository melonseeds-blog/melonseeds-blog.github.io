데코레이터란?

데코레이터(decorator)는 함수를 인자로 받아 새 함수를 반환하는 함수다. 원본 함수를 직접 수정하지 않고 호출 전후에 동작을 끼워 넣을 수 있다. Python은 이를 @ 문법으로 간결하게 표현한다.

다음 두 코드는 완전히 동일하다.

@deco
def f():
    pass

# 위와 정확히 같다
def f():
    pass
f = deco(f)

즉 @deco는 정의 직후 f = deco(f)를 수행하는 단순한 문법 설탕(syntactic sugar)이다. 이 점만 기억하면 데코레이터의 동작 원리가 전부 설명된다.

데코레이터의 호출 흐름 — 원본 함수가 wrapper로 감싸진 후 같은 이름에 다시 바인딩된다.

일급 함수

Python에서 함수는 일급 객체(first-class object)다. 즉 함수도 일반 값처럼 변수에 할당하고, 다른 함수의 인자로 전달하고, 반환값으로 돌려줄 수 있다. 데코레이터는 이 성질에 전적으로 의존한다.

def greet(name):
    return f"Hello, {name}"

# 1) 변수에 할당
say = greet
print(say("Alice"))         # Hello, Alice

# 2) 인자로 전달
def call_twice(fn, x):
    return fn(x), fn(x)

print(call_twice(greet, "Bob"))   # ('Hello, Bob', 'Hello, Bob')

# 3) 반환값으로 돌려줌
def make_greeter(prefix):
    def inner(name):
        return f"{prefix}, {name}"
    return inner

hi = make_greeter("Hi")
print(hi("Charlie"))        # Hi, Charlie

make_greeter가 내부 함수 inner를 반환하는 부분이 데코레이터의 핵심 패턴이다.

클로저(closure)

클로저는 내부 함수가 자신을 둘러싼 외부 함수의 지역 변수를 기억하는 메커니즘이다. 외부 함수가 종료된 뒤에도 캡처한 변수에 계속 접근할 수 있다.

def make_counter():
    count = 0
    def increment():
        nonlocal count       # 외부 변수를 쓰기 위해 필요
        count += 1
        return count
    return increment

counter = make_counter()
print(counter())   # 1
print(counter())   # 2
print(counter())   # 3

count는 make_counter가 끝난 후에도 살아 있다. increment가 count를 캡처했기 때문이다. 캡처된 변수는 함수의 __closure__ 속성으로 확인할 수 있다.

print(counter.__closure__)
# (<cell at 0x...: int object at 0x...>,)
print(counter.__closure__[0].cell_contents)   # 3
nonlocal vs global 외부 함수의 변수를 수정하려면 nonlocal이 필요하다. 모듈 전역 변수를 수정하려면 global. 단순히 읽기만 한다면 키워드 없이도 가능하다.

기본 데코레이터 작성

기본 형태

가장 단순한 데코레이터 형태는 다음과 같다.

def my_decorator(func):
    def wrapper(*args, **kwargs):
        print("호출 전")
        result = func(*args, **kwargs)
        print("호출 후")
        return result
    return wrapper

@my_decorator
def say_hello(name):
    print(f"Hello, {name}")

say_hello("Alice")
실행 결과
호출 전 Hello, Alice 호출 후

*args, **kwargs로 받는 이유는 어떤 시그니처의 함수가 들어와도 그대로 전달하기 위해서다.

실행 시간 측정

import time

def timed(func):
    def wrapper(*args, **kwargs):
        start = time.perf_counter()
        result = func(*args, **kwargs)
        elapsed = time.perf_counter() - start
        print(f"[{func.__name__}] {elapsed*1000:.2f} ms")
        return result
    return wrapper

@timed
def slow_sum(n):
    return sum(range(n))

slow_sum(1_000_000)
실행 결과
[slow_sum] 18.34 ms

로깅 데코레이터

def log_calls(func):
    def wrapper(*args, **kwargs):
        arg_str = ", ".join([repr(a) for a in args] +
                            [f"{k}={v!r}" for k, v in kwargs.items()])
        print(f"-> {func.__name__}({arg_str})")
        result = func(*args, **kwargs)
        print(f"<- {func.__name__} = {result!r}")
        return result
    return wrapper

@log_calls
def add(a, b):
    return a + b

add(3, 5)
실행 결과
-> add(3, 5) <- add = 8

functools.wraps — 메타데이터 보존

데코레이터를 그냥 작성하면 원본 함수의 __name__, __doc__이 wrapper의 것으로 바뀐다.

def deco(func):
    def wrapper(*args, **kwargs):
        return func(*args, **kwargs)
    return wrapper

@deco
def hello():
    """인사 함수."""
    pass

print(hello.__name__)   # wrapper  (원하지 않은 결과)
print(hello.__doc__)    # None

functools.wraps를 사용하면 원본 함수의 메타데이터가 그대로 유지된다.

from functools import wraps

def deco(func):
    @wraps(func)                       # 핵심
    def wrapper(*args, **kwargs):
        return func(*args, **kwargs)
    return wrapper

@deco
def hello():
    """인사 함수."""
    pass

print(hello.__name__)   # hello
print(hello.__doc__)    # 인사 함수.
@wraps는 사실상 필수다 없어도 동작은 한다. 하지만 디버깅, 로깅, 문서화 도구가 모두 __name__과 __doc__에 의존한다. help(hello)가 깨지고 스택 트레이스도 이상해진다. 데코레이터를 만들 때는 항상 @wraps(func)를 붙이자.

인자를 받는 데코레이터

@deco(times=3)처럼 데코레이터 자체에 인자를 주려면 함수가 한 겹 더 필요하다. 즉 3중 함수 구조가 된다.

from functools import wraps

def repeat(times):                     # 1단: 인자 받음
    def decorator(func):               # 2단: 함수 받음
        @wraps(func)
        def wrapper(*args, **kwargs):  # 3단: 호출 인자 받음
            result = None
            for _ in range(times):
                result = func(*args, **kwargs)
            return result
        return wrapper
    return decorator

@repeat(times=3)
def greet(name):
    print(f"Hi, {name}")

greet("Alice")
실행 결과
Hi, Alice Hi, Alice Hi, Alice

호출 흐름을 풀어 보면 다음과 같다.

greet = repeat(times=3)(greet)
# repeat(times=3) -> decorator
# decorator(greet) -> wrapper
# greet = wrapper
패턴구조사용 예
인자 없는 데코레이터def deco(func): def wrapper: ...@timed
인자 받는 데코레이터def deco(arg): def real(func): def wrapper: ...@repeat(times=3)
두 형태 모두 지원인자 유무 분기 처리@deco 또는 @deco(x=1)

클래스 데코레이터

클래스를 데코레이터로 쓰려면 __call__을 구현하면 된다. 인스턴스가 함수처럼 호출 가능해진다.

from functools import update_wrapper

class CountCalls:
    def __init__(self, func):
        self.func = func
        self.count = 0
        update_wrapper(self, func)   # wraps의 클래스 버전

    def __call__(self, *args, **kwargs):
        self.count += 1
        print(f"[{self.func.__name__}] 호출 횟수: {self.count}")
        return self.func(*args, **kwargs)

@CountCalls
def say_hi():
    print("Hi")

say_hi()
say_hi()
print(say_hi.count)   # 2
실행 결과
[say_hi] 호출 횟수: 1 Hi [say_hi] 호출 횟수: 2 Hi 2

클래스 데코레이터는 상태를 보관하기 쉽다는 장점이 있다. 호출 횟수, 캐시, 등록 목록 같은 데이터를 인스턴스 속성으로 깔끔하게 관리할 수 있다.

내장 데코레이터

Python은 클래스 작성에 자주 쓰이는 데코레이터 몇 가지를 표준으로 제공한다.

데코레이터역할첫 번째 인자
@property메서드를 속성처럼 접근self
@classmethod클래스를 받는 메서드cls
@staticmethodself/cls 없는 메서드없음
@dataclass__init__·__repr__ 자동 생성—
@functools.cached_property첫 호출 결과를 캐싱self
class Circle:
    PI = 3.14159

    def __init__(self, radius):
        self._radius = radius

    @property
    def radius(self):
        """반지름 (읽기/쓰기)."""
        return self._radius

    @radius.setter
    def radius(self, value):
        if value < 0:
            raise ValueError("음수 불가")
        self._radius = value

    @property
    def area(self):
        """면적 — 읽기 전용."""
        return Circle.PI * self._radius ** 2

    @classmethod
    def unit(cls):
        """단위 원 생성."""
        return cls(1.0)

    @staticmethod
    def is_valid_radius(r):
        return r > 0

c = Circle(5)
print(c.radius)        # 5      (메서드 호출 아님!)
print(c.area)          # 78.539...
c.radius = 10          # setter 호출
unit = Circle.unit()   # 클래스 메서드로 생성
print(Circle.is_valid_radius(-1))   # False
classmethod는 대체 생성자에 자주 쓴다 datetime.fromisoformat()처럼 다양한 입력으로부터 인스턴스를 만드는 팩토리 메서드로 활용한다. cls를 받기 때문에 상속 시 자식 클래스의 인스턴스를 자연스럽게 반환할 수 있다.

functools.lru_cache

lru_cache는 함수의 호출 결과를 인자별로 캐싱하는 데코레이터다. 같은 인자로 다시 호출되면 함수 본문을 실행하지 않고 캐시된 값을 즉시 반환한다. 재귀 함수 메모이제이션에 특히 강력하다.

from functools import lru_cache

@lru_cache(maxsize=None)
def fib(n):
    if n < 2:
        return n
    return fib(n - 1) + fib(n - 2)

print(fib(100))
# 354224848179261915075
print(fib.cache_info())
# CacheInfo(hits=98, misses=101, maxsize=None, currsize=101)

maxsize를 지정하면 가장 오래 안 쓰인 항목부터 제거(LRU 정책)된다. Python 3.9부터는 더 간결한 @functools.cache(무제한 캐시)도 추가됐다.

인자가 hashable이어야 한다 캐시 키로 인자를 그대로 사용하기 때문에 list·dict 같은 가변 객체는 인자로 받을 수 없다. tuple이나 frozenset으로 바꿔서 넘기자.

데코레이터 활용 예

인증 검사

from functools import wraps

def require_admin(func):
    @wraps(func)
    def wrapper(user, *args, **kwargs):
        if not user.get("is_admin"):
            raise PermissionError("관리자 권한 필요")
        return func(user, *args, **kwargs)
    return wrapper

@require_admin
def delete_all(user):
    print(f"{user['name']}이(가) 전체 삭제 수행")

delete_all({"name": "root", "is_admin": True})    # OK
# delete_all({"name": "guest", "is_admin": False}) # PermissionError

재시도

import time
from functools import wraps

def retry(times=3, delay=0.5, exceptions=(Exception,)):
    def decorator(func):
        @wraps(func)
        def wrapper(*args, **kwargs):
            last_exc = None
            for attempt in range(1, times + 1):
                try:
                    return func(*args, **kwargs)
                except exceptions as e:
                    last_exc = e
                    print(f"[{attempt}/{times}] 실패: {e}")
                    time.sleep(delay)
            raise last_exc
        return wrapper
    return decorator

@retry(times=3, delay=0.2, exceptions=(ConnectionError,))
def fetch():
    import random
    if random.random() < 0.7:
        raise ConnectionError("네트워크 오류")
    return "OK"

입력 검증

from functools import wraps

def validate_positive(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        for a in args:
            if isinstance(a, (int, float)) and a < 0:
                raise ValueError(f"음수 불가: {a}")
        return func(*args, **kwargs)
    return wrapper

@validate_positive
def area(width, height):
    return width * height

print(area(3, 4))     # 12
# area(-1, 4)         # ValueError

핸들러 등록

handlers = {}

def route(path):
    def decorator(func):
        handlers[path] = func
        return func               # 원본 그대로 반환 (감싸지 않음)
    return decorator

@route("/")
def home():
    return "home"

@route("/about")
def about():
    return "about"

print(handlers)
# {'/': <function home>, '/about': <function about>}

이 패턴이 Flask·FastAPI 같은 웹 프레임워크의 라우팅 데코레이터의 본질이다.

흔한 함정

@wraps 누락

앞서 다뤘듯 __name__·__doc__·__module__이 모두 wrapper의 것으로 덮인다. 로깅, 디버거, Sphinx 같은 도구가 모두 망가지므로 모든 데코레이터에 @wraps(func)를 붙이는 습관을 들이자.

스택 순서

데코레이터를 여러 개 쌓으면 아래에서 위로 적용된다.

@A
@B
@C
def f():
    pass

# 동치: f = A(B(C(f)))
# 실행 시 호출 순서: A의 wrapper -> B의 wrapper -> C의 wrapper -> 원본 f

예를 들어 캐싱과 로깅을 함께 쓸 때 순서에 따라 동작이 달라진다.

@log_calls       # 로그가 캐시 hit/miss 모두 찍힘
@lru_cache
def f(x): ...

@lru_cache       # 캐시 hit이면 로그가 안 찍힘
@log_calls
def f(x): ...

반복문 안의 클로저

for 루프 안에서 함수를 만들면서 루프 변수를 캡처하면, 모두 같은 변수를 공유하게 된다.

funcs = []
for i in range(3):
    funcs.append(lambda: i)

print([f() for f in funcs])   # [2, 2, 2]  (1, 2, 3 아님!)

# 해결: 기본 인자로 캡처 강제
funcs = []
for i in range(3):
    funcs.append(lambda i=i: i)

print([f() for f in funcs])   # [0, 1, 2]
클로저는 변수를 캡처하지, 값을 캡처하지 않는다 내부 함수는 외부 변수의 최종 상태를 본다. 루프 변수를 즉시 묶고 싶다면 기본 인자(lambda i=i: ...)나 functools.partial을 사용하자.

데코레이터 남용

데코레이터는 깔끔해 보여서 과하게 쓰기 쉽다. 다음 신호가 보이면 의심해 보자.

  • 데코레이터 5겹 이상으로 스택돼 호출 순서를 추적하기 어렵다
  • 같은 로직이 한 번만 등장하는데도 데코레이터로 추상화한다
  • 비즈니스 로직(돈 계산, 권한 처리 등)이 데코레이터에 숨어 있어 함수만 봐선 동작을 알 수 없다
"마법"이 되지 않게 하라 데코레이터는 횡단 관심사(cross-cutting concerns) — 로깅·캐싱·인증·재시도 같은 반복되는 부가 기능에 가장 잘 어울린다. 핵심 로직 자체를 데코레이터에 숨기면 가독성이 급격히 떨어진다.
