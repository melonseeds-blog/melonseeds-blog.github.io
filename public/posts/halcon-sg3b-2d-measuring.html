2D 측정이란 무엇인가

2D 측정은 평면 위에 놓인 대상에서 면적, 위치, 방향, 치수, 각도, 개수 같은 공간 정보를 추출하는 작업이다. HALCON은 이 목적에 맞춰 region 기반 분석부터 subpixel contour fitting, Metrology 모델까지 단계별로 정교해지는 도구들을 제공한다.

측정 도구 선택은 세 가지 축에서 결정된다.

  • 측정 목표 — 면적인지, 치수인지, 각도인지
  • 요구 정밀도 — pixel 단위면 충분한지, subpixel이 필요한지
  • 대상의 표현 — 균질한 region으로 보이는지, edge transition만 뚜렷한지
1D Measuring과의 관계 1D Measuring(Solution Guide III-A)은 직선이나 호에 수직한 단일 line profile을 따라 edge를 잡는 도구다. 2D Measuring은 이를 포함해 contour 전체와 도형 모델을 다룬다. 두 가이드는 형제 관계라고 보면 된다.

네 가지 기본 도구

Solution Guide III-B는 2D 측정의 도구를 크게 네 부류로 묶는다.

2.1 Region Processing

blob 분석 계열이다. threshold로 region을 추출하고 area_center, orientation_region, smallest_rectangle2, inner_circle 등으로 특성을 뽑는다. pixel-precise이고 빠르지만 outlier에 약하다.

2.2 Contour Processing

edge transition 기반이다. edges_sub_pix로 XLD contour를 만들고 select_contours_xld·segment_contours_xld로 정리한 뒤, 도형 fitting으로 정밀 parameter를 얻는다. subpixel 정밀도가 가능하고 open contour도 다룬다.

2.3 2D Metrology

측정 대상이 line·circle·ellipse·rectangle 같은 단순 도형이고 위치·크기를 대략 안다는 전제로 동작한다. 초기 도형 parameter를 모델에 넣으면 HALCON이 경계를 따라 measure region을 깔고 edge를 정밀하게 잡아 도형 parameter를 refine한다.

2.4 Geometric Operations

점·선·선분·contour·region 사이의 거리, 각도, 교점, 투영을 계산한다. distance_pp, distance_pl, distance_pc, angle_ll, intersection_lines, projection_pl 등이 여기 속한다. 앞의 세 도구로 얻은 기하 요소를 조합해 최종 치수·각도를 산출하는 마지막 단계다.

XLD Contour와 도형 Fitting

정밀 치수가 필요한 경우 가장 먼저 떠올려야 하는 흐름이다.

edges_sub_pix
→ select_contours_xld
→ segment_contours_xld ('lines_circles')
→ fit_line_contour_xld / fit_circle_contour_xld / fit_rectangle2_contour_xld
→ distance_pp / angle_ll 등으로 결과 산출

3.1 Segment 후 형상 판별

segment_contours_xld는 각 segment에 cont_approx라는 전역 속성을 붙인다. 값이 -1이면 line, 0이면 ellipse arc, 1이면 circular arc로 근사 가능하다는 뜻이다. get_contour_global_attrib_xld로 조회한 뒤 분기해 적절한 fitting을 적용한다.

3.2 도형 fitting 함수

함수 출력 parameter 주 용도
fit_line_contour_xld시작·끝점, 법선, 잔차직선도, 기준선, 평행도
fit_circle_contour_xld중심, 반경, StartPhi/EndPhihole 직경, 원형 부품, 진원도
fit_ellipse_contour_xld중심, 장·단축, 회전각타원형 부품, 기울어진 hole
fit_rectangle2_contour_xld중심, 두 half length, 방향사각형 부품의 위치·치수

모든 fitting 함수는 outlier에 견디도록 Algorithm parameter를 제공한다. 'tukey'·'huber'·'drop' 같은 robust 추정기를 선택하면 burr나 defect의 영향을 줄일 수 있다. 단순 회귀가 필요하면 'regression'을 쓴다.

Contour 기반 측정의 표준 단계

2D Metrology 모델

Metrology는 측정 객체를 model이라는 컨테이너에 모아 관리하는 방식이다. line·circle·ellipse·rectangle 등 단순 도형이 대상이고, 초기 parameter를 알고 있을 때 강하다.

4.1 기본 흐름

create_metrology_model (MetrologyHandle)
set_metrology_model_image_size (MetrologyHandle, Width, Height)

add_metrology_object_circle_measure (...)
add_metrology_object_rectangle2_measure (...)
add_metrology_object_line_measure (...)

apply_metrology_model (Image, MetrologyHandle)

get_metrology_object_result (MetrologyHandle, Index, 'all',
                             'result_type', 'all_param', Parameter)

apply_metrology_model이 실행되면 HALCON이 각 도형의 경계를 따라 measure region을 자동으로 깔고, 그 안의 edge를 잡아 도형 parameter를 refine한다. 결과는 get_metrology_object_result로 일관된 인터페이스로 조회한다.

4.2 측정 객체 추가 함수

함수 초기 parameter
add_metrology_object_circle_measure중심 (row, col), 반경
add_metrology_object_ellipse_measure중심, 회전각, 장·단축
add_metrology_object_line_measure시작·끝점
add_metrology_object_rectangle2_measure중심, 회전각, half length 두 개
add_metrology_object_generic위 도형들을 한 번에

set_metrology_object_param으로 measure region의 길이·간격·threshold·edge transition 등을 세밀하게 조정할 수 있다. 동일 모델 안에 객체 여러 개를 넣고 한 번의 apply 호출로 전부 측정한다 — 다중 치수 검사에 적합한 구조다.

4.3 결과 활용

측정에 실제로 쓰인 edge 점들은 'used_edges' 옵션으로 조회한다. 디버깅 시 시각화에 유용하다. refine된 도형은 'result_type' + 'all_param'으로 받아 공차 판정에 사용한다.

get_metrology_object_result (MetrologyHandle, 'all', 'all',
                             'used_edges', 'row', UsedRow)
get_metrology_object_result (MetrologyHandle, 'all', 'all',
                             'used_edges', 'column', UsedColumn)

5.1 1D Measuring과의 관계

1D Measuring은 사각형이나 호 안의 1차원 gray profile만 본다. 입력은 작고 결과는 단순하며 매우 빠르다. edge가 line이나 arc에 수직하다는 전제가 깔린다.

2D Measuring의 도구들은 2D 영역 전체를 본다. 곡선이든 임의 형상이든 다룰 수 있고, Metrology의 measure region 자체가 사실 내부적으로 1D measure를 다발로 묶은 것에 가깝다.

Metrology Alignment 전략

실제 라인에서는 부품 위치·회전이 매 영상마다 다르다. Metrology 모델은 reference system을 기준으로 정의되므로, 매 영상에서 부품의 pose를 알아내 모델을 align해야 한다. Solution Guide III-B는 세 가지 방법을 제시한다.

6.1 Shape-based matching

create_generic_shape_model + train_generic_shape_model로 기준 부품의 shape model을 만들고, online에서 find_generic_shape_model로 row·column·angle을 얻어 align_metrology_model에 넣는다. 가장 일반적이고 robust한 방법이다.

6.2 Region processing 기반

부품이 threshold로 깔끔하게 분리되는 경우 area_center와 orientation_region만으로도 alignment가 가능하다. 빠르지만 부품이 단순 형상에 가까워야 한다.

6.3 Rigid transformation from point correspondences

기준 영상과 online 영상 모두에서 대응되는 reference point들을 안정적으로 검출할 수 있을 때 사용한다. vector_to_rigid + hom_mat2d_to_affine_par로 강체 변환을 얻고 align_metrology_model에 넘긴다.

Calibration과 World Coordinate

측정값을 mm·μm 같은 물리 단위로 보고하려면 camera calibration이 필수다. pixel distance는 카메라·렌즈·자세에 묶인 값이지 부품의 실제 치수가 아니다.

흐름은 단순하다.

calibration plate 촬영 (여러 pose)
→ create_calib_data / find_calib_object
→ calibrate_cameras
→ 외부·내부 parameter 획득
→ 측정 후 image coordinate를 world coordinate로 변환

변환 자체는 측정 결과(점·contour)에 image_points_to_world_plane 또는 contour_to_world_plane_xld 같은 연산자를 적용해 수행한다. 결과는 mm 단위의 실측치다.

측정 plane과 calibration plane의 일치 calibration plate가 놓인 평면과 실제 측정 대상 평면의 Z 높이가 다르면 scale error가 생긴다. telecentric lens가 아니면 이 효과는 더 커진다. plate를 측정 plane과 같은 높이에 두고 calibration해야 한다.
Calibration 없는 물리 치수는 의미가 없다 "0.234 pixel"은 측정이지만 "0.234 mm"는 calibration이 보장하기 전엔 추정일 뿐이다. 공차 판정 시스템에서는 반드시 calibration verification target으로 검증한 뒤 출하한다.

카메라·렌즈 calibration 상세는 Solution Guide III-C(3D Vision)와 시리즈 I의 calibration 챕터를 참고한다.

핵심 정리

  • 2D 측정은 Region·Contour·Metrology·Geometric Operations의 조합으로 푼다.
  • 정밀 치수에는 XLD contour fitting이 표준이고, robust algorithm으로 outlier를 막는다.
  • Metrology 모델은 단순 도형 다수의 반복 검사에 가장 적합한 구조다.
  • Alignment는 shape matching·region·rigid transform 중 부품 특성에 맞춰 고른다.
  • 물리 치수가 필요하면 camera calibration과 world coordinate 변환은 선택이 아니다.
  • partial arc, measure region 과대, calibration plane 불일치는 반복되는 함정이다.
한 줄 요약 같은 측정이라도 Region에서 XLD로, XLD에서 Metrology로 한 칸씩 올라갈 때마다 정밀도·반복성·구조성이 함께 올라간다. 정밀 측정 시스템 설계는 결국 이 사다리에서 적정 위치를 고르는 일이다.
