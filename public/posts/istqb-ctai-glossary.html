1. AI 일반 12개

인공지능 / Artificial Intelligence (AI)Ch1
사람의 인지·학습·추론 능력을 모방하는 시스템. 정의는 시대에 따라 변하며 합의된 단일 정의가 없다.
AI 효과 / AI EffectCh1
AI가 어떤 작업을 풀면 그 작업은 더 이상 AI로 여겨지지 않는 인식 현상. AI 정의가 시간에 따라 좁아진다.
약인공지능 / Narrow AICh1
특정 작업 하나만 처리하도록 설계된 AI. 현존하는 모든 실용 AI가 이 범주에 속한다.
강인공지능 / General AI (AGI)Ch1
인간 수준의 범용 지능을 가진 AI. 아직 구현되지 않은 가설적 단계이다.
초인공지능 / Super AICh1
모든 면에서 인간 지능을 넘어서는 AI. 기술적 특이점 이후 등장한다고 가정되는 사변적 개념.
기술적 특이점 / Technological SingularityCh1
AI가 스스로를 개선해 인간의 통제·예측 한계를 넘어서는 가설적 시점.
AIaaS / AI as a ServiceCh1·Ch11
클라우드 사업자가 제공하는 즉시 사용 가능한 AI 서비스(API). 자체 모델 학습 없이 빠른 도입이 가능하다.
사전훈련 모델 / Pre-trained ModelCh1
대규모 데이터로 미리 학습해 가중치가 확정된 모델. 새로운 작업의 출발점으로 활용된다.
전이학습 / Transfer LearningCh1·Ch3
사전훈련된 모델의 지식을 새로운 작업으로 옮겨 적용하는 학습 방법. 적은 데이터로도 효과적이다.
파인튜닝 / Fine-tuningCh3
사전훈련 모델의 일부(혹은 전체) 가중치를 새 데이터로 추가 학습하여 도메인에 맞추는 과정.
AI 에이전트 / AI AgentCh1
환경을 인지하고 목표를 달성하기 위해 자율적으로 행동하는 AI 시스템.
전문가 시스템 / Expert SystemCh1
사람 전문가의 지식을 규칙 기반으로 구현한 초기 AI 시스템. 추론 엔진과 지식 베이스로 구성된다.

2. ML 학습 형태와 작업 11개

머신러닝 / Machine Learning (ML)Ch3
데이터로부터 패턴을 학습해 명시적 프로그래밍 없이 작업을 수행하는 AI의 한 분야.
지도 학습 / Supervised LearningCh3
레이블이 달린 데이터로 입력-출력 관계를 학습. 분류와 회귀가 대표 작업이다.
비지도 학습 / Unsupervised LearningCh3
레이블 없는 데이터에서 내재된 패턴이나 구조를 학습. 군집화·차원 축소가 대표 작업.
강화 학습 / Reinforcement LearningCh3
환경과 상호작용하며 보상을 최대화하는 행동 정책을 학습. 시행착오 기반.
자가학습 / Self-supervised LearningCh3
데이터 일부를 가리고 맞히는 식으로 모델이 스스로 레이블을 생성해 학습. 대규모 사전훈련에 사용.
분류 / ClassificationCh3
입력을 미리 정의된 이산적 클래스 중 하나로 할당하는 지도 학습 작업.
회귀 / RegressionCh3
입력으로부터 연속적인 수치값을 예측하는 지도 학습 작업.
군집화 / ClusteringCh3
레이블 없이 데이터를 유사성에 따라 그룹으로 나누는 비지도 학습 작업.
연관 규칙 / AssociationCh3
데이터 항목들 간의 동시 발생 패턴을 발견하는 비지도 학습. 장바구니 분석이 대표 예.
차원 축소 / Dimensionality ReductionCh3
정보 손실을 최소화하며 특성 수를 줄이는 기법. PCA가 대표적이다.
하이퍼파라미터 / HyperparameterCh3
학습 전에 사람이 설정하는 모델 외부 변수. 학습률, 배치 크기, 트리 깊이 등이 해당된다.

3. ML 워크플로우와 데이터 15개

데이터 준비 / Data PreparationCh4
원시 데이터를 모델 학습에 적합한 형태로 가공하는 전 과정. 수집·정제·변환·증강을 포함한다.
데이터 증강 / Data AugmentationCh4
기존 데이터를 변형(회전·반전·노이즈 등)해 학습 데이터 양을 늘리는 기법. 과적합 완화에 도움.
데이터 레이블링 / Data LabelingCh4
학습 데이터에 정답을 부여하는 작업. 품질·일관성이 모델 성능을 좌우한다.
훈련 데이터셋 / Training DatasetCh4
모델의 가중치를 학습시키는 데 사용되는 데이터셋. 일반적으로 전체의 60~80%.
검증 데이터셋 / Validation DatasetCh4
학습 중 하이퍼파라미터 조정과 모델 선택에 사용되는 데이터셋. 학습에는 직접 쓰이지 않음.
테스트 데이터셋 / Test DatasetCh4
최종 모델의 일반화 성능을 평가하기 위한 별도 데이터셋. 학습·조정에는 절대 사용하지 않는다.
탐색적 데이터 분석 / Exploratory Data Analysis (EDA)Ch4·Ch9
데이터의 분포·결측·이상치를 시각화·통계로 파악하는 초기 분석 단계.
특성 공학 / Feature EngineeringCh4
원시 데이터에서 모델에 유용한 입력 변수를 추출·설계하는 과정.
과적합 / OverfittingCh3
훈련 데이터에 지나치게 맞춰져 새 데이터에서 성능이 떨어지는 현상. 잡음까지 학습한 결과.
과소적합 / UnderfittingCh3
모델이 데이터의 패턴조차 잡지 못하는 상태. 모델 용량 부족이나 학습 부족이 원인.
컨셉 드리프트 / Concept DriftCh7
시간 경과로 입력-출력의 통계적 관계가 변하는 현상. 운영 중 모델 성능 저하의 주원인.
데이터 드리프트 / Data DriftCh7
입력 데이터의 분포가 학습 시점과 달라지는 현상. 컨셉 드리프트의 원인이 될 수 있다.
데이터 누수 / Data LeakageCh4
학습 시 사용해선 안 될 정보(미래 정보·테스트 데이터)가 모델에 흘러들어가 성능이 부풀려지는 결함.
교차 검증 / Cross-validationCh3
데이터를 여러 폴드로 나눠 번갈아 검증해 모델 성능을 안정적으로 추정하는 기법.
데이터 오염 / Data PoisoningCh4·Ch8
악의적으로 변조된 샘플을 학습 데이터에 끼워 넣어 모델이 잘못된 동작을 학습하게 하는 공격.

4. 신경망 11개

신경망 / Neural Network (NN)Ch6
뉴런으로 구성된 층 구조로 입력을 출력으로 변환하는 학습 모델. 사람 뇌의 단순화된 모델.
심층 신경망 / Deep Neural Network (DNN)Ch6
은닉층이 여러 개인 신경망. 딥러닝의 기반이며 복잡한 비선형 패턴 학습이 가능하다.
딥러닝 / Deep LearningCh6
심층 신경망을 활용한 머신러닝의 한 분야. 이미지·음성·자연어에서 큰 성과를 거뒀다.
뉴런 / NeuronCh6
입력에 가중치를 곱해 합산한 뒤 활성화 함수를 적용해 출력을 내는 신경망의 기본 단위.
가중치 / WeightCh6
각 입력이 뉴런 출력에 미치는 영향의 크기. 학습은 곧 가중치를 조정하는 과정이다.
편향 / Bias (NN)Ch6
뉴런 출력에 더해지는 상수 항. 활성화 함수의 위치를 좌우로 이동시켜 표현력을 높인다.
활성화 함수 / Activation FunctionCh6
뉴런의 가중합을 비선형 출력으로 변환하는 함수. ReLU, Sigmoid, Tanh가 대표적이다.
역전파 / BackpropagationCh6
출력 오차를 입력 방향으로 전파해 각 가중치의 기울기를 계산하는 학습 알고리즘.
손실 함수 / Loss FunctionCh6
예측과 정답의 차이를 수치화한 함수. 학습은 이 값을 최소화하는 방향으로 진행된다.
뉴런 커버리지 / Neuron CoverageCh6
테스트 입력으로 활성화된 뉴런의 비율. 신경망의 화이트박스 커버리지 지표.
임계값 커버리지 / Threshold CoverageCh6
각 뉴런의 활성화 값이 특정 임계값을 넘은 비율을 측정하는 신경망 커버리지의 변형.

5. 성능 지표 12개

혼동행렬 / Confusion MatrixCh5
분류 모델의 예측과 실제값을 TP·TN·FP·FN으로 정리한 표. 모든 분류 지표의 기반이다.
정확도 / AccuracyCh5
(TP+TN)/전체. 전체 예측 중 맞춘 비율. 클래스 불균형일 때 오해를 줄 수 있다.
정밀도 / PrecisionCh5
TP/(TP+FP). 양성으로 예측한 것 중 실제 양성 비율. FP 비용이 클 때 중요.
재현율 / Recall (Sensitivity)Ch5
TP/(TP+FN). 실제 양성 중 잡아낸 비율. FN이 치명적일 때 우선시한다.
F1 점수 / F1 ScoreCh5
정밀도와 재현율의 조화 평균. 두 지표의 균형을 한 수치로 표현.
위양성 / False Positive (FP)Ch5
음성인데 양성으로 잘못 분류한 경우. 1종 오류.
위음성 / False Negative (FN)Ch5
양성인데 음성으로 잘못 분류한 경우. 2종 오류.
ROC 곡선 / ROC CurveCh5
임계값을 바꿔가며 진양성률(TPR)과 위양성률(FPR)의 관계를 그린 곡선.
AUC / Area Under the CurveCh5
ROC 곡선 아래 면적. 분류기의 종합 성능을 0~1 사이의 단일 값으로 요약한다.
결정 계수 / R-squared (R²)Ch5
회귀 모델이 데이터 분산을 설명하는 비율. 1에 가까울수록 설명력이 높다.
평균 제곱 오차 / Mean Squared Error (MSE)Ch5
예측과 정답의 차이를 제곱해 평균한 회귀 손실. 큰 오차에 더 큰 페널티를 준다.
평균 절대 오차 / Mean Absolute Error (MAE)Ch5
예측과 정답의 절대 차이의 평균. MSE보다 이상치에 덜 민감하다.

6. AI 품질 특성 14개

유연성 / FlexibilityCh2
학습된 영역 외에서도 어느 정도 합리적 결과를 내는 능력.
적응성 / AdaptabilityCh2
새로운 환경이나 데이터 분포 변화에 모델이 맞춰 변하는 능력.
자율성 / AutonomyCh2
사람의 개입 없이 시스템이 스스로 결정하고 행동하는 정도.
진화 / EvolutionCh2
시간 경과에 따라 모델이 학습·재학습으로 지속적으로 변하는 특성.
편향 / BiasCh2·Ch4
특정 결과로 치우치는 경향. 샘플 편향·알고리즘 편향·부적절한 편향으로 구분된다.
윤리 / EthicsCh2
AI 시스템 설계·운영에서 지켜야 할 도덕적 원칙. 공정성·책임성·프라이버시 등을 포함.
부작용 / Side EffectsCh2·Ch8
주 목표를 달성하면서 의도치 않은 다른 결과가 발생하는 현상. 보상 함수 설계 결함이 원인.
보상 해킹 / Reward HackingCh2·Ch8
보상 함수의 허점을 이용해 의도와 다른 방식으로 점수만 얻는 강화학습 모델의 행동.
투명성 / TransparencyCh2·Ch8
모델·데이터·의사결정 과정이 외부에 공개되어 있는 정도.
해석가능성 / InterpretabilityCh2·Ch8
모델의 내부 동작 자체를 사람이 이해할 수 있는 정도. 선형모델·결정트리가 높다.
설명가능성 / Explainability (XAI)Ch2·Ch8
모델의 특정 예측 결과를 사람이 이해할 수 있도록 설명하는 능력. LIME·SHAP이 대표 기법.
안전 / SafetyCh2·Ch8
AI 시스템이 사람·환경에 해를 끼치지 않도록 보장하는 품질 속성.
강건성 / RobustnessCh2·Ch8
노이즈·변형·적대적 입력 등 예외 상황에서도 모델이 안정적으로 동작하는 능력.
개인정보 보호 / PrivacyCh2
학습·운영 과정에서 개인 데이터를 보호하는 속성. GDPR·차등 프라이버시 등이 관련된다.

7. 테스팅 기법 13개

적대적 테스팅 / Adversarial TestingCh8·Ch9
사람 눈엔 같아 보이는 미세 변형 입력으로 모델을 속이는 공격을 시뮬레이션하는 테스팅.
적대적 예제 / Adversarial ExampleCh8
의도적으로 조작되어 모델을 오분류하게 만드는 입력 샘플.
페어와이즈 테스팅 / Pairwise TestingCh9
모든 파라미터 쌍의 값 조합을 한 번 이상 커버하는 조합 기법. 테스트 수 절감에 효과적.
조합 테스팅 / Combinatorial TestingCh9
t개 파라미터 조합을 모두 커버하는 일반화된 기법. t=2가 페어와이즈이다.
백투백 테스팅 / Back-to-Back TestingCh9
두 개 이상의 구현(레퍼런스 모델·기존 모델 등)에 같은 입력을 넣고 출력을 비교하는 기법.
A/B 테스팅 / A/B TestingCh9
두 버전(A, B)을 사용자 그룹에 노출하고 통계적으로 성능을 비교하는 운영 환경 테스트.
변성 테스팅 / Metamorphic TestingCh9
입력의 변형과 출력의 변화 관계(변성 관계)를 검증해 오라클 문제를 우회하는 기법.
변성 관계 / Metamorphic RelationCh9
입력 변형과 그에 대응되는 출력 변화 사이의 약속된 관계. 변성 테스팅의 핵심 오라클.
탐색적 테스팅 / Exploratory TestingCh9
사전 정의된 테스트 케이스 없이 학습·설계·실행을 동시에 진행하는 기법. AI의 미지 결함 탐색에 유용.
테스트 오라클 문제 / Test Oracle ProblemCh7
주어진 입력에 대한 정답(기대 결과)을 알 수 없거나 정의하기 어려운 상황. AI 테스팅의 본질적 난점.
의사 오라클 / Pseudo-oracleCh9
정확한 정답 대신 비교 기준 역할을 하는 대체 출력(다른 구현 결과, 변성 관계 등).
테스팅에 AI 활용 / AI for TestingCh11
테스트 케이스 생성·UI 변경 적응·결함 예측·자가 치유 자동화 등 테스팅 활동에 AI를 적용하는 분야.
자가 치유 테스트 / Self-healing TestCh11
UI 요소 변경 시 AI가 새로운 로케이터를 자동으로 찾아 테스트가 깨지지 않도록 하는 기법.

8. 테스트 환경 4개

가상 테스트 환경 / Virtual Test EnvironmentCh10
소프트웨어로 구현된 가상 환경에서 AI 시스템을 테스트하는 환경. 자율주행 시뮬레이션이 대표적.
시뮬레이터 / SimulatorCh10
실제 환경의 동작을 모사하는 도구. AI가 안전하고 반복 가능하게 학습·테스트할 수 있게 한다.
디지털 트윈 / Digital TwinCh10
물리 시스템을 디지털 공간에 1:1로 재현한 모델. 실제와 동기화되어 운영 중 검증에 활용.
레코드/리플레이 / Record/ReplayCh10
실제 운영 환경의 입력을 녹화해 테스트 환경에서 재현하는 기법.

9. 표준과 규정 8개

GDPR / General Data Protection RegulationCh2
EU 일반 개인정보보호 규정. 자동화된 의사결정에 대한 설명 요구 등 AI 시스템에 직접 영향을 준다.
ISO 26262 Ch2·Ch8
자동차 기능 안전성(Functional Safety) 국제 표준. 차량 시스템의 결함으로 인한 위험 관리를 다룬다.
ISO/PAS 21448 (SOTIF) Ch2·Ch8
의도된 기능의 안전성(Safety of the Intended Functionality) 표준. 결함이 없어도 발생할 수 있는 위험을 다루며 AI 기반 자율주행에 핵심.
ISO/IEC JTC 1/SC 42 Ch2
국제 표준화기구의 AI 전담 위원회. AI 개념·용어·신뢰성·관리 등의 표준을 제정한다.
ISO/IEC 25010 Ch2
소프트웨어 제품 품질 모델 표준. AI 품질 특성도 이 모델을 확장하여 다룬다.
ISO/IEC 23053 Ch2
머신러닝을 활용한 AI 시스템의 프레임워크 표준. ML 라이프사이클의 구성요소를 정의한다.
EU AI Act Ch2
EU의 AI 규제 법안. 위험 등급별로 AI 시스템의 요구사항과 금지 사항을 정한다.
IEEE 7000 시리즈 Ch2
AI·자율 시스템의 윤리 설계, 투명성, 알고리즘 편향 등을 다루는 IEEE 표준 모음.
학습 우선순위 Ch1~Ch5의 용어는 정의 자체가 직접 출제되는 경우가 많다. Ch6~Ch11의 용어는 시나리오 안에서 "이게 무슨 기법인지" 묻는 형태로 나온다. 한영 병기를 외워두면 영문 선지가 섞인 문제에서도 흔들리지 않는다.
