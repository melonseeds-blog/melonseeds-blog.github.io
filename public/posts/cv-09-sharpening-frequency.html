샤프닝이란?

샤프닝(sharpening)은 이미지의 엣지를 강조해 더 또렷하고 선명하게 보이도록 만드는 처리다. 블러가 인접 픽셀을 평균 내 경계를 뭉개는 연산이라면, 샤프닝은 정반대로 경계에서의 명암 차이를 키워 윤곽을 도드라지게 한다.

핵심 발상은 간단하다. 이미지에서 급격하게 변하는 부분이 곧 엣지다. 이 급격한 변화 성분만 골라내 원본에 더하면 엣지가 더 강해진다. "급격한 변화"를 어떻게 뽑아내느냐에 따라 방법이 갈린다 — 2차 미분(Laplacian)을 쓰거나, 원본에서 블러를 빼는(언샤프 마스킹) 방식이다. 둘 다 결국 고주파 성분을 추출해 원본에 보강한다는 같은 원리 위에 있다.

샤프닝은 없던 디테일을 만들지 못한다 샤프닝은 이미 존재하는 엣지의 대비를 키울 뿐, 사라진 정보를 복원하지 않는다. 심하게 흐려진 이미지를 샤프닝해도 원래의 선명함은 돌아오지 않고 부자연스러운 테두리만 생긴다.

Laplacian 기반 샤프닝

Laplacian은 2차 미분 연산자다. 1차 미분이 밝기의 변화율(기울기)을 보는 것이라면, 2차 미분은 그 변화율이 다시 얼마나 빠르게 변하는지를 본다. 엣지처럼 명암이 급변하는 곳에서 Laplacian 값이 크게 튄다. 평탄한 영역에서는 0에 가깝다.

샤프닝 공식은 다음과 같다. 원본에서 Laplacian을 빼면(Laplacian 부호 규약에 따라) 엣지가 강조된다.

sharpened = original − α × Laplacian(original) 

#include <opencv2/opencv.hpp>
#include <iostream>

int main()
{
    cv::Mat src = cv::imread("part.jpg", cv::IMREAD_GRAYSCALE);
    if (src.empty())
    {
        std::cerr << "이미지를 열 수 없습니다." << std::endl;
        return -1;
    }

    // Laplacian은 음수가 나오므로 부호 있는 타입으로 받는다
    cv::Mat lap;
    cv::Laplacian(src, lap, CV_16S, 3);  // 커널 크기 3

    // 원본도 같은 타입으로 맞춘 뒤 빼기
    cv::Mat src16;
    src.convertTo(src16, CV_16S);

    // sharpened = original - Laplacian
    cv::Mat sharp16 = src16 - lap;

    // 0~255 범위로 클리핑하며 8비트로 환원
    cv::Mat sharpened;
    sharp16.convertTo(sharpened, CV_8U);

    cv::imshow("Original", src);
    cv::imshow("Laplacian Sharpened", sharpened);
    cv::waitKey(0);
    return 0;
}

샤프닝 커널 직접 만들기 — filter2D

위 과정은 사실 하나의 3×3 커널로 합칠 수 있다. 원본(중심에 1)과 Laplacian 커널을 더해 두면, filter2D 한 번으로 끝난다. 가장 널리 쓰이는 샤프닝 커널이다.

// 중심 5, 상하좌우 -1 — 가장 기본적인 샤프닝 커널
cv::Mat kernel = (cv::Mat_<float>(3, 3) <<
     0, -1,  0,
    -1,  5, -1,
     0, -1,  0);

cv::Mat sharpened;
cv::filter2D(src, sharpened, src.depth(), kernel);

// 더 강한 샤프닝 — 대각선까지 포함한 8방향 커널
cv::Mat strongKernel = (cv::Mat_<float>(3, 3) <<
    -1, -1, -1,
    -1,  9, -1,
    -1, -1, -1);

cv::Mat strongSharp;
cv::filter2D(src, strongSharp, src.depth(), strongKernel);
커널 원소의 합이 1이어야 평균 밝기가 유지된다 샤프닝 커널의 모든 원소를 더하면 1이 되도록 설계한다(예: 5 + (-1)×4 = 1). 합이 1이면 평탄한 영역의 밝기가 그대로 유지되고, 엣지에서만 대비가 커진다. 합이 1보다 크면 전체가 밝아지고 작으면 어두워진다.

언샤프 마스킹

언샤프 마스킹(Unsharp Masking, USM)은 이름과 달리 이미지를 선명하게 만드는 기법이다. 이름의 유래는 필름 시절 흐릿한("unsharp") 음화를 마스크로 써서 원본을 강조하던 암실 기법이다. 디지털에서도 원리는 똑같다.

원본에서 블러 버전을 빼면 무엇이 남을까? 블러는 완만한 변화(저주파)만 남기고 엣지를 지운다. 따라서 원본 − 블러 = 엣지·디테일 성분, 즉 고주파 성분이다. 이 고주파를 다시 원본에 가중 합산하면 엣지가 강조된다.

언샤프 마스킹 흐름: 원본에서 블러를 빼 고주파를 얻고, amount(k)만큼 키워 원본에 다시 더한다.

수식으로 쓰면 다음과 같다. amount가 클수록 샤프닝 강도가 세진다.

sharp = original + amount × (original − blurred)

addWeighted로 구현하기

위 수식을 정리하면 sharp = (1 + amount) × original − amount × blurred가 된다. 이는 두 이미지의 가중 합이므로 cv::addWeighted 한 번으로 표현된다.

#include <opencv2/opencv.hpp>

// 언샤프 마스킹으로 이미지를 선명하게 만든다.
cv::Mat unsharpMask(const cv::Mat& src, double amount, int blurSize, double sigma)
{
    // 1) 저주파만 남기는 블러 버전
    cv::Mat blurred;
    cv::GaussianBlur(src, blurred, cv::Size(blurSize, blurSize), sigma);

    // 2) sharp = (1 + amount)*src - amount*blurred
    cv::Mat sharp;
    cv::addWeighted(src, 1.0 + amount, blurred, -amount, 0.0, sharp);

    return sharp;
}

int main()
{
    cv::Mat src = cv::imread("part.jpg");
    if (src.empty()) { return -1; }

    cv::Mat result = unsharpMask(src, 1.0, 5, 1.0);  // amount=1.0

    cv::imshow("Original", src);
    cv::imshow("Unsharp Masked", result);
    cv::waitKey(0);
    return 0;
}

고주파를 명시적으로 다뤄 보고 싶다면 단계를 풀어서 쓸 수도 있다. subtract와 addWeighted를 직접 조합하는 방식이다.

cv::Mat blurred, highFreq, sharp;

// 블러 버전
cv::GaussianBlur(src, blurred, cv::Size(0, 0), 3.0);  // sigma로만 지정

// 고주파 = 원본 - 블러
cv::subtract(src, blurred, highFreq);

// 원본 + amount * 고주파
double amount = 1.5;
cv::addWeighted(src, 1.0, highFreq, amount, 0.0, sharp);
블러 반경(sigma)이 샤프닝의 "스케일"을 정한다 sigma가 작으면 가는 디테일만, 크면 넓은 윤곽까지 강조된다. GaussianBlur에 Size(0,0)을 주면 sigma만으로 커널 크기를 자동 계산하므로 스케일 조절이 편하다. 실무에서는 amount와 sigma 두 손잡이를 함께 돌려 가며 맞춘다.

샤프닝의 부작용

샤프닝은 공짜가 아니다. "급격한 변화"를 강조한다는 것은 엣지만이 아니라 노이즈도 함께 키운다는 뜻이다. 노이즈는 본질적으로 픽셀 단위의 급격한 값 변동, 즉 고주파 성분이기 때문이다.

  • 노이즈 증폭 — 평탄해야 할 영역에 알갱이(grain)가 도드라진다. 어두운 영역에서 특히 두드러진다.
  • 링잉(ringing) — 강한 엣지 주변에 밝고 어두운 띠가 생긴다. 검은 글자 주변에 흰 후광이 보이는 현상이다.
  • 하얀 테두리 / 오버슈트 — amount가 과하면 엣지의 밝은 쪽이 255를 넘어 클리핑되고, 어두운 쪽은 0으로 깔린다. 결과적으로 인공적인 윤곽선이 생긴다.
  • 계조 손실 — 클리핑이 일어난 영역은 원래의 밝기 차이를 잃어버려 디테일이 오히려 사라진다.
샤프닝 전에 노이즈를 먼저 잡아야 한다 노이즈가 있는 이미지를 바로 샤프닝하면 노이즈가 같이 폭발한다. 순서는 디노이징 → 샤프닝이다. 또는 언샤프 마스킹에서 고주파 성분에 임계값을 두어(threshold) 작은 변동은 무시하고 뚜렷한 엣지만 강조하는 방법도 쓴다. amount는 보통 0.5~1.5 사이에서 시작해 결과를 보며 조절한다.

주파수 영역 개념

지금까지는 이미지를 공간 영역(spatial domain)에서 다뤘다. 픽셀의 위치 (x, y)에 밝기값이 놓여 있는, 우리가 눈으로 보는 그 형태다. 그런데 같은 이미지를 완전히 다른 시각으로 표현할 수 있다 — 주파수 영역(frequency domain)이다.

주파수 영역에서는 이미지를 "여러 주파수의 물결이 겹쳐진 것"으로 본다. 어떤 물결이 얼마나 강하게 섞여 있는지를 나타낸다.

구분의미이미지에서의 정체
저주파밝기가 완만하게 변하는 성분배경, 큰 면적의 매끄러운 영역, 전체적인 밝기
고주파밝기가 급격하게 변하는 성분엣지, 가는 선, 텍스처, 디테일, 노이즈

이 관점이 강력한 이유는 지금까지 한 모든 작업이 주파수로 깔끔하게 설명되기 때문이다. 블러 = 고주파를 깎는 것, 샤프닝 = 고주파를 키우는 것. 공간 영역에서 커널을 옮겨가며 합성곱하던 작업이, 주파수 영역에서는 단순히 특정 주파수 대역을 곱셈으로 통과/차단하는 일이 된다.

합성곱 = 주파수 영역에서의 곱셈 컨볼루션 정리(convolution theorem)에 따르면, 공간 영역의 합성곱은 주파수 영역의 곱셈과 같다. 그래서 큰 커널로 합성곱하는 무거운 연산을 주파수 영역에서는 가벼운 원소별 곱셈으로 대체할 수 있다. 두 세계를 잇는 다리가 바로 푸리에 변환이다.

푸리에 변환 (DFT)

공간 영역의 이미지를 주파수 영역으로 옮기는 도구가 이산 푸리에 변환(Discrete Fourier Transform, DFT)이다. OpenCV에서는 cv::dft로 수행한다.

DFT의 결과는 복소수다. 각 주파수 성분의 크기(magnitude)와 위상(phase)을 담기 때문이다. 우리가 눈으로 확인하는 것은 보통 크기 성분 — 크기 스펙트럼(magnitude spectrum)이다.

DFT와 스펙트럼 시각화

#include <opencv2/opencv.hpp>

int main()
{
    cv::Mat src = cv::imread("part.jpg", cv::IMREAD_GRAYSCALE);
    if (src.empty()) { return -1; }

    // 1) DFT에 최적인 크기로 패딩 (2,3,5의 곱 형태가 빠르다)
    int m = cv::getOptimalDFTSize(src.rows);
    int n = cv::getOptimalDFTSize(src.cols);
    cv::Mat padded;
    cv::copyMakeBorder(src, padded, 0, m - src.rows, 0, n - src.cols,
                       cv::BORDER_CONSTANT, cv::Scalar::all(0));

    // 2) 실수부 + 허수부(0)로 2채널 복소 행렬 구성, float 사용
    cv::Mat planes[] = {
        cv::Mat_<float>(padded),
        cv::Mat::zeros(padded.size(), CV_32F)
    };
    cv::Mat complexImg;
    cv::merge(planes, 2, complexImg);

    // 3) 푸리에 변환 실행
    cv::dft(complexImg, complexImg);

    // 4) 크기(magnitude) 계산: sqrt(Re^2 + Im^2)
    cv::split(complexImg, planes);
    cv::Mat mag;
    cv::magnitude(planes[0], planes[1], mag);

    // 5) log 스케일로 압축 (값의 범위가 너무 넓다)
    mag += cv::Scalar::all(1);   // log(0) 방지
    cv::log(mag, mag);

    // 6) 사분면 교환 — 저주파를 중앙으로 이동(shift)
    int cx = mag.cols / 2, cy = mag.rows / 2;
    cv::Mat q0(mag, cv::Rect(0, 0, cx, cy));
    cv::Mat q1(mag, cv::Rect(cx, 0, cx, cy));
    cv::Mat q2(mag, cv::Rect(0, cy, cx, cy));
    cv::Mat q3(mag, cv::Rect(cx, cy, cx, cy));
    cv::Mat tmp;
    q0.copyTo(tmp); q3.copyTo(q0); tmp.copyTo(q3);  // 좌상 <-> 우하
    q1.copyTo(tmp); q2.copyTo(q1); tmp.copyTo(q2);  // 우상 <-> 좌하

    // 7) 0~1로 정규화해야 화면에 보인다
    cv::normalize(mag, mag, 0, 1, cv::NORM_MINMAX);

    cv::imshow("Input", src);
    cv::imshow("Magnitude Spectrum", mag);
    cv::waitKey(0);
    return 0;
}

시각화한 스펙트럼에서 중앙이 저주파, 바깥쪽이 고주파다. 사분면 교환(shift)을 하는 이유는, DFT 원본 출력은 저주파가 네 모서리에 흩어져 있어 보기 불편하기 때문이다. 중앙으로 모으면 직관적으로 읽힌다 — 보통 중앙에 밝은 점이 강하게 뜨고(저주파가 에너지의 대부분), 규칙적인 패턴이 있으면 특정 위치에 밝은 점이 나타난다.

DFT 입력은 float, 크기는 getOptimalDFTSize로 cv::dft는 보통 CV_32F 입력을 받는다. 8비트 이미지를 그대로 넣지 말고 float로 변환한다. 또 임의 크기에서는 DFT가 느리다 — getOptimalDFTSize로 2·3·5의 곱이 되는 크기를 구해 copyMakeBorder로 패딩하면 수 배 빨라진다.

주파수 영역 필터링

주파수 영역으로 옮겼으면 필터링은 마스크를 곱하는 일이 된다. 통과시킬 주파수는 1, 막을 주파수는 0인 마스크를 만들어 DFT 결과에 곱하고, 역변환(cv::idft)하면 필터링된 이미지가 나온다.

필터통과 대역마스크 모양효과
저역 통과(LPF)저주파만중앙에 흰 원블러 — 디테일·노이즈 제거
고역 통과(HPF)고주파만중앙에 검은 원샤프닝 — 엣지만 남김
대역 차단(notch)특정 점만 차단특정 좌표에 검은 점주기 노이즈 제거
주파수 영역 필터링 흐름: dft → shift → 마스크 곱 → idft → 정규화.

저역 통과 필터 — 주파수 영역 블러

#include <opencv2/opencv.hpp>

// DFT 결과의 사분면을 교환한다 (저주파를 중앙으로).
void fftShift(cv::Mat& mat)
{
    int cx = mat.cols / 2, cy = mat.rows / 2;
    cv::Mat q0(mat, cv::Rect(0, 0, cx, cy));
    cv::Mat q1(mat, cv::Rect(cx, 0, cx, cy));
    cv::Mat q2(mat, cv::Rect(0, cy, cx, cy));
    cv::Mat q3(mat, cv::Rect(cx, cy, cx, cy));
    cv::Mat tmp;
    q0.copyTo(tmp); q3.copyTo(q0); tmp.copyTo(q3);
    q1.copyTo(tmp); q2.copyTo(q1); tmp.copyTo(q2);
}

int main()
{
    cv::Mat src = cv::imread("part.jpg", cv::IMREAD_GRAYSCALE);
    if (src.empty()) { return -1; }

    // 최적 크기 패딩
    int m = cv::getOptimalDFTSize(src.rows);
    int n = cv::getOptimalDFTSize(src.cols);
    cv::Mat padded;
    cv::copyMakeBorder(src, padded, 0, m - src.rows, 0, n - src.cols,
                       cv::BORDER_CONSTANT, cv::Scalar::all(0));

    // 복소 행렬 구성 후 DFT
    cv::Mat planes[] = { cv::Mat_<float>(padded),
                         cv::Mat::zeros(padded.size(), CV_32F) };
    cv::Mat complexImg;
    cv::merge(planes, 2, complexImg);
    cv::dft(complexImg, complexImg);

    // 저주파가 중앙에 오도록 shift
    fftShift(complexImg);

    // 저역 통과 마스크: 중앙 반경 radius 안만 1
    cv::Mat mask = cv::Mat::zeros(complexImg.size(), CV_32F);
    int radius = 60;  // 작을수록 더 강한 블러
    cv::circle(mask, cv::Point(mask.cols / 2, mask.rows / 2),
               radius, cv::Scalar(1), -1);

    // 2채널(실수/허수)에 같은 마스크를 곱한다
    cv::Mat maskPlanes[] = { mask, mask };
    cv::Mat mask2ch;
    cv::merge(maskPlanes, 2, mask2ch);
    cv::multiply(complexImg, mask2ch, complexImg);

    // 다시 shift 되돌리고 역변환
    fftShift(complexImg);
    cv::Mat result;
    cv::idft(complexImg, result, cv::DFT_SCALE | cv::DFT_REAL_OUTPUT);

    // 역변환 결과는 반드시 정규화해야 화면에 제대로 보인다
    cv::normalize(result, result, 0, 1, cv::NORM_MINMAX);

    cv::imshow("Input", src);
    cv::imshow("Low-pass (blurred)", result);
    cv::waitKey(0);
    return 0;
}

고역 통과 필터 — 주파수 영역 샤프닝

고역 통과는 마스크를 뒤집기만 하면 된다 — 중앙을 0, 바깥을 1로 만든다. 저주파(배경·전체 밝기)가 잘려 나가므로 결과는 엣지만 남은 영상이 된다.

// 고역 통과 마스크: 기본 1, 중앙 반경 안만 0
cv::Mat mask = cv::Mat::ones(complexImg.size(), CV_32F);
int radius = 30;  // 클수록 더 많은 저주파를 자른다
cv::circle(mask, cv::Point(mask.cols / 2, mask.rows / 2),
           radius, cv::Scalar(0), -1);

// 이후 곱셈 / idft / 정규화는 저역 통과와 동일

// 엣지만 남은 결과를 원본에 더하면 샤프닝 효과가 된다
// sharpened = original + k * highPassResult
이상적 필터(딱 떨어지는 원)는 링잉을 만든다 0과 1로 칼같이 나뉘는 원형 마스크는 경계가 너무 급격해 역변환 결과에 물결무늬(링잉)가 생긴다. 실무에서는 마스크 경계를 가우시안이나 버터워스 형태로 부드럽게 깎아 쓴다. 또한 idft 결과는 값 범위가 임의이므로 normalize 없이 imshow하면 새까맣거나 새하얗게 보인다.

공간 영역 vs 주파수 영역

같은 필터링을 두 가지 방식으로 할 수 있다면, 언제 어느 쪽을 골라야 할까. 정답은 "대부분 공간 영역, 특정 상황에서 주파수 영역"이다.

비교 항목공간 영역 (filter2D 등)주파수 영역 (dft / idft)
처리 방식커널을 옮겨가며 합성곱변환 후 마스크 곱, 역변환
작은 커널매우 빠름 (3×3, 5×5)변환 오버헤드가 더 큼
큰 커널커널 크기에 비례해 느려짐커널 크기와 무관, 유리
직관성픽셀 단위로 이해하기 쉬움주파수 개념 이해 필요
주기 패턴 제거거의 불가능매우 효과적 (notch 필터)
구현 복잡도함수 한 줄패딩·shift·정규화 등 단계 많음
기본은 공간 영역, 주파수 영역은 "주기성"이 핵심일 때 일반적인 블러·샤프닝·엣지 검출은 작은 커널로 충분하니 공간 영역이 빠르고 간단하다. 주파수 영역이 진짜 빛나는 순간은 (1) 아주 큰 커널이 필요하거나, (2) 격자무늬 같은 주기적 패턴을 분석·제거해야 할 때다. 주기 성분은 주파수 영역에서 또렷한 점으로 나타나기 때문이다.

산업 검사 관점

산업 비전 현장에서 주파수 영역 필터링이 결정적인 역할을 하는 대표 사례가 주기적 패턴 노이즈 제거다.

  • 격자무늬·줄무늬 노이즈 — 디스플레이 패널, 직물, 메쉬, 인쇄물 검사에서 조명 간섭이나 센서 특성으로 규칙적인 무늬가 끼는 경우. 공간 영역 블러로 지우려 하면 정작 봐야 할 결함까지 뭉개진다.
  • 모아레(moire) 패턴 — 규칙적인 피사체와 센서 격자가 간섭해 생기는 물결무늬.
  • 전원 라인 노이즈 — 일정 주파수로 반복되는 횡선.

이런 주기 노이즈는 공간 영역에서는 이미지 전체에 퍼져 있어 떼어내기 어렵지만, 주파수 영역에서는 스펙트럼의 특정 좌표에 또렷한 밝은 점으로 모인다. 그 점만 0으로 찍어 막으면(notch 필터) 노이즈만 골라 제거되고 결함 신호는 보존된다.

// notch 필터: 스펙트럼에서 노이즈 점을 찾아 차단한다.
// (DFT + shift는 앞 예제와 동일하다고 가정)

cv::Mat mask = cv::Mat::ones(complexImg.size(), CV_32F);

// 크기 스펙트럼을 보고 찾아낸 노이즈 피크 좌표들
std::vector<cv::Point> noisePeaks = {
    cv::Point(180, 240),
    cv::Point(332, 240)   // 보통 중심 대칭으로 쌍을 이룬다
};

// 각 피크 주변의 작은 원을 0으로 막는다
const int kNotchRadius = 8;
for (const cv::Point& p : noisePeaks)
{
    cv::circle(mask, p, kNotchRadius, cv::Scalar(0), -1);
}

cv::Mat maskPlanes[] = { mask, mask };
cv::Mat mask2ch;
cv::merge(maskPlanes, 2, mask2ch);
cv::multiply(complexImg, mask2ch, complexImg);

// 이후 shift 복원 + idft + normalize
"노이즈는 패턴, 결함은 무작위"라는 비대칭을 이용한다 주기 노이즈는 규칙적이라 주파수 영역에서 점으로 압축되지만, 스크래치·이물 같은 결함은 불규칙해 스펙트럼 전체에 퍼진다. 점만 골라 제거하면 노이즈는 사라지고 결함은 남는다 — 이 비대칭이 주파수 필터링을 산업 검사에서 강력하게 만드는 핵심이다.

흔한 함정

샤프닝과 주파수 영역 작업에서 반복적으로 마주치는 실수들이다.

샤프닝으로 노이즈 증폭

노이즈가 있는 이미지를 바로 샤프닝하지 않는다 샤프닝은 고주파를 키우는데 노이즈도 고주파다. 순서는 항상 디노이징 먼저, 샤프닝 나중. amount를 무작정 키우기보다 디노이징을 충분히 한 뒤 적당한 amount(0.5~1.5)를 쓰는 편이 결과가 훨씬 깨끗하다.

DFT 입력 타입과 크기

DFT 입력은 float, 크기는 getOptimalDFTSize 8비트 정수 이미지를 그대로 cv::dft에 넣으면 안 된다 — CV_32F로 변환한다. 또 소수가 섞인 임의 크기는 DFT가 느리다. getOptimalDFTSize로 구한 크기로 copyMakeBorder 패딩하면 성능이 크게 좋아진다.

스펙트럼은 log 스케일로 봐야 한다

크기 스펙트럼을 선형 스케일로 그리면 거의 안 보인다 저주파(중앙)의 에너지가 다른 성분보다 압도적으로 커서, 선형으로 그리면 중앙의 점 하나만 보이고 나머지는 새까맣다. cv::log로 압축한 뒤(0 방지를 위해 +1) 시각화해야 패턴이 드러난다.

역변환 후 정규화 누락

idft 결과는 그대로 imshow하면 안 된다 역변환 결과는 값 범위가 0~255로 떨어지지 않는다. cv::DFT_SCALE로 스케일을 맞추고, 표시·저장 전에는 cv::normalize로 0~1(또는 0~255)로 맞춰야 제대로 보인다. 이걸 빼면 결과가 새하얗거나 새까맣게 나와 "필터링이 안 됐다"고 착각하기 쉽다.
정리하면 샤프닝은 고주파 보강이고 블러는 고주파 제거다 — 둘 다 주파수 관점에서 한 줄로 설명된다. 일상적인 처리는 공간 영역(filter2D, 언샤프 마스킹)으로 빠르게 하고, 주기 패턴 노이즈처럼 주파수 구조가 핵심인 문제에서만 DFT를 꺼낸다. DFT를 쓸 때는 float 입력, 최적 크기, log 스케일 시각화, 역변환 후 정규화 네 가지를 잊지 않는다.
