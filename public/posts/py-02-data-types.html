동적 타이핑이란

Python은 동적 타입(dynamically typed) 언어다. 변수 자체에 타입이 정해져 있지 않고, 변수가 가리키는 값(객체)에 타입이 있다. 같은 변수에 서로 다른 타입의 값을 자유롭게 재할당할 수 있다.

x = 10          # x는 int를 가리킨다
x = "hello"     # 이제 x는 str을 가리킨다
x = [1, 2, 3]   # 이제 x는 list를 가리킨다
print(type(x))  # <class 'list'>

C++과 비교하면 차이가 분명하다. C++은 정적 타입(statically typed)이라 변수 선언 시점에 타입이 고정되고, 다른 타입을 대입할 수 없다.

// C++ — 정적 타입
int x = 10;
x = "hello";   // 컴파일 에러: const char*를 int에 대입 불가
비교C++ (정적 타입)Python (동적 타입)
타입 결정 시점컴파일 타임런타임
타입 소유자변수값(객체)
재할당같은 타입만 가능아무 타입 가능
오류 발견컴파일 시실행 시
속도빠름느림 (런타임 검사)
동적 타입 vs 약타입은 다르다 Python은 동적 타입이지만 강타입(strongly typed)이다. 1 + "2"는 자동 변환 없이 TypeError가 발생한다. JavaScript와 다른 점이다.

정수와 부동소수

int — 무제한 정밀도

Python의 int는 메모리가 허락하는 한 크기 제한이 없다. C++ int(32비트 한계 ~21억)와 본질적으로 다르다.

big = 2 ** 1000
print(big)
# 10715086071862673209484250490600018105614048117055336074437503883703510...
# (자릿수 302자리)

# C++의 long long도 19자리에서 오버플로
# Python은 그냥 동작한다
# 진수 표현
hex_val = 0xFF       # 16진수, 255
oct_val = 0o17       # 8진수, 15
bin_val = 0b1010     # 2진수, 10

# 가독성을 위한 언더스코어 (Python 3.6+)
million = 1_000_000  # 1000000

# 나눗셈
print(7 / 2)    # 3.5  — 실수 나눗셈
print(7 // 2)   # 3    — 정수 나눗셈 (몫)
print(7 % 2)    # 1    — 나머지
print(2 ** 10)  # 1024 — 거듭제곱

float — IEEE 754 double

float는 C의 double(64비트)을 사용한다. 이진 부동소수의 한계가 그대로 적용된다.

print(0.1 + 0.2)         # 0.30000000000000004
print(0.1 + 0.2 == 0.3)  # False  ← 함정!

# 안전한 비교: math.isclose
import math
print(math.isclose(0.1 + 0.2, 0.3))  # True

# 정확한 십진 연산이 필요하면 Decimal
from decimal import Decimal
print(Decimal("0.1") + Decimal("0.2"))  # 0.3
float 비교는 == 대신 isclose 부동소수는 표현 오차가 있어 직접 동등 비교를 피한다. 금액 계산처럼 정확도가 중요하면 decimal.Decimal을 쓴다.

문자열

str는 유니코드 문자의 불변(immutable) 시퀀스다. 작은따옴표와 큰따옴표를 구분하지 않는다.

s1 = 'hello'
s2 = "hello"
s3 = '''여러 줄
문자열'''
s4 = """이것도 가능"""

# 이스케이프
s5 = "줄바꿈\n탭\t따옴표\""

# 원시 문자열 (raw) — 이스케이프 무시
path = r"C:\Users\name"   # 백슬래시 그대로

f-string (Python 3.6+)

가장 권장되는 문자열 포맷팅 방식이다.

name = "Alice"
age = 30
print(f"이름: {name}, 나이: {age}")
# 이름: Alice, 나이: 30

# 식도 평가
x, y = 3, 4
print(f"{x} + {y} = {x + y}")  # 3 + 4 = 7

# 포맷 스펙
pi = 3.14159
print(f"{pi:.2f}")     # 3.14   (소수점 2자리)
print(f"{42:05d}")     # 00042  (5자리 0 채움)
print(f"{1234567:,}")  # 1,234,567 (천 단위 구분)

# 디버깅 (Python 3.8+)
print(f"{x=}, {y=}")   # x=3, y=4

자주 쓰는 str 메서드

s = "  Hello, World!  "

s.strip()         # "Hello, World!"  (앞뒤 공백 제거)
s.lower()         # "  hello, world!  "
s.upper()         # "  HELLO, WORLD!  "
s.replace("l", "L")  # 모두 치환
s.split(",")      # ['  Hello', ' World!  ']
"-".join(["a", "b", "c"])  # "a-b-c"

# 검색
"world" in s.lower()  # True
s.find("World")       # 9 (없으면 -1)
s.startswith("  H")   # True
s.endswith("!  ")     # True

# 길이/슬라이싱
len(s)         # 17
s[0]           # ' '
s[2:7]         # "Hello"
s[::-1]        # 뒤집기

bool과 None

bool — int의 서브클래스

흥미롭게도 bool은 int를 상속한다. True는 1, False는 0과 동등하다.

print(True + True)         # 2
print(True == 1)           # True
print(isinstance(True, int))  # True

# 합계로 카운트 응용
votes = [True, True, False, True]
print(sum(votes))  # 3

truthy / falsy

모든 객체는 if 문맥에서 boolean으로 평가된다. 다음 값들이 falsy다.

# Falsy 값들
bool(False)    # False
bool(None)     # False
bool(0)        # False
bool(0.0)      # False
bool("")       # False — 빈 문자열
bool([])       # False — 빈 리스트
bool({})       # False — 빈 딕셔너리
bool(set())    # False — 빈 집합

# 그 외 모든 값은 truthy
bool("False")  # True (비어있지 않은 문자열)
bool([0])      # True (요소가 있는 리스트)
bool(-1)       # True (0이 아닌 수)

# 실용 예
items = []
if not items:
    print("리스트가 비었다")

name = ""
print(name or "익명")  # "익명" — 단축 평가

None — null 대용

None은 "값이 없음"을 나타내는 유일한 NoneType 인스턴스다. C++의 nullptr이나 Java의 null에 해당한다.

x = None

# None 비교는 == 가 아닌 is 를 쓴다 (PEP 8)
if x is None:
    print("값이 없다")

# 함수가 명시적으로 반환하지 않으면 None을 반환한다
def greet(name):
    print(f"Hello, {name}")

result = greet("Alice")
print(result)  # None

타입 힌트 (Type Hints)

Python 3.5부터 도입된 타입 힌트는 변수와 함수에 타입 정보를 표기할 수 있게 한다. 실행 시 검사는 하지 않지만, IDE 자동완성과 mypy 같은 정적 검사기에서 활용된다.

# 함수 매개변수와 반환 타입
def add(x: int, y: int) -> int:
    return x + y

def greet(name: str) -> str:
    return f"Hello, {name}"

# 변수 어노테이션
age: int = 30
name: str = "Alice"
scores: list[int] = [90, 85, 100]   # Python 3.9+
mapping: dict[str, int] = {"a": 1}

typing 모듈

from typing import Optional, Union, Callable

# Optional[T] = T | None
def find_user(user_id: int) -> Optional[str]:
    if user_id == 1:
        return "Alice"
    return None

# Union — 여러 타입 중 하나 (Python 3.10+에서는 X | Y 문법)
def parse(value: Union[int, str]) -> int:
    return int(value)

# Python 3.10+
def parse2(value: int | str) -> int:
    return int(value)

# Callable — 함수 타입
def apply(func: Callable[[int], int], x: int) -> int:
    return func(x)

mypy로 정적 검사

# bad.py
def add(x: int, y: int) -> int:
    return x + y

result = add(3, "5")   # 타입 힌트 위반
mypy 실행 결과
$ mypy bad.py bad.py:4: error: Argument 2 to "add" has incompatible type "str"; expected "int" Found 1 error in 1 file (checked 1 source file)
타입 힌트는 런타임 강제가 아니다 Python 인터프리터는 타입 힌트를 무시한다. add(3, "5")도 실행은 된다(결과는 "55"... 아니, TypeError). 검사는 mypy, pyright 같은 외부 도구로 한다. 중대형 프로젝트에서는 거의 필수다.

type() vs isinstance()

x = 42

# type() — 정확한 타입 반환
print(type(x))              # <class 'int'>
print(type(x) == int)       # True
print(type(x) is int)       # True (관용적)

# isinstance() — 상속 관계까지 확인
print(isinstance(x, int))   # True
print(isinstance(True, int))  # True ← bool은 int의 서브클래스

# 여러 타입 한꺼번에
print(isinstance(x, (int, float)))  # True

# type()은 상속을 못 본다
class Animal: pass
class Dog(Animal): pass

d = Dog()
print(type(d) == Animal)         # False
print(isinstance(d, Animal))     # True ← 추천
일반적으로 isinstance를 쓴다 다형성을 지원해야 하니까. type() == X는 정말 정확한 타입이 필요할 때만(예: True와 1을 구분).

변수와 객체

Python의 변수는 C++의 변수와 다르다. C++ 변수는 메모리 슬롯이지만, Python 변수는 객체에 붙은 이름(레이블, name binding)이다.

a와 b는 같은 객체를 가리킨다 (a is b → True). c는 값이 같아도 다른 객체다 (a == c → True, a is c → False).
a = [1, 2, 3]
b = a               # 같은 객체에 새 이름을 붙임
c = [1, 2, 3]       # 별도의 새 객체

print(a == b)       # True  (값이 같다)
print(a is b)       # True  (같은 객체)
print(id(a) == id(b))  # True

print(a == c)       # True  (값이 같다)
print(a is c)       # False (다른 객체)

# a를 통해 수정하면 b도 영향을 받는다
a.append(4)
print(b)            # [1, 2, 3, 4]  ← 같은 객체이므로
== vs is ==은 값 비교, is는 객체 동일성 비교(같은 id인지). None, True, False 외엔 is를 거의 쓰지 않는다.

가변(mutable) vs 불변(immutable)

객체는 생성 후 내용을 바꿀 수 있는지에 따라 두 부류로 나뉜다. Python의 동작을 이해하는 핵심 개념이다.

불변 (Immutable)가변 (Mutable)
intlist
floatdict
complexset
boolbytearray
str사용자 정의 클래스 (대부분)
tuple
frozenset
bytes
NoneType
# 불변: 새 객체가 만들어진다
s = "hello"
print(id(s))      # 예: 140234...
s = s + " world"
print(id(s))      # 다른 id ← 새 문자열 객체

# 가변: 객체 내부가 바뀐다
lst = [1, 2, 3]
print(id(lst))    # 예: 140235...
lst.append(4)
print(id(lst))    # 같은 id ← 같은 객체

함수 인자 전달에 미치는 영향

Python은 참조에 의한 호출(pass by object reference)이다. 함수 내부에서 가변 객체를 변경하면 호출자도 영향을 받는다.

def modify_list(lst):
    lst.append(100)        # 객체를 직접 수정

def reassign_list(lst):
    lst = [9, 9, 9]        # 지역 이름을 다른 객체에 묶음 (호출자 영향 없음)

def modify_int(n):
    n = n + 1              # int는 불변, 새 객체. 호출자 영향 없음

a = [1, 2, 3]
modify_list(a)
print(a)        # [1, 2, 3, 100]  ← 바뀜

reassign_list(a)
print(a)        # [1, 2, 3, 100]  ← 그대로

x = 10
modify_int(x)
print(x)        # 10  ← 그대로

흔한 함정

기본 인자에 가변 객체

# 함정 — 기본 인자는 함수 정의 시 단 한 번만 평가된다
def add_item(item, target=[]):   # !! 위험
    target.append(item)
    return target

print(add_item(1))   # [1]
print(add_item(2))   # [1, 2]  ← 누적된다!
print(add_item(3))   # [1, 2, 3]
기본 인자로 list/dict를 절대 쓰지 말자 같은 객체를 재사용하므로 호출 간에 상태가 공유된다. None을 기본값으로 두고 함수 내부에서 새로 만든다. 
# 올바른 패턴
def add_item(item, target=None):
    if target is None:
        target = []
    target.append(item)
    return target

print(add_item(1))   # [1]
print(add_item(2))   # [2]  ← 매번 새로 만든다

is로 동등 비교

a = 1000
b = 1000
print(a == b)   # True
print(a is b)   # False (CPython 구현에 따라) ← 함정

# 작은 정수 캐싱 — CPython은 -5~256을 미리 만들어 둠
x = 100
y = 100
print(x is y)   # True ← 우연히 동작
x = 257
y = 257
print(x is y)   # False ← 캐싱 밖

# 문자열 인터닝도 비슷한 함정
s1 = "hello"
s2 = "hello"
print(s1 is s2)  # True (보통 인터닝)
s3 = "hello world!"
s4 = "hello world!"
print(s3 is s4)  # 구현 의존적
값 비교에는 절대 is를 쓰지 말자 is는 같은 객체인지를 보는 연산이다. 정수 캐싱·문자열 인터닝 때문에 우연히 동작할 수 있지만 구현 세부사항에 의존하면 안 된다. 값 비교는 ==, None·True·False 비교만 is.

float 직접 비교

# 함정
total = 0.0
for _ in range(10):
    total += 0.1
print(total)         # 0.9999999999999999
print(total == 1.0)  # False ← 함정

# 해결
import math
print(math.isclose(total, 1.0))  # True
print(abs(total - 1.0) < 1e-9)   # True

얕은 복사 vs 깊은 복사

import copy

original = [[1, 2], [3, 4]]

shallow = copy.copy(original)        # 또는 list(original), original[:]
deep    = copy.deepcopy(original)

original[0].append(99)
print(shallow)   # [[1, 2, 99], [3, 4]]  ← 내부 리스트는 공유
print(deep)      # [[1, 2], [3, 4]]      ← 완전히 독립
중첩 자료구조 복사는 deepcopy list(x), x[:], x.copy()는 한 단계만 복사한다. 내부에 또 가변 객체가 있으면 copy.deepcopy를 쓴다.
