공간 필터링이란?

공간 필터링(spatial filtering)은 픽셀 하나를 그 픽셀 자신만 보고 바꾸는 것이 아니라, 주변 이웃 픽셀까지 함께 보고 새 값을 계산하는 처리다. 밝기 조정이나 이진화처럼 픽셀을 독립적으로 다루는 점 연산(point operation)과 구별된다.

핵심 도구는 커널(kernel)이라 부르는 작은 행렬이다. 보통 3×3, 5×5처럼 작은 정사각형이다. 이 커널을 이미지 위에서 한 칸씩 미끄러뜨리며(sliding), 커널이 덮은 영역의 픽셀들과 커널 계수를 곱해 더한 값을 중심 픽셀의 새 값으로 삼는다. 이 연산이 합성곱(convolution)이다.

커널의 계수를 어떻게 채우느냐에 따라 블러(흐림), 샤프닝(선명화), 엣지 검출 등 전혀 다른 효과가 나온다. 이 글에서는 그중 노이즈 제거에 쓰이는 블러 계열 필터를 집중적으로 다룬다.

"공간"이라는 이름의 뜻 이미지의 가로·세로 평면, 즉 픽셀이 놓인 공간 영역에서 직접 연산하기 때문에 공간 필터링이라 부른다. 푸리에 변환을 거쳐 주파수 영역에서 처리하는 주파수 필터링과 대비되는 용어다.

합성곱과 커널

합성곱의 동작을 그림으로 보면 직관적이다. 3×3 커널이 이미지 위를 한 칸씩 이동하며, 매 위치에서 겹친 9개 픽셀과 커널 9개 계수를 각각 곱해 모두 더한 값이 중심 픽셀의 출력이 된다.

합성곱: 커널이 이미지 위를 슬라이딩하며 겹친 픽셀과 계수를 곱해 더한 값을 출력으로 낸다.

커널 크기와 정규화

커널이 클수록 더 넓은 이웃을 평균하므로 효과가 강해진다. 3×3보다 7×7이 훨씬 더 흐려진다. 그리고 블러 커널은 계수의 합이 1이 되도록 정규화해야 한다. 합이 1보다 크면 결과가 밝아지고, 작으면 어두워진다. 3×3 평균 커널의 계수가 모두 1/9인 이유다.

filter2D로 커스텀 커널 적용

OpenCV는 임의의 커널을 직접 만들어 적용하는 filter2D를 제공한다. 커널을 cv::Mat으로 정의하고 넘기면 된다.

#include <opencv2/opencv.hpp>

int main()
{
    cv::Mat src = cv::imread("part.png", cv::IMREAD_GRAYSCALE);
    if (src.empty())
    {
        std::cerr << "이미지를 열 수 없습니다." << std::endl;
        return -1;
    }

    // 3x3 평균 커널을 직접 만든다 (계수 합 = 1)
    cv::Mat kernel = cv::Mat::ones(3, 3, CV_32F) / 9.0f;

    cv::Mat dst;
    // ddepth = -1 은 입력과 같은 깊이로 출력
    cv::filter2D(src, dst, -1, kernel);

    cv::imwrite("part_avg.png", dst);
    return 0;
}

커널 계수만 바꾸면 같은 filter2D로 샤프닝도 된다. 중심을 키우고 주변을 음수로 두면 엣지가 강조된다.

// 샤프닝 커널 — 중심 강조, 주변 차감 (계수 합 = 1)
cv::Mat sharpen = (cv::Mat_<float>(3, 3) <<
     0, -1,  0,
    -1,  5, -1,
     0, -1,  0);

cv::Mat sharpened;
cv::filter2D(src, sharpened, -1, sharpen);
전용 함수가 있으면 그것을 쓴다 평균·가우시안 블러는 filter2D로도 만들 수 있지만, OpenCV의 전용 함수(blur, GaussianBlur)는 분리 가능 커널(separable kernel) 최적화가 들어 있어 훨씬 빠르다. 커스텀 커널이 꼭 필요할 때만 filter2D를 쓴다.

평균 블러 (blur / boxFilter)

평균 블러는 가장 단순한 블러다. 커널 영역 안의 모든 픽셀을 똑같은 가중치로 평균낸다. 박스 모양으로 균등하게 평균한다고 해서 박스 필터(box filter)라고도 부른다.

cv::Mat src = cv::imread("part.png");
cv::Mat dst;

// 5x5 영역을 균등 평균. 커널 크기는 cv::Size(width, height)
cv::blur(src, dst, cv::Size(5, 5));

// boxFilter는 정규화 여부를 직접 제어할 수 있다
cv::Mat boxed;
cv::boxFilter(src, boxed, -1, cv::Size(5, 5), cv::Point(-1, -1),
              true);   // normalize = true 면 blur와 동일

blur는 항상 정규화된 평균이고, boxFilter는 normalize 인자로 정규화를 끌 수 있다. 정규화를 끄면 단순 합이 되어 결과가 매우 밝아진다.

평균 블러는 매우 빠르지만 단점이 뚜렷하다. 엣지 근처의 픽셀도 배경과 똑같이 평균해 버리므로 경계가 함께 뭉개진다. 또 커널이 사각형이라 결과에 약한 격자 모양 아티팩트가 생길 수 있다. 노이즈를 빠르게 줄이는 용도로는 쓸 만하지만, 품질이 중요하면 가우시안 블러가 낫다.

평균 블러는 엣지를 보존하지 못한다 엣지 위의 픽셀을 주변과 균등 평균하면 밝은 쪽과 어두운 쪽이 섞여 경계가 흐려진다. 검사 대상의 윤곽이 중요하다면 평균 블러는 피한다.

가우시안 블러 (GaussianBlur)

가우시안 블러는 평균 블러와 달리 거리에 따라 가중치를 다르게 준다. 중심 픽셀에 가까울수록 큰 가중치, 멀수록 작은 가중치를 주는데, 그 가중치 분포가 종 모양의 가우시안 함수를 따른다. 그래서 가까운 이웃이 결과에 더 크게 반영되어 평균 블러보다 자연스럽게 흐려진다. 노이즈 제거의 사실상 기본값이다.

cv::Mat src = cv::imread("part.png");
cv::Mat dst;

// 커널 크기 (홀수), sigmaX, sigmaY
cv::GaussianBlur(src, dst, cv::Size(5, 5), 1.5);

// sigma = 0 이면 커널 크기에서 sigma를 자동 계산한다
cv::Mat autoSigma;
cv::GaussianBlur(src, autoSigma, cv::Size(7, 7), 0);

sigma와 커널 크기의 관계

sigma(표준편차)는 가우시안 종 모양이 얼마나 넓게 퍼지는지를 결정한다. sigma가 크면 가중치가 멀리까지 고르게 퍼져 더 강하게 흐려지고, sigma가 작으면 중심에 집중되어 약하게 흐려진다.

sigma와 커널 크기는 서로 맞물려야 한다. 가우시안 곡선은 대략 중심에서 3·sigma 거리를 넘으면 거의 0이 된다. 커널이 그보다 작으면 곡선의 꼬리가 잘려 효과가 제대로 안 나고, 커널이 sigma에 비해 너무 크면 0에 가까운 계수만 계산하느라 느려진다. 경험칙으로 커널 크기는 대략 6·sigma + 1 근처가 적당하다.

sigma = 0 의 자동 계산 GaussianBlur에 sigma를 0으로 주면 OpenCV가 커널 크기로부터 적절한 sigma를 역산한다(sigma = 0.3·((ksize-1)·0.5 - 1) + 0.8). 커널 크기만 신경 쓰고 싶을 때 편하다. 반대로 sigma만 주고 커널 크기를 cv::Size(0, 0)으로 두면 sigma에서 커널 크기를 자동 계산한다.

미디언 블러 (medianBlur)

미디언 블러는 평균이 아니라 중앙값(median)을 쓴다. 커널 영역 안의 픽셀들을 크기순으로 정렬해 가운데 값을 중심 픽셀에 넣는다. 곱셈·덧셈으로 새 값을 "만들어내는" 합성곱과 달리, 미디언 블러는 원래 있던 픽셀값 중 하나를 그대로 고르는 비선형 필터다.

이 성질이 salt-and-pepper 노이즈(소금·후추 노이즈, 흰·검은 점이 흩뿌려진 잡음)에 특히 강한 이유다. 0이나 255 같은 극단적인 이상치는 정렬했을 때 양 끝으로 밀려나고, 가운데 값으로는 선택되지 않는다. 평균 블러였다면 이 극단값이 평균을 끌어당겨 점이 흐릿하게 번지지만, 미디언은 아예 무시한다.

cv::Mat src = cv::imread("noisy_part.png");
cv::Mat dst;

// ksize는 1보다 큰 홀수. cv::Size가 아니라 정수 하나
cv::medianBlur(src, dst, 5);   // 5x5 영역의 중앙값

주의할 점이 두 가지 있다. 첫째, 인자가 cv::Size가 아니라 정수 하나다(항상 정사각형, 홀수). 둘째, 컬러 이미지에 적용하면 채널별로 따로 중앙값을 구한다. B·G·R 각 채널에서 독립적으로 median을 뽑으므로, 원본에 없던 색 조합이 결과에 나타날 수 있다.

미디언 블러는 엣지 보존이 평균·가우시안보다 우수하다. 계단형 엣지에서 중앙값은 밝은 쪽이나 어두운 쪽 중 한쪽 값을 그대로 고르는 경향이 있어 경계가 덜 번진다.

양방향 필터 (bilateralFilter)

지금까지의 필터는 공간적 거리만 봤다. 가까운 픽셀이면 엣지든 배경이든 가리지 않고 섞었다. 양방향 필터(bilateral filter)는 여기에 한 가지 조건을 더한다 — 밝기 차이도 같이 본다.

두 가지 가중치를 곱해서 쓴다. 하나는 공간 거리에 따른 가중치(가까울수록 큼), 다른 하나는 밝기 차이에 따른 가중치(밝기가 비슷할수록 큼)다. 결과적으로 "가깝고 + 밝기도 비슷한" 픽셀만 평균에 크게 반영된다. 엣지 건너편의 픽셀은 거리가 가까워도 밝기가 크게 다르므로 가중치가 거의 0이 되어 무시된다. 그래서 엣지는 살리면서 평탄한 영역의 노이즈만 제거하는, 두 마리 토끼를 잡는 필터다.

cv::Mat src = cv::imread("part.png");
cv::Mat dst;

// d: 이웃 픽셀 지름 (양수면 그대로, 음수면 sigmaSpace에서 계산)
// sigmaColor: 밝기 차이 허용 폭 (클수록 더 넓은 밝기 차이도 섞음)
// sigmaSpace: 공간적 거리 영향 범위
cv::bilateralFilter(src, dst, 9, 75.0, 75.0);

sigmaColor가 클수록 밝기 차이를 너그럽게 봐서 엣지 보존이 약해지고, 작을수록 엣지를 칼같이 지킨다. sigmaSpace는 공간적 영향 범위이고, d는 실제로 고려할 이웃 픽셀의 지름이다.

양방향 필터는 느리다 픽셀마다 공간 가중치와 밝기 가중치를 모두 계산하므로 가우시안 블러보다 수십 배 느리다. 실시간 영상 루프에서는 d를 작게 잡거나, 입력을 축소한 뒤 처리하거나, 미리보기에만 쓰는 식으로 타협한다. 정지 이미지의 후처리에는 품질이 좋아 자주 쓴다.

경계 처리 (BorderTypes)

커널이 이미지 가장자리에 오면 문제가 생긴다. 3×3 커널의 중심이 맨 윗줄 픽셀에 있으면, 커널의 윗줄은 이미지 밖을 가리킨다. 존재하지 않는 픽셀값을 어떻게 채울지를 정하는 것이 경계 처리(border handling)다.

OpenCV의 모든 필터 함수는 borderType 인자를 받는다. 기본값은 보통 BORDER_DEFAULT(= BORDER_REFLECT_101)다.

BorderType이미지 밖을 채우는 방식가장자리 픽셀 abc | 채움
BORDER_REPLICATE가장자리 픽셀을 그대로 복제aaaaaa | abc...
BORDER_REFLECT가장자리를 거울처럼 반사 (경계 포함)cba | abc...
BORDER_REFLECT_101가장자리 픽셀을 빼고 반사 (기본값)dcb | abc...
BORDER_CONSTANT고정 상수값으로 채움 (보통 0)000000 | abc...
BORDER_WRAP반대쪽 가장자리에서 가져옴...xyz | abc...
cv::Mat src = cv::imread("part.png");
cv::Mat reflect, replicate, constant;

// 기본값 — 가장자리를 반사 (대부분 무난)
cv::GaussianBlur(src, reflect, cv::Size(5, 5), 1.5,
                 1.5, cv::BORDER_REFLECT_101);

// 가장자리 픽셀을 그대로 늘림
cv::GaussianBlur(src, replicate, cv::Size(5, 5), 1.5,
                 1.5, cv::BORDER_REPLICATE);

// 이미지 밖을 0(검정)으로 채움 — 가장자리가 어두워질 수 있음
cv::GaussianBlur(src, constant, cv::Size(5, 5), 1.5,
                 1.5, cv::BORDER_CONSTANT);
BORDER_CONSTANT는 가장자리에 인공적인 어둠을 만든다 이미지 밖을 0으로 채우면 밝은 객체의 가장자리가 검정과 평균되어 어두운 테두리가 생긴다. 검사 대상이 이미지 경계에 닿아 있다면 BORDER_REFLECT_101이나 BORDER_REPLICATE가 더 안전하다.

필터별 비교

네 가지 블러 필터는 각각 장단점이 뚜렷하다. 노이즈의 종류와 엣지 보존 요구, 속도 제약에 따라 골라 쓴다.

필터OpenCV 함수속도엣지 보존적합한 노이즈
평균 블러blur / boxFilter매우 빠름나쁨가벼운 가우시안 노이즈, 빠른 처리 우선
가우시안 블러GaussianBlur빠름보통일반적인 가우시안 노이즈 (가장 무난)

양방향 필터bilateralFilter느림매우 좋음엣지 보존이 필수인 노이즈 제거

실무 선택의 큰 줄기는 이렇다. 속도가 가장 중요하면 평균 블러, 특별한 요구가 없으면 가우시안 블러, 흰·검은 점 잡음이면 미디언 블러, 엣지를 반드시 살려야 하면 양방향 필터다. 가우시안 블러가 가장 자주 쓰이는 기본값이고, 나머지는 상황이 명확할 때 꺼내 쓴다.

산업 검사 관점

산업용 비전에서 블러는 보통 검사 본 처리의 전처리 단계에 들어간다. 카메라 센서 노이즈, 조명의 미세한 떨림, 표면의 작은 텍스처가 그대로 남으면 임계값 처리나 엣지 검출에서 거짓 신호가 튀어나온다. 적절한 블러로 이런 고주파 잡음을 먼저 눌러주면 뒤 단계가 안정된다.

다만 블러는 본질적으로 정보를 깎아내는 연산이다. 노이즈만 골라서 지우는 것이 아니라 미세한 디테일을 함께 잃는다. 산업 검사에서 찾으려는 결함 — 머리카락 같은 스크래치, 작은 기공, 미세한 치수 편차 — 은 종종 노이즈와 비슷한 크기의 고주파 신호다.

과도한 블러는 결함도 함께 지운다 커널을 크게 잡거나 sigma를 키우면 노이즈는 깨끗하게 사라지지만, 정작 검출해야 할 미세 결함까지 배경에 녹아버린다. 검사 시스템에서 블러 강도는 "노이즈는 줄이되 최소 결함 크기는 살아남는" 선에서 신중히 튜닝해야 하는 파라미터다.

실무 가이드라인 몇 가지를 정리한다.

  • 블러 커널 크기는 검출해야 할 최소 결함 크기보다 작게 잡는다. 결함이 3~4 픽셀이면 5×5 이상은 위험하다.
  • 센서의 임펄스 노이즈(불량 픽셀, 흰·검은 점)에는 가우시안보다 미디언 블러가 결함 손실이 적다.
  • 치수 측정처럼 엣지 위치 정확도가 중요한 검사에는 양방향 필터로 엣지를 보존하며 노이즈만 제거한다.
  • 블러는 가능한 한 관심 영역(ROI)에만 적용해 처리 비용과 정보 손실을 모두 줄인다.

흔한 함정

블러 계열 함수에서 거의 모두가 한 번씩 밟는 함정들이다.

커널 크기는 홀수여야 한다

짝수 커널은 중심 픽셀이 없다 커널에는 출력이 매핑될 중심 픽셀이 하나 있어야 한다. 3, 5, 7처럼 홀수여야 가운데가 정확히 한 칸으로 정해진다. GaussianBlur에 짝수 크기를 주면 예외가 발생하고, medianBlur도 1보다 큰 홀수만 받는다.

cv::Mat dst;

// 나쁨 — 짝수 커널, 런타임 예외 발생
// cv::GaussianBlur(src, dst, cv::Size(4, 4), 1.0);

// 좋음 — 홀수 커널
cv::GaussianBlur(src, dst, cv::Size(5, 5), 1.0);

// medianBlur는 정수 하나, 1보다 큰 홀수만 허용
cv::medianBlur(src, dst, 5);

과도한 블러로 인한 정보 손실

"노이즈가 안 보일 때까지" 커널을 키우다 보면 어느새 엣지와 디테일까지 다 사라진다. 블러는 노이즈를 선택적으로 지우지 못한다 — 고주파 성분을 통째로 깎는다. 노이즈가 충분히 줄어드는 가장 작은 커널에서 멈추는 것이 원칙이다.

// 나쁨 — 21x21 은 대부분의 산업 검사에서 과하다
// cv::GaussianBlur(src, dst, cv::Size(21, 21), 0);

// 좋음 — 작게 시작해서 필요한 만큼만 키운다
cv::GaussianBlur(src, dst, cv::Size(3, 3), 0);

가우시안 sigma = 0의 동작 오해

sigma = 0 은 "블러 없음"이 아니다 GaussianBlur의 sigma에 0을 주면 블러가 꺼지는 게 아니라, OpenCV가 커널 크기로부터 sigma를 자동 계산한다. 블러를 끄려면 함수 자체를 호출하지 않아야 한다. sigma를 직접 제어하고 싶으면 반드시 양수를 명시한다. 
// sigma = 0 → 커널 크기 7x7 기준으로 sigma 자동 계산 (블러 적용됨)
cv::GaussianBlur(src, dst, cv::Size(7, 7), 0);

// sigma 를 직접 지정 → 의도한 강도로 제어
cv::GaussianBlur(src, dst, cv::Size(7, 7), 1.8);

미디언 블러는 컬러에 채널별로 적용된다

medianBlur를 3채널 이미지에 쓰면 B·G·R 각 채널에서 독립적으로 중앙값을 구한다. 한 픽셀의 출력 B값과 G값이 서로 다른 원본 픽셀에서 왔을 수 있다는 뜻이다. 그래서 원본에 존재하지 않던 색 조합이 결과에 나타날 수 있다. 색의 일관성이 중요하면 그레이스케일에서 처리하거나 다른 필터를 고려한다.

cv::Mat color = cv::imread("part.png");          // CV_8UC3
cv::Mat result;
cv::medianBlur(color, result, 5);
// → B, G, R 각각 따로 median. 채널 간 정렬이 깨질 수 있음

// 색 일관성이 중요하면 그레이스케일에서 처리
cv::Mat gray;
cv::cvtColor(color, gray, cv::COLOR_BGR2GRAY);
cv::medianBlur(gray, result, 5);
정리하면 커널 크기는 홀수로, 가장 작은 크기에서 시작해 필요한 만큼만 키운다. 가우시안 sigma는 의도가 있으면 직접 명시하고, 미디언을 컬러에 쓸 때는 채널별 처리라는 점을 기억한다. 산업 검사에서는 "노이즈는 줄이되 결함은 살린다"가 블러 튜닝의 한 줄 원칙이다.
