월간 트렌드 브리핑 — 2026년 8월호

2026-08-03 약 10분 분량 월간 트렌드 브리핑
이번 호 안내 세 번째 호다. 지난 호(7월호)가 7월 중순까지를 담았으므로, 이번 호는 그 뒤인 7월 중순부터 8월 초까지의 흐름을 정리한다. 이번 구간의 특징은 "정식 출시"보다 "가격·운영 방식의 변화"가 두드러졌다는 점이다 — 새 모델(Opus 5)과 파격적인 가격 인하(GPT-5.6), 그리고 계속 밀리는 출시(Gemini 3.5 Pro)가 나란히 자리했다.

이달의 헤드라인

  • Claude Opus 5, Fable 5급 성능을 절반 가격에. 7월 24일 출시됐으며 입력 $5·출력 $25(1M 토큰당, 전작 Opus 4.8과 동일 가격)로 Fable 5에 근접한 코딩·지식 작업 성능을 낸다고 보도된다. 작업마다 사고 강도(저·중·고)를 고르는 이펙트 토글이 특징이다.
  • GPT-5.6, 파격적인 가격 인하. 7월 30일부터 Luna 가격이 80%, Terra 가격이 20% 내렸다. Luna는 입력 $0.20·출력 $1.20(1M 토큰당)로 현존 프런티어급 모델 중 최저가 수준에 들어섰다는 평이다.
  • Gemini 3.5 Pro, 세 번째 연기. 6월 목표에서 7월 17일로, 다시 밀렸다. DeepMind가 환각률·신뢰성 이슈로 베이스 모델을 재구축했다는 보도가 있다. Google은 대신 Flash 계열 3종을 7월 21일 공개했다.

프런티어 모델 동향

7월 중순부터 8월 초 사이는 신규 출시보다 가격 경쟁과 지연이 두드러진 구간이다. 랩별로 정리하면 이렇다.

Anthropic — Opus 5로 "가성비 최상위" 자리 노려

Claude Opus 5가 7월 24일 나왔다. Fable 5와 견줄 만한 코딩·지식 작업 성능을 절반 수준 가격대에서 제공한다고 보도되며, 사이버보안 등 일부 과제에서는 여전히 Fable 5가 앞선다는 평가도 함께 나왔다. 저·중·고 세 단계로 사고 강도를 조절할 수 있어 비용과 성능을 상황에 맞게 조절하는 용도로 설명된다. 지난 호에서 다룬 Sonnet 5(기본 모델)에 이어, Anthropic 라인업이 Haiku 4.5·Sonnet 5·Opus 5·Fable 5 네 단으로 다시 정돈된 모습이다.

OpenAI — GPT-5.6 가격 대폭 인하

7월 9일 정식 공개된 GPT-5.6 패밀리(Sol·Terra·Luna)의 가격이 7월 30일부터 크게 내렸다 — Luna는 80%, Terra는 20% 인하됐다. API 기준 Terra는 입력 $2·출력 $12, Luna는 입력 $0.20·출력 $1.20(1M 토큰당)으로 보도된다. 최상위 Sol은 LiveBench 수학·추론, ARC-AGI-2 등 여러 지표에서 선두로 소개된다.

Google·xAI — Gemini 3.5 Pro 세 번째 연기, Flash 계열로 우회

Gemini 3.5 Pro는 5월 I/O에서 예고된 뒤 6월→7월 17일→그 이후로 계속 밀리는 중이다. 환각률과 실사용 신뢰성 목표에 못 미쳐 DeepMind가 베이스 모델을 다시 만들었다는 보도가 있으며, 확정된 공개일은 아직 없다. 대신 Google은 7월 21일 Gemini 3.6 Flash·3.5 Flash-Lite·Flash Cyber 세 모델을 공개해 하위 라인업부터 채웠다.

벤치마크 수치는 그대로 믿지 않는다 이 글의 성능·순위·연기 사유 언급은 8월 초 시점의 외부 보도와 서드파티 비교를 근거로 한 것이며, 측정 방식·버전·시점에 따라 출렁인다. 절대값보다 "어느 방향으로 움직였나"를 보는 게 안전하고, 정확한 사양은 각 랩의 공식 발표를 확인한다.

코딩 에이전트 — Claude Code vs Codex

지난 호의 결론("둘 다 쓴다")은 이번 달에도 유효하다. 이번 구간의 특징은 두 도구가 "백그라운드 실행"이라는 같은 방향으로 움직였다는 점이다 — Claude Code는 코드 리뷰를, Codex는 보안 스캔을 각각 메인 작업을 막지 않는 형태로 내놓았다.

SWE-bench Verified 같은 종합 지표는 여전히 근소 차(1점 안팎)로 접전이지만, 세부 지표로 들어가면 성격이 갈린다 — Codex는 짧은 호흡의 터미널형 작업에, Claude Code는 긴 호흡의 다중 파일·대형 코드베이스 작업에 강하다는 서드파티 비교가 반복적으로 나온다. 장문맥 검색(MRCR) 벤치에서도 Claude 계열이 100만 토큰 구간에서 큰 격차로 앞선다는 보도가 있다.

현장 컨센서스 — "짧고 빠른 작업엔 Codex, 길고 복잡한 작업엔 Claude Code"라는 역할 분담이 이번 구간에도 이어진다. 다만 둘 다 "메인 작업을 막지 않는 백그라운드 실행"을 핵심 방향으로 잡은 점은 눈여겨볼 만하다 — 도구 경쟁의 축이 "무엇을 더 잘하냐"에서 "내 작업 흐름을 얼마나 안 끊느냐"로 옮겨 가는 신호로 읽힌다.

도구·기능 업데이트

7월 중순부터 8월 초까지 두 도구의 변경 이력에서 눈에 띄는 항목을 추린다.

Claude Code — 백그라운드 리뷰·서브에이전트·Opus 5 기본화

7월 22일(v2.1.218) /code-review가 백그라운드 서브에이전트로 실행되도록 바뀌어, 리뷰 작업이 더는 대화창을 채우지 않는다. 이어 7월 24일(v2.1.220)에는 Opus 5가 기본 Opus 모델로 지정됐고, 동적 워크플로와 중첩 서브에이전트가 확장됐다. /fork가 현재 대화를 새 백그라운드 세션으로 복제하는 기능도 추가됐다(원래 세션은 계속 사용 가능). 그 외 WebSearch 호출 세션당 한도(기본 200회, CLAUDE_CODE_MAX_WEB_SEARCHES_PER_SESSION로 조정 가능), 게시된 아티팩트가 볼 때마다 MCP 커넥터의 실시간 데이터를 불러오는 기능, 스크린 리더 모드도 함께 들어왔다.

Codex — 보안 CLI 오픈소스 + 데스크톱 앱 강화

7월 29일 OpenAI가 Codex Security CLI를 오픈소스로 공개했다. 저장소 스캔, 실행 간 발견 사항 추적, 수정 검증, CI/CD 보안 체크 추가를 지원한다. 데스크톱 앱은 브라우징·코드 리뷰·이미지 편집 속도가 개선됐고, 다중 저장소 diff 리뷰, 확장된 이미지 뷰어, Activity 뷰, ChatGPT Voice, 다중 폴더 프로젝트 지원이 더해졌다. Codex와 ChatGPT Work 합산 활성 사용자는 7월 중 800만 명을 넘어선 것으로 보도된다.

읽는 법 이번 달은 "새 모델"보다 "가격"과 "백그라운드 실행"이라는 두 축이 더 크게 움직였다. Opus 5와 GPT-5.6 가격 인하는 같은 성능을 더 싸게 쓰는 쪽으로, Claude Code·Codex의 백그라운드 기능들은 에이전트를 계속 켜둔 채 다른 작업을 하는 쪽으로 흐른다. 두 흐름 모두 "AI 도구를 상시 켜 두고 쓰는 비용"을 낮추는 방향이라는 공통점이 있다.
