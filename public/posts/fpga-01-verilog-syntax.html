C++이나 Python을 알고 있다면 Verilog 문법은 생긴 건 비슷한데 동작 방식이 꽤 다르다. 변수가 아닌 신호선을 선언하고, 함수 호출 대신 항상 켜져 있는 회로를 기술한다. 이 글은 그 차이를 중심으로 자주 쓰는 문법을 정리한다.

예제는 SystemVerilog를 기준으로 한다. SystemVerilog는 Verilog의 상위 집합으로, always_ff·always_comb·logic 같은 키워드가 추가돼 실수하기 어려운 구조를 잡아준다. 요즘 FPGA 도구는 대부분 SystemVerilog를 지원한다.

1. 모듈 — 함수도 클래스도 아님

Verilog의 기본 단위는 모듈이다. 생긴 건 함수 선언과 비슷하지만, 호출해서 실행하는 게 아니라 항상 존재하는 회로를 정의하는 것이다.

module adder #(
    parameter WIDTH = 8        // 합성 시점 상수 (C++ template 인자와 비슷)
)(
    input  wire [WIDTH-1:0] a,
    input  wire [WIDTH-1:0] b,
    output wire [WIDTH-1:0] result
);
    assign result = a + b;
endmodule

parameter는 런타임 변수가 아니라 합성 시점에 고정되는 값이다. 같은 모듈을 WIDTH=8짜리, WIDTH=16짜리 회로로 각각 찍어낼 수 있다. C++ 템플릿의 비형식 인자(template<int N>)와 같은 개념이다.

모듈 인스턴스화 다른 모듈 안에서 모듈을 쓸 때는 이름과 포트를 연결해 인스턴스를 만든다. C++ 객체 생성과 비슷하지만, 실행하는 게 아니라 회로를 배선하는 것이다. 
adder #(.WIDTH(16)) u_add (
    .a(data_a), .b(data_b), .result(sum)
);

2. wire vs reg

Verilog에는 두 가지 신호 타입이 있다.

타입용도대입 방법
wire 조합 논리 결과선, 모듈 간 연결 assign문으로만
reg always 블록 안에서 쓰는 변수 always 블록 안에서 
wire [7:0] combo_out;   // assign으로만 구동
reg  [7:0] ff_out;      // always 블록 안에서 구동
reg라고 항상 FF가 되는 건 아님 reg는 타입 이름이 혼란스럽다. always_comb 안에서 쓰면 조합 논리로 합성되고, always_ff 안에서 쓰면 플립플롭(FF)으로 합성된다. 이름보다 어떤 always 블록에서 쓰이느냐가 회로 구조를 결정한다. 이 때문에 SystemVerilog에서는 logic이라는 타입으로 통합해 혼란을 줄였다.

3. assign — 항상 켜져 있는 연결

assign out = a & b;     // a나 b가 바뀌는 순간 out도 즉시 바뀜
assign mux  = sel ? a : b;  // 삼항 연산자도 자주 씀

함수 호출이 아니라 전선을 연결하는 것이다. 클럭이 없고, 입력이 바뀌면 출력이 즉시 따라 바뀐다. 이렇게 클럭 없이 입력에서 출력이 바로 나오는 회로를 조합 논리라고 한다.

4. always 블록 — 두 종류

always 블록은 두 가지 용도로 쓴다. 어떤 것을 쓰느냐가 회로 구조를 결정한다.

조합 논리용: always_comb

// 입력이 바뀔 때마다 실행 — FF 없음
always_comb begin
    if (sel)  out = a;
    else      out = b;
end

assign보다 복잡한 조합 논리를 표현할 때 쓴다. if/case를 쓸 수 있어서 조건이 여러 개일 때 유용하다. assign과 마찬가지로 클럭이 없고 입력에 즉시 반응한다.

순차 논리용: always_ff

// 클럭 상승 에지에서만 실행 — FF 생성
always_ff @(posedge clk) begin
    if (rst)  q <= 8'h00;
    else      q <= d;
end

posedge clk은 클럭 신호가 0→1로 올라가는 순간을 뜻한다. 이 순간에만 실행된다. 여기서 대입된 값은 FF에 저장되고, 다음 클럭 때까지 유지된다.

always_combalways_ff
실행 시점입력이 바뀔 때마다클럭 상승 에지에만
생성되는 회로조합 논리플립플롭(FF)
상태 저장없음있음 (클럭 간 유지)
대입 연산자=<=

5. = vs <= — 가장 중요한 차이

FPGA 개발에서 처음 접하는 가장 큰 함정이다. 같은 always_ff 블록 안에서도 어떤 대입 연산자를 쓰느냐에 따라 합성되는 회로가 달라진다.

= (blocking): 순차 대입

always_ff @(posedge clk) begin
    a = b + 1;   // a가 즉시 바뀜
    c = a + 1;   // 이미 바뀐 a를 씀 → 의도와 다른 회로
end

위에서 아래로 순서대로 실행된다. 두 번째 줄에서 a는 이미 갱신된 값이다. C++과 같은 방식이지만, always_ff 안에서 이렇게 쓰면 안 된다.

<= (non-blocking): 동시 대입

always_ff @(posedge clk) begin
    a <= b + 1;  // 클럭 전의 b로 계산
    c <= a + 1;  // 클럭 전의 a로 계산 → 의도대로
end

모든 우변을 먼저 평가한 뒤 클럭 상승 에지에서 동시에 대입한다. 두 번째 줄의 a는 이번 클럭 이전의 값이다. 이것이 실제 하드웨어 동작과 일치한다.

규칙: always_ff 안에서는 무조건 <= =를 써도 합성은 되지만 회로가 달라진다. 타이밍 분석도 틀어진다. 예외 없이 <=만 쓰는 것을 습관으로 만들어야 한다.

6. 비트 표기와 연산

Verilog에서 숫자는 비트 폭을 명시하는 게 원칙이다.

4'b1010    // 4비트 2진수 → 10
8'hFF      // 8비트 16진수 → 255
16'd100    // 16비트 10진수 → 100

비트를 잘라내거나 이어 붙이는 연산도 자주 쓴다.

wire [7:0] data = 8'hA5;

// 슬라이싱
wire [3:0] high = data[7:4];  // 상위 4비트 → 4'hA
wire [3:0] low  = data[3:0];  // 하위 4비트 → 4'h5
wire       msb  = data[7];    // 1비트 추출

// 연결 (concatenation) — C++에 없는 연산
wire [7:0] swapped = {low, high};  // 하위와 상위를 바꿔서 붙임 → 8'h5A
wire [8:0] extended = {1'b0, data}; // 0을 앞에 붙여 9비트로 확장

{}는 비트열을 이어 붙이는 연산자다. 여러 신호를 묶어서 하나의 넓은 버스로 만들거나, 비트 확장에 많이 쓴다.

7. case — default 필수

always_comb begin
    case (sel)
        2'b00: out = a;
        2'b01: out = b;
        2'b10: out = c;
        default: out = 8'h00;  // 반드시 있어야 함
    endcase
end
default를 빠뜨리면 래치가 생김 default가 없으면 합성 도구가 "이 조건에선 값을 유지해야 하나?"로 해석해서 의도하지 않은 래치(latch)를 만든다. 래치는 FF와 비슷하지만 클럭이 아닌 레벨로 동작해서 타이밍 분석이 훨씬 복잡해진다. always_comb 안에서는 항상 default를 넣는다.

8. generate — 합성 시점 루프

genvar i;
generate
    for (i = 0; i < 8; i = i + 1) begin : gen_xor
        assign out[i] = in[i] ^ mask[i];
    end
endgenerate

런타임에 반복하는 게 아니라 같은 회로를 N벌 찍어내는 것이다. 합성이 끝나면 루프는 사라지고 병렬 회로 8개만 남는다. 비슷한 구조의 회로를 여러 개 만들 때 코드를 반복하지 않아도 된다.

generate vs 런타임 루프 C++의 constexpr for나 템플릿 메타프로그래밍과 비슷하다. 컴파일 타임에 코드가 펼쳐지는 것처럼, generate 루프도 합성 시점에 회로로 펼쳐진다. 실제로 동작할 때는 루프가 없고 병렬 회로가 동시에 작동한다.
