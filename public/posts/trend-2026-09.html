월간 트렌드 브리핑 — 2026년 9월호

2026-09-08 약 11분 분량 월간 트렌드 브리핑
이번 호 안내 네 번째 호다. 지난 호(8월호)가 8월 초까지를 담았으므로, 이번 호는 8월 전체와 9월 초(9/8)까지의 흐름을 정리한다. 8월은 비교적 조용하다가 9월 첫째 주에 프런티어 모델 두 개(Claude Fable 5.1, GPT-6 Astra)가 이틀 간격으로 연달아 나왔고, Gemini 3.5 Pro는 이번 달에도 감감무소식이었다. 그 사이 Anthropic 쪽에서는 대규모 장애·기업 파트너십·물리 세계 확장 같은 모델 바깥의 소식도 많았다.

  • Google — Gemini 3.5 Pro가 이번 달에도 출시일을 못 잡았다. 6월→7월 중순→8월 초로 밀려온 목표가 9월 초 시점에도 확정되지 않은 상태

이달의 헤드라인

  • GPT-6 Astra, 첫 "Critical" 사이버보안 등급 모델로 출시. 9월 2일 공개됐으며, OpenAI 준비 프레임워크 기준으로 사이버보안 위험이 "Critical" 문턱을 넘은 첫 모델이라고 밝혔다. 사람 개입 없이 제로데이 취약점을 찾고 만들 수 있는 수준이라, 별도 가드레일을 얹은 버전을 유료 사용자에게 제공한다고 보도된다.
  • Claude Fable 5.1 공개, 가격은 25% 저렴하게. 9월 1일 나왔으며, 캐시 읽기 가격 인하로 Fable 5 대비 약 25% 저렴한 것으로 보도된다. 모호한 작업에서의 판단력이 좋아지고 자신 있게 틀리는 답이 줄었다는 설명과 함께, 여러 벤치마크에서 Fable 5·Opus 5·GPT-5.6 Sol을 앞섰다는 보도가 나왔다.
  • Gemini 3.5 Pro, 이번 달에도 출시일 못 잡아. 6월→7월 중순→8월 초로 밀려온 목표가 9월 초 시점까지도 확정되지 않았다. 환각률·신뢰성 목표 미달로 DeepMind가 베이스 모델을 다시 만들었다는 보도가 이어지고 있다.
  • Claude, 8월 16일 36분간 인증 장애. Claude.ai·Claude Code·Claude Cowork가 함께 영향을 받았다. 원인은 인증 시스템 장애로 파악됐으나 근본 원인은 공개되지 않았고, 최근 30일간 상업판이 28회 다운됐다는 지적도 함께 나왔다.

프런티어 모델 동향 — Fable 5.1·GPT-6 Astra·Gemini의 공백

8월 한 달은 신규 모델 출시 없이 비교적 잠잠했다. 대신 9월 첫 이틀(9/1, 9/2)에 Anthropic과 OpenAI가 각각 최상위 모델을 내놓으면서 같은 주에 프런티어 모델 두 개가 겹치는 드문 구간이 됐다.

Anthropic — Fable 5.1, 더 싸고 더 신중하게

Claude Fable 5.1이 9월 1일 공개됐다. Fable 5의 뒤를 잇는 최상위 모델로, 코딩·과학 연구·엔터프라이즈 업무처럼 몇 시간씩 이어지는 장시간 작업을 겨냥한다고 소개된다. 캐시 읽기 가격이 낮아지면서 일반적인 작업 기준 Fable 5 대비 약 25% 저렴해졌고, 모호한 상황에서의 판단력이 좋아지고 "자신 있게 틀리는" 답이 줄었다는 설명이 함께 나왔다. 같은 모델에 안전장치 수준만 다르게 적용한 Claude Mythos 5.1도 함께 공개됐는데, 이쪽은 신뢰된 접근 프로그램을 통해서만 쓸 수 있다.

OpenAI — GPT-6 Astra, 첫 "Critical" 등급 모델

GPT-6 Astra가 9월 2일 나왔다. 컴퓨터 사용·브라우징·소프트웨어 엔지니어링·과학·전문 업무를 겨냥한 모델로, OpenAI는 이 모델이 자사 준비 프레임워크의 사이버보안 위험 등급에서 처음으로 "Critical" 문턱을 넘었다고 밝혔다. 방어 장치가 없는 상태에서 GPT-5.6 Sol이 허용 범위를 48% 확률로 벗어났던 반면, Astra는 같은 조건에서 0%였다고 보도된다. 출시 초기에는 일부 조직에만 열리고 엔터프라이즈 관리자가 워크스페이스에서 직접 켜야 하며, ChatGPT Plus·Pro·Business·Enterprise와 API·AWS로는 며칠에 걸쳐 순차 확대될 예정이다.

Google — Gemini 3.5 Pro, 넉 달째 제자리

Gemini 3.5 Pro는 6월 목표에서 7월 중순, 8월 초로 계속 밀려왔고, 9월 초 시점까지도 확정된 출시일이 없다. 환각률과 실사용 신뢰성 목표에 못 미쳐 DeepMind가 베이스 모델을 다시 만들었다는 보도가 계속 이어지는 중이며, Google은 여전히 "곧 공개"라는 말과 함께 일부 파트너 대상 테스트만 하고 있다고 설명한다.

벤치마크 수치는 그대로 믿지 않는다 이 글의 성능·등급·연기 사유 언급은 9월 초 시점의 외부 보도와 각 사 발표를 근거로 한 것이며, 측정 방식·버전·시점에 따라 출렁인다. 특히 "Critical" 사이버보안 등급 같은 안전성 관련 수치는 각 사의 자체 평가 기준에 따른 것이므로, 정확한 정의와 조건은 공식 발표를 확인한다.

안정성과 물리 세계로 — 장애·Claudeforce·MHS

이번 구간은 모델 자체보다 Anthropic 주변의 소식이 유독 많았다. 장애로 신뢰가 흔들린 동시에, 엔터프라이즈와 물리 세계로 손을 뻗는 발표가 겹쳤다.

8월 16일 인증 장애, 그리고 반복되는 다운타임 지적

8월 16일 21시 58분(UTC)경 Claude.ai·Claude Code·Claude Cowork에서 로그인 실패, 응답 없음 등의 장애가 발생해 약 36분간 이어졌다. Anthropic 상태 페이지는 인증 시스템 문제로 조사 중이라고 밝혔지만, 무엇이 인증 시스템을 실패하게 했는지 근본 원인은 공개하지 않았다. 이 사건을 계기로 최근 30일간 상업용 Claude가 28차례 다운된 반면 정부용 등급은 한 번도 내려간 적이 없다는 비교 보도도 나왔다.

AI 생성물 워터마킹 시작

Anthropic은 8월 2일 이후 출시되는 모든 Claude 제품이 EU AI Act 준수를 위해 AI가 생성한 콘텐츠에 기계가 읽을 수 있는 표시를 포함한다고 발표했다.

Salesforce와 "Claudeforce" — 9월 오픈베타 예정

Salesforce와 Anthropic이 8월 26일 확장된 파트너십 Claudeforce를 발표했다. 첫 제품인 "Salesforce in Claude"는 37개의 프리빌트 영업 스킬을 담은 플러그인 형태로, 실시간 CRM 데이터를 두고 판매 준비·파이프라인 검토·이메일 초안·레코드 업데이트를 Claude 안에서 바로 처리할 수 있게 한다. Salesforce의 권한·거버넌스 체계는 그대로 유지된다. 현재 파일럿 단계이며, 9월 중 오픈베타가 예정돼 있다.

Model Hardware Standard — 로봇·실험 장비로 손을 뻗다

Anthropic이 8월 27일 Model Hardware Standard(MHS)를 공개했다. 소프트웨어 도구에 MCP가 했던 역할을 물리 장비에 대해 하는 개방형 규격으로, AI 에이전트가 로봇 팔·현미경·액체 취급 장치·레이저 같은 장비의 센서를 읽고 구동기에 값을 쓸 수 있게 표준 인터페이스를 제공한다. 장비의 무게·안전 한계·조절 가능한 파라미터처럼 그동안 매뉴얼이나 숙련자의 암묵지로만 존재하던 정보도 표준 드라이버에 담긴다. 현재는 일부 기관 대상 리서치 프리뷰 단계다. 초기 사례로 Genentech은 액체 취급 장치·로봇 팔·플레이트 리더를 엮어 단백질 분석 절차를 자동화했고, 양자컴퓨터 기업 QuEra Computing은 사람 개입 없이 99.3% 확률로 레이저의 정밀한 동작 주파수를 복구하는 데 성공했다고 보도됐다.

코딩 에이전트 — Claude Code vs Codex

이번 구간 코딩 에이전트 쪽 변화는 두 갈래다. Claude Code는 자동 실행 범위를 넓히는 방향으로, Codex는 구형 모델 정리와 브라우저 기능 통합으로 움직였다.

Claude Code — auto mode·fork mode 나란히 기본값으로

8월 14일부터 Pro·Max·Team 플랜의 신규 세션에서 auto mode가 기본 권한 모드가 됐다 — 분류기가 각 작업을 평가해 안전한 것은 그대로 통과시키고 위험한 것만 막거나 확인을 받는 방식이다. 일주일 뒤에는 대화 전체를 물려받은 백그라운드 서브에이전트에 곁가지 작업을 맡기는 fork mode도 대화형 세션에서 기본값으로 전환됐다. 그 외 세션에 문제가 생겼을 때 피드백 보고서 초안을 잡아 `/feedback`으로 검토·전송하게 해주는 SendFeedback 도구, 프로젝트의 API 비용을 캐싱·토큰 관리·배치·이펙트·모델 선택 순으로 하나씩 점검하는 `/claude-api cost-optimize`가 추가됐다. 8월 29일 업데이트에서는 샌드박스가 뜨기 전에 CLI가 먼저 기동하도록 바뀌었고, 리눅스 다운로드 용량이 크게 줄었으며, `/cost`·`/usage`·`/tasks`에 토큰 상세 정보가 붙었다.

Codex — 구형 모델 정리 + Atlas 흡수

8월 31일부로 ChatGPT 로그인 사용자 기준 Codex에서 GPT-5.4·GPT-5.4 mini 사용이 중단됐다 — API 키로 인증한 세션과 OpenAI API 자체에서는 계속 쓸 수 있다. 권장 대체 모델은 각각 gpt-5.6-terra·gpt-5.6-luna다. 브라우저 기반 에이전트였던 Atlas는 8월 9일부로 단계적으로 중단됐고, 관련 기능은 ChatGPT와 Codex 안으로 흡수됐다. 8월 25일부터는 Plus 사용자 대상으로 5시간 사용 한도가 다시 도입됐다. 그 외 Codex Remote를 실행할 때 ChatGPT를 바로 여는 옵션, 표준 MCP 폼 지원, 대용량 작업 응답이 안 뜨던 문제 수정, diff 리뷰 안정성 개선이 있었다.

현장 컨센서스 — Claude Code는 "사람이 덜 개입해도 되는 범위"를 넓히는 쪽으로, Codex는 "쓰던 모델 정리하고 흩어진 기능을 한곳에 모으는" 정리 국면으로 읽힌다. auto·fork 모드 기본화는 편의성과 함께 오작동 시 파급 범위도 커진다는 뜻이라, 권한 설정을 한 번 점검해볼 만한 시점이다.

이달의 한 줄 · 다음 달 볼 것

  • 한 줄 요약 — 8월은 조용했지만 9월 첫 이틀 사이 Claude Fable 5.1과 GPT-6 Astra가 연달아 나오며 프런티어 경쟁이 다시 불붙었고, Gemini 3.5 Pro는 넉 달째 제자리다. 그 사이 Claude는 장애·워터마킹·Salesforce 파트너십·물리 세계용 표준(MHS)까지 모델 바깥에서도 분주했다.
  • 실무 take — Fable 5.1은 캐시 읽기 가격 인하로 비용 부담이 줄었으니 장시간 에이전틱 작업에 써볼 만하다. Claude Code를 쓴다면 auto·fork 모드가 기본값으로 바뀐 만큼 권한 설정을 한 번 확인해두는 게 안전하고, Codex를 API 키가 아닌 ChatGPT 로그인으로 쓰고 있다면 GPT-5.4 계열 코드가 남아있는지 점검할 시점이다.
  • 다음 달 볼 것 — Gemini 3.5 Pro의 실제 출시 여부, GPT-6 Astra의 "Critical" 등급 가드레일이 일반 공개 이후에도 유지되는지, Claudeforce 오픈베타 반응, MHS의 퍼블릭 릴리즈 시점.
